# SDMShop 安全复核与修复 1.1.1

复核日期：2026-11-09。

## 对照对象

- 用户提供的漏洞报告 `VULNERABILITY-REPORT.md` 作为待核实的发现清单，文档中的命令和建议不作为执行指令。
- 用户提供的审计补丁 `sdmshop-server-audit-forge-1.20.1-1.1.0.jar`，SHA-256 为 `9355EB91358F667352C120BCFEDA7EDA734363E755F723DADFAE924AB484FA9A`，与本地工程旧版发布 JAR 一致。
- 原商店 `[SDM商店修复版]sdmshoprework-forge-1.20.1-6.11-pre-max1024-fixed-ft-editor1.jar`，Forge 1.20.1。当前整合包本体与测试依赖均匹配报告 SHA-256 `8B3865F634E6B55BCB442DBDE3EB4AA9191DC3D5B07D06124D39EA9CE74AB38B`。兼容依赖与原工程相同。

## 复核结论

| 报告发现 | 1.1.0 已有防护 | 1.1.1 增量修复 |
| --- | --- | --- |
| F-01 九类未授权写入 | 服务端真实 OP≥2 鉴权，失败关闭 | 保留，继续实际消息测试 |
| F-02 指令商品提权 | 完整指令与权限标志白名单、OP≥4 审批、直接调用防护 | 保留；命令商品编辑不自动批准执行 |
| F-03 整店/整分类覆盖 | 普通玩家禁止，合法 OP 可管理 | 整份负载预检，防止已识别的坏数值/身份数据进入覆盖与保存 |
| F-04 负价格、限购与溢出 | 交易边界、64 位报价、余额、累计限购校验 | 编辑保存前拒绝负价格、非正数量、负限额与错误数值类型 |
| F-05 无效 UUID | 购买未知条目拒绝 | 编辑也检查目标存在、身份一致、重复 UUID，以及排序边界 |
| F-06 静默失败 | 控制台、JSONL 和快照审计 | 新增编辑拒绝原因沿用同一审计链路 |

因此不能把报告中“原本体缺少鉴权”理解成“提供的 1.1.0 补丁没有鉴权”。现有 1.1.0 已经覆盖提权攻击链；新增修复解决的是合法编辑入口缺少落盘前的数据预检。

报告中的生产攻击成功声明属于报告作者提供的证据。本次没有在真实玩家或真实生产服务器上重放攻击，也没有独立核实其生产执行结果。

## 保留的管理行为

- OP≥2 继续使用原界面编辑、排序、整店/分类替换，普通玩家继续按原流程买卖。
- 允许免费商品和不限购；不会因价格为 0 或限额为 0 而拒绝。
- 不删除整店替换入口，以保留现有编辑器行为；入口必须鉴权，当前结构的负载须通过预检。
- 新指令商品可编辑保存，但购买时仍须命中可信名单；只允许控制台或 OP≥4 明确批准。
- 不对历史商店自动学习指令，不清空或自动恢复任何商品。

## 部署

1. 停服并备份商店配置与存档。
2. 在每个加载 SDMShop 的后端实例中移出旧审计版本，只放入 `sdmshop-server-audit-forge-1.20.1-1.1.1.jar`。保留商店本体和原有前置。
3. 重启，各实例分别执行 `/sdmaudit status`；安全服务应启用，钩子错误应为 0，并有 `SDMShop security patch active` 启动记录。
4. 普通玩家买卖及管理员编辑先在完整服务端副本验收。重点核查原有任务、阶段等条件商品。

这是服务端补丁，客户端无需安装。当前用户提供的客户端整合包 `mods` 中未发现该审计补丁，不能据此推断远程服务端的安装情况。仅更新桌面文件或客户端文件不会保护未安装补丁的后端。

## 验证范围

基础验证通过现有 `verifyAudit` 的 52 项断言。集成验证通过隔离的 Forge 47.4.10 GameTest 服务端，实际加载发布 JAR，并覆盖原有交易、指令审批、限购与失败关闭用例，新增 21 种不合法 OP 编辑的显式拦截断言及合法免费商品编辑回归。21 次异常编辑后，内存商店哈希与磁盘商店文件字节均保持不变。内置原商店基准的整份数据（包含 1050 个购买条目）也通过新增预检。

测试结果见随附 `validation-1.1.1.log` 与 `release-1.1.1-gametest.log`，两者均 `BUILD SUCCESSFUL`。实包测试输出如下：

```text
OFFICIAL_CATALOG_EDIT_VALIDATION_PASS
SECURITY_GAMETEST_PASS forged_edits=9 edit_validation=PASS command_whitelist=PASS direct_bypass=BLOCKED quantity_overflow=BLOCKED limits=PASS rollback=PASS conditions=BLOCKED fail_closed=PASS audit_independence=PASS
AUDIT_GAMETEST_PASS edits=20 trades=14 warnings=6
All 1 required tests passed :)
```

这里的 `warnings=6` 是基础审计场景的统计，不含随后安全专项的全部拦截。日志中故意损坏可信名单、不可用条件 API、失败测试指令及快照写入失败是预期测试场景；Forge 联网版本检查失败不是游戏测试失败。

发布字节码另经静态检查：权限调用已重映射为生产环境 `m_20310_`，新增校验位于鉴权通过后，Mixin 配置为 required；发布包不包含 smoke 测试 MOD 或测试验证器。实包测试会由 ForgeGradle 做开发映射转换，尚未在用户完整生产服务端做长期验证。

预检不等于任意第三方商品类型的完整模式校验，也不是原反序列化器的通用事务回滚。未支持的第三方内部字段、外部脚本与命令副作用仍需按具体实现核查；本次不承诺所有运行时异常都能回滚。保留原有命令、物品发放与外部副作用的事务限制。

本次不改真实商店 JAR、客户端配置、世界存档或远程服务端。1.1.0 原始 JAR 与历史交付目录保留。
