# 农场物语：物品介绍自动滚动

Forge 1.20.1 客户端补丁，配合 Obscure Tooltips 3.10.1 使用。配件羁绊、附魔、食物效果等介绍在自动换行后超出屏幕高度时，沿用现有提示框的滚动范围自动翻阅。

- 悬停后在开头停留 1.5 秒，再以每秒 18 个 GUI 像素向下翻阅。
- 到结尾停留 2 秒，返回开头循环。
- 鼠标滚轮仍可手动滚动，最后一次操作后暂停自动翻阅 5 秒，再从当前位置继续。
- 切换物品、介绍高度变化、修改 GUI 缩放或离开后重新悬停时，从开头重新计时。
- 没有超出屏幕高度的介绍保持原样；关闭 Obscure Tooltips 或其滚动功能时，本补丁不接管滚动。
- 仅客户端需要安装；补丁不更改物品数据、羁绊效果或现有提示框模组文件。

在 PowerShell 运行 `./build.ps1`，使用本机 JDK 17 与 Gradle 缓存中的 Forge/Mixin 编译依赖离线构建。产物为 `build/libs/ft_tooltip_autoscroll-1.0.0.jar`，放入当前实例的 `mods`，重启游戏后生效。

源码中的 Minecraft 相关参数来自现有 Obscure Tooltips 类型，Mixin 只注入该模组自己的未混淆方法及字段，不依赖 Minecraft 映射重写。依赖 JAR 仅用于编译，不打入成品。
