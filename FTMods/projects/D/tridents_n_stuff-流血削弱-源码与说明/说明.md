# 血腥契约（Sanguine Bond / sanguine 三叉戟）流血削弱

改动位置：`tridents_n_stuff` 0.2.0+1.20.1 (Forge 1.20.1-47.4.10)

被修改的 3 个 class：

| class | 方法 | 改动 |
| --- | --- | --- |
| `TridentModifier` | `applySanguine` | 层数封顶、持续时间、倍率封顶 |
| `TnsEvents` | `onLivingHurt` | 倍率封顶 |
| `BleedingEffect` | 整类重写 | 10 秒后逐层衰减 |

---

## 1. 流血层数上限 5 层（等级 V）

`TridentModifier.applySanguine`：

```
原：target.addEffect(MobEffectInstance(BLEEDING, 100, amp + 1))     // 无上限
现：target.addEffect(MobEffectInstance(BLEEDING, 400, min(amp + 1, 4)))
```

## 2. 伤害倍率上限 16 倍

原本两处都按 `2^(amp+1)` 指数增长，5 层稳定态是 **32×**；现在两处都改成 `2^min(amp+1, 4)`，上限 **16×**：

* `TnsEvents.onLivingHurt`：`event.setAmount(amount * 2^min(amp+1, 4))`
* `TridentModifier.applySanguine`：`multiplier = 2^min(amp+1, 4)`（同时用于自我治疗 `heal(2 × multiplier)`）

| 命中时目标已有层数 | 放大器 | 原倍率 | 现倍率 |
| --- | --- | --- | --- |
| 无流血 | -1 → 0 | 1× | 1× |
| Lv1 | 0 → 1 | 2× | 2× |
| Lv2 | 1 → 2 | 4× | 4× |
| Lv3 | 2 → 3 | 8× | 8× |
| Lv4 | 3 → 4 | 16× | 16× |
| **Lv5（满层）** | 4 → 4 | **32×** | **16×** |

自我治疗同步变成最高 `2 × 16 = 32` 点（受生命上限限制），原来是 64 点。

## 3. 流血 10 秒后开始逐层下降

`BleedingEffect` 重写：

* 持续时间 100 tick(5s) → **400 tick(20s)**，这样「10 秒满强度 + 10 秒衰减期」能装进同一个效果实例
* 每次命中依旧刷新（持续时间重置为 20 秒）→ 持续输出时层数维持在上限
* 距最后一次命中满 **10 秒** 后，每 **2 秒** 掉 1 层，直到 0 层，效果在 20 秒时自然结束

```
0s ─────────────── 10s ── 12s ── 14s ── 16s ───────── 20s
Lv5 满强度          Lv4    Lv3    Lv2    Lv1          结束
```

流血直接伤害节奏沿用原公式（每 `50 >> amplifier` tick 造成 1.5 点），只是把 `isDurationEffectTick` 的判定搬进了 `applyEffectTick`，因为现在要每 tick 检查衰减。

---

## 可调参数

`BleedingEffect.java`：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `MAX_AMPLIFIER` | 4 | 最高放大器（4 = 5 层） |
| `DECAY_START_DURATION` | 200 | 剩余 200 tick（10 秒）时开始衰减 |
| `DECAY_INTERVAL` | 40 | 每 40 tick（2 秒）掉 1 层 |

`PatchMod.java` 的命令行参数：`<原版extract目录> <输出目录> <最高放大器> <持续时间tick> <最大指数>`
本次构建用的是 `4 400 4`（5 层 / 20 秒 / 16 倍）。

**注意**：`DECAY_START_DURATION` 与效果总时长必须满足 `总时长 - 200 = 10 秒`，
即总时长固定 400 tick 才能保证「最后一次命中后满 10 秒」才开始衰减。

## 副作用（需要留意）

持续战斗中的流血 DPS **没有变化**（层数上限 + 命中刷新，仍是最高每 3 tick 1.5 点）。
但脱战后流血会残留最多 20 秒（原来只有 5 秒），所以「打一下就走的」总流血伤害会变高：

| 层数 | 原来（5 秒） | 现在（20 秒，含衰减） |
| --- | --- | --- |
| Lv5 | 34 次 / 51.0 伤害 | 81 次 / 121.5 伤害 |
| Lv4 | 17 次 / 25.5 伤害 | 41 次 / 61.5 伤害 |
| Lv1 | 2 次 / 3.0 伤害 | 8 次 / 12.0 伤害 |

如果觉得残留太久，把 `DECAY_INTERVAL` 改成 20（1 秒掉 1 层）可把总时长压到 15 秒。

## 构建方式（可复现）

```
# 1. 重新编译 BleedingEffect
javac --release 17 -cp forge-1.20.1-47.4.10-srg.jar -d out src/BleedingEffect.java

# 2. 字节码补丁（需要 asm 9.x）
java -cp tools;asm-9.8.jar;asm-tree-9.8.jar PatchMod <extract目录> out 4 400 4

# 3. 用 out/ 里的 3 个 class 替换原 jar 中的同名条目
#    （tools/build_jar.ps1，其余 217 个条目字节完全一致）
```

原版备份：`mods/[武器]tridents_n_stuff-0.2.0+1.20.1-forge原生.jar.bak`
