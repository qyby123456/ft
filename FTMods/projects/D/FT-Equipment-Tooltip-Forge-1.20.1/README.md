# 农场物语：装备属性汇总

Forge 1.20.1 客户端独立补丁。武器、工具和护甲的属性按装备槽位、属性种类合并，集中放在物品名称下方；短属性每行最多两项。默认收起原版修饰符明细，按住 Shift 保留明细。附魔、技能描述、套装说明、食物提示、NBT 调试信息和现有提示框样式不接管。

## 计算口径

- 从实际 `ItemStack.getAttributeModifiers(slot)` 读取，包含 NBT 与 Forge 属性事件的结果，不修改物品、玩家或存档。
- 按 `(基础值 + 固定加值之和) × (1 + 基础倍率之和) × 各总倍率之积` 计算。相同属性、相同 UUID 仅保留一个修饰符。
- 主手攻击伤害、攻击速度分别使用标准玩家基础值 1 和 4；不计当前玩家技能、药水、其他装备等加成。攻击伤害包含附魔对普通目标的通用额外伤害；不虚构对亡灵、节肢等特定目标或触发技能的伤害。
- 其他属性显示此装备的净加值；纯倍率合并为百分比。固定值与倍率并存时显示为“原有值 ×倍率，另加净固定值”，这是独立于玩家当前属性的准确合并表达，不能假装成一个绝对值。例如固定加值 4、基础倍率 20%、总倍率 50%，结果为“原有值 ×1.8，另加 7.2”。
- 击退抗性的固定值按百分比显示，避免原版单位歧义；主手攻击属性遵循该属性的取值范围。
- 仅替换原版实际显示出来的装备属性段落，因此遵循隐藏属性提示的物品设置；不同槽位不混加。不接管 Curios 自定义槽位的属性说明。

## 兼容与回滚

与当前 `obscure_api-18-farmingtales.3` 的顶部重复装备图标行兼容：汇总成功时移除该行，若该行含耐久则单独保留耐久。食物图标不会移除。兼容 Obscure Tooltips 的外框、自动换行与自动滚动，不覆盖这两个模组。

计算失败时保留原始提示，同物品只记录一次警告；不会清空原始说明。按住 Shift 时依然提供汇总，但原版属性分项留在下方，便于核对。

运行 `./build.ps1` 使用本机 JDK 17、当前实例声明的本地库与现有 Forge 缓存离线编译，执行检查后使用 ForgeAutoRenamingTool 转换为生产环境 SRG 名称。产物为 `build/libs/ft_equipment_tooltip-1.0.0.jar`，仅客户端安装。删除该新增 JAR 并重启即可回滚；没有需要恢复的装备、配置或存档数据。

游戏已运行时新增 JAR 不会热加载，需要完整退出并重新启动。独立检查不等于游戏内视觉验收，需在游戏中分别悬停普通剑、多词条武器、护甲和附魔装备，并按住 Shift 核对。

## 自动检查

构建时运行实际 Minecraft `AttributeInstance` 的 1000 组随机交叉校验（含负固定值、负倍率、多项基础倍率、多项总倍率），同时检查汇总表达式、重复 UUID、非有限数值、按槽位识别、Shift 展开、技能与附魔保留、食物图标保留、耐久恢复、失败不修改原列表与重复调用保护。生产 JAR 额外逐个链接所有直接调用的 Minecraft/Forge 字段和方法，验证 SRG 转换不遗留不可用的方法名。构建结果写入 `build/verification.json`。
