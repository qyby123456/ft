# 420 私有种子隔离

主动审查416引入的私有种子输出发现：仅核对私有构建器finish帧，不能阻止外部反射构造该构建器并传入既有CompoundTag。SeedBoundary420在417字节码上复现既有种子被改写，不能把这个边界视为安全。

修复仅修改NativeExpectedFieldObservation.fingerprintCompoundForRead416：有种子时要求精确CompoundTag类，并复制后再写入私有结果。外部种子保持原样，子类在copy回调之前被拒绝；不关闭CURRENT或放宽任意映射写入权限。

前后独立Java进程分别证实旧实现改写外来种子、修复后不改写且拒绝恶意子类。640项字节/别名对照、128项摘要、六项外部入口拒绝、八类ASM和单方法差分通过。测试修正中，种子不变性改为与该种子本身的事前序列化字节比较，避免将原生copy可能产生的不同HashMap布局误认为写入；产出字节与原始算法的对照未降低。

421累计绑定；真实混入环境仍由422验证。保持NOT-INSTALLABLE。
