最终范围仅为 Forge 1.5.2；本轮不读取或写入 NeoForge 实例。早期 `_work/event-four-way-20261008` 标记 SUPERSEDED，工程、备份和历史记录全部保留，等待统一通知线程集中审计清理。

## 优化

- 核心保持 KubeJS `cardinal` 四向放置，显式设置旧存档默认北向，并补齐方块结构旋转和镜像回调。
- 统一四向状态为确定性的紧凑 JSON；只压缩表示，不改变模型引用或角度。
- 重新审计三模型几何、面、UV、纹理、物品父级与边界。保留已有模型和纹理，不为减面破坏旋转后可见面或核心两段碰撞箱。
- 天气预报机朝向实现与预言机对照校验，保留现有交互与其他类方法；本轮不再次替换实现类。
- 独立部署工具移除双实例目标和锁定后的重试/替代写入；只在基线匹配、文件未锁定时原子写入。

## 部署约束

`release.py prepare` 从当前 Forge JAR、脚本和资源读取本次增量与预览素材，保存测试基线。
校验完成后 `release.py deploy` 再核验部署当刻的相关文件 SHA256，先备份，再从当刻 JAR 逐项保留未修改条目；不使用早期整包覆盖。
共享部署锁不可用、目标文件被占用或任何相关基线变化均停止，不重试、不强行原地覆盖。已写入项逐项记录于部署日志；并发变化不触发旧快照覆盖。
`release.py verify` 检查部署结果；`release.py package` 归档本轮工程、预览、校验与部署备份，生成逐文件 `CHECKSUMS.json` 和归档 `archive-sha256.json`。
