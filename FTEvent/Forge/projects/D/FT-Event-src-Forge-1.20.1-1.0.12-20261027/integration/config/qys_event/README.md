# Event 配置入口

## 修改金币锅的金币概率

打开同目录的 `wishing_well/gold_pot_coins.json`。

- `coins`：中奖时的金币数，依次为 1、100、1000、10000、100000、1000000。
- `weight`：概率权重。某档概率 = 本档权重 ÷ 六档权重之和。
- 金币类别在每锅中占 5%，其他类别和绿宝石许愿不读这个文件。
- 默认金币类别内平均 180000 金币，乘 5% 后，每锅直接金币返还期望 **9000**。
- 金币锅金币不叠加三倍或数量大奖。保存合法 UTF-8 JSON 后，下次投入金币锅即可读取，不覆盖你的编辑。
- 改权重会改变期望，不会自动维持 9000。六档和顺序须保留，权重必须是正整数。

详细奖励、升级和结构：[许愿井说明](../../kubejs/WISHING_WELL.md)。JAR 内置中文手册位于 `docs/`，可用压缩软件打开 JAR 阅读。

天气仍使用上一层的 `qys_event-common.toml`，不要把天气配置和许愿池金币配置混在一起。
