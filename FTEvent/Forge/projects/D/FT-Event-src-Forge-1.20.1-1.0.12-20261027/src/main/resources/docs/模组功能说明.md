# Event 模组功能说明

Event 包含节气天气、每日世界事件、预言机、天气预报机及原生许愿井。整合包另有 KubeJS 多方块许愿井；两个井不是同一个奖池。

## 常用方块

| 方块 | 用途 |
| --- | --- |
| `qys_event:oracle` | 预言机，消耗绿宝石查看带误差的未来事件预言 |
| `qys_event:weather_forecaster` | 预报明日节气天气 |
| `qys_event:wishing_well` | 模组原生许愿井，消耗绿宝石抽物品、幸运、预兆或空白回应 |
| `farmingtales:wishing_well_core` | 整合包多方块核心，支持升级、金币锅和商店；见《许愿池奖励说明》 |

## 天气与世界事件

- 根据二十四节气选择普通天气；有 32 种季节限定的特殊天气。默认特殊天气日概率 15%，随机触发后至少间隔 2 个普通日。
- 19 种每日世界事件独立于天气调度，包含主题生物、作物与环境效果。
- “大雪”实际是棕褐色污雨：支持同层安全地面补充刷新，室内和洞穴也能出现主题生物；刷新上限与远距清理保留。
- 预言机可以显示错误日期、错误事件与错乱文本，属于玩法，不是稳定精确的事件时间表。
- 作物生长、产量、连续同天气衰减以及破坏性天气由 `config/qys_event-common.toml` 控制。

## 原生许愿井的概率

这不是金币锅池，不受六档金币配置影响：45% 普通物品、25% 幸运效果、20% 天气与事件预兆、10% 空白回应。物品类别中会随机石材、木材、金粒、紫水晶、铁粒、绿宝石或钻石。石材与木材读取对应物品标签。

## 管理与调试

管理员可用 `/qysevent status` 查看状态、`/qysevent event list` 查看事件，天气相关指令在 `/solarweather` 下。多方块许愿井测试入口为 `/wishingwelltest` 或 `/ft wishingwell`；测试会真实发放物品。

完整的旧版效果逐项研究保留在工程 `docs/history/` 和 `docs/research/`。历史文档内的版本号、部署路径、许愿井升级和金币概率不代表当前规则；当前奖励以《许愿池奖励说明》及外置配置为准。
