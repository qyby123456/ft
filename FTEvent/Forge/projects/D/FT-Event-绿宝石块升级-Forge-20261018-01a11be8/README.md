# Event 1.0.8：许愿井绿宝石块升级

适用当前 FarmingTales Forge 1.20.1 实例。已经部署并保持开启，不是只改说明文字。

- 累计投入一组 **64 个绿宝石块**永久升满级，解锁商店和金币锅许愿。可分次累计，达到要求后只扣剩余差额。
- 绿宝石块右键核心投入 1 个，潜行右键投入整叠，也可丢入完整许愿井的内圈水中。
- 未解锁不消耗金币锅；解锁后从第一锅开始每锅抽奖一次，不再用 100 锅升级。
- 原版已投入 100 锅的玩家保留资格。商店价格、奖池概率、矿物稀有度、灾变三种块和四向放置保持。
- `ftboss` 没有修改；未接触世界存档和 NeoForge 实例。旧 Event 1.0.7 已禁用并备份。
