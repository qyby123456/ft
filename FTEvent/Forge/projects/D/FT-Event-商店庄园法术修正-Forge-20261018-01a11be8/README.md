# Event 1.0.8 配套脚本修正：500 万随机庄园法术卷轴

本轮只更新当前 Forge 实例的许愿井服务器脚本和客户端提示。Event JAR 保持 1.0.8，Boss JAR 未修改；不触碰世界存档、NeoForge、fix2 或桌面副本。

## 正式规则

- SDM **500 万**购买 1 张随机庄园法术卷轴，**不包含常规原版铁魔法**。
- 使用 Boss 的真实 `ManorSpellRules.Kind.values()` 和 `ManorIronSpells.spell(kind)` 枚举庄园专属目录，过滤未启用法术。当前原生目录有 35 项，实际可购买范围取决于启用配置。
- 不读取通用 `SpellRegistry.getEnabledSpells()`，也不靠 `allowLooting()` 筛选：庄园法术的该标记原本就是 `false`，旧逻辑因此恰好排除了庄园法术。
- 仅在庄园目录中随机选法术，继续在该法术的合法最小/最大等级内随机等级；写入并验证真实法术容器 NBT。卷轴载体仍是铁魔法的 scroll 物品，但内装法术只来自庄园。
- 庄园目录缺失、全部禁用、为空、混入非庄园 ID 或容器写入失败时，购买失败且不扣款，绝不退回通用铁魔法池。
- 原有关闭商店、恢复原生背包、再扣费发奖的队列保持；背包满不扣款。

## 保持不变

- 64 个绿宝石块累计解锁、第一锅即可抽奖，以及旧版已解锁资格。
- 非庄园召唤物 1 金币锅，随机庄园武器 5000 万且不含万味胚刃。
- 金币锅许愿奖池仍有独立的普通铁魔法类别和 0.035% 庄园综合奖励；这次只改 **500 万商店商品**，不改变抽奖概率。
- 四向放置、天气、其他脚本、Event/Boss 的实际 JAR 均不变。

## 自动验证

候选及实际安装脚本回归均为 517 项通过、0 失败；保留绿宝石升级、首锅抽奖和购买恢复等回归，原通用卷轴的 T16/T18/T25 改由新的庄园范围、价格、队列及 NBT 验收覆盖。没有修改旧版参考文件来制造通过。

相同的新入口验收对未修改的上一版脚本产生 5 项预期失败，包括 4000 次均抽到普通铁魔法和庄园池为空仍扣款；新脚本 4000 次无普通铁魔法。另用实际 Boss JAR 的纯枚举类读取 35 个法术 ID，再验证动态目录遍历，而不是只测两个手写法术。

运行：`node project/docs/wishing_well.behavior.test.js`。安装后的文件可追加 `--instance` 与实例绝对路径；`--baseline` 是上一版逻辑负对照，预期退出码为 1。

本次没有重编译或替换未变化的 JAR，也没有启动游戏做实机测试。重启游戏后让服务端脚本和客户端提示一起生效。

## 文件

- `integration/`：配套 KubeJS；只有服务器许愿井脚本和客户端许愿井提示有本轮修改。
- `project/`：继承的完整 Event 源码、测试和构建说明，JAR 版本未变。
- `reference/`：未修改的旧版夹具、上一版服务器及提示脚本。
- `audit/`：候选/安装回归、负对照、原生目录/API 核对。
- `deployment/before/`：本轮更新前两份脚本；部署回执为 `deployment/receipt.json`。
- `deliverables/`：未改变的独立 Event 1.0.8 JAR 与含源码、脚本、测试的完整包。单独替换 JAR 不包含本轮脚本修正。
