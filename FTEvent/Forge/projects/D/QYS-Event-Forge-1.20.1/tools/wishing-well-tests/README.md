# 许愿井行为测试资料

统一入口：工程根目录执行 `node tools/test-wishing-well.cjs`。加 `--instance` 与游戏绝对路径可验证实际安装脚本。

- `cases/`：当前发奖、料理、商店与升级用例；`coin.cases.js` 是 1.0.9 新增的精确金币、批量、掉落和退款回归。
- `reference/`：保留的旧版夹具、价格脚本与修改前许愿井，供测试比较；不是安装用脚本。
- `audit/`：实际料理与原生庄园法术枚举结果，作为固定测试数据。

Java 规则验证由构建执行，穷举全部 9000000 个金币签、100000 个类别签、10000 个矿物签，以及配置首次导出和读取修改。

脚本测试的原生抽奖结果是夹具，负责验证实际付款和发奖流程；不能代替启动 Minecraft 的实机验收。
