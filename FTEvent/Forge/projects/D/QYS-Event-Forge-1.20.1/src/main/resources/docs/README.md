# Event 模组维护入口

Minecraft 1.20.1 / Forge 47.4.10，版本 **1.0.12**。这里是 Event 的唯一维护工程；已合入现用 1.0.8 的四向放置、矿物奖池，以及最新许愿井脚本，不能再用旧 1.0.6 工程覆盖安装。

| --- | --- |

| 构建和验证 | `tools/build.ps1`；`node tools/test-wishing-well.cjs` |

## 当前规则摘要

季节兼容接口只解析一次，节气状态仍实时读取；每日事件按不可变 ID 索引查询，许愿井商店复用不可变布局与边框坐标。奖励、天气、存档和网络协议不变。

- 许愿井满级商店改为墨绿暖金像素界面，配有重绘井景、召唤物区、庄园秘藏区与行囊；核心提示和潜行右键仅保留简易玩法介绍，不再显示搭建及蓝图文本。
- 每个金币锅独立抽奖，金币类别概率仍是 5%；六档金币让每锅直接金币返还期望精确为 **9000**。
- 金币锅金币不乘三倍、不参与数量大奖；金币锅其余物品的三倍、1% 数量大奖、三菜价值至少 1000 的规则保留。这些加成不适用于绿宝石许愿。
- 累计 64 个绿宝石块解锁商店与金币锅许愿，首锅即可抽奖；旧版解锁资格保留。
- 庄园武器与法术购入需要本人同时满级许愿井、获取过猩红契约；否则不显示商品、价格或购买卡片，召唤物购买不受影响。获取武器获得红色粗体“×”成就，资格永久保留，旧版 `ftboss:blood_pact` 获取记录在登录时补发新成就。
- 庄园综合奖励仍为 0.035%，不是每件各占 0.035%。绿宝石许愿恢复原始奖励数量，四档类别概率不变；商店价格、天气和世界事件不变。

JAR 内置 `docs/README.md`、三份中文手册以及默认金币 JSON。游戏外置 JSON 优先，按批次读取，改完保存后下次金币锅许愿生效；修改 Java 或 KubeJS 后需要重新构建或重启游戏。
