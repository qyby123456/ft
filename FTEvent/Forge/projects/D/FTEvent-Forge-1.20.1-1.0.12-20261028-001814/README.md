先备份目标服/客户端原有模组、脚本、配置和世界，关闭客户端/服务端后再手动安装。本导出过程没有安装或修改游戏。
JAR 放入 `mods/`；`integration/kubejs/` 与 `integration/config/` 按原相对路径合入游戏目录。配置来自当前实例，包含本整合包现用设置；目标服如有自定义设置，请先比较，不要盲目覆盖。保留其他 Mod 和其他 KubeJS 文件，确保 Event 只启用一个版本。
