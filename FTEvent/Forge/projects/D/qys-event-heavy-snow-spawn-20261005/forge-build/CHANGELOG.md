# Changelog

## 1.0.5 - 2026-10-05

### 整理与性能
- 拆分天气调度与运行时效果，新增 `WeatherEffects`。
- 合并天气主循环中的重复存档读取和有效天气判断。
- 缓存按方块类型生成的作物识别信息。
- 增加玩家退出、服务器停止时的运行时缓存清理。
- 删除未被读取的预言咨询记录和天气预报节气持久化字段。
- 清理过时的 `ResourceLocation` 用法与重复构建脚本。
- 生成可复现 JAR。

### 兼容性
- 保持已有天气、每日事件、许愿井、预言机、命令和 Boss Mod 可选兼容行为不变。
- 旧存档可直接读取；已废弃 NBT 键会被忽略并在后续保存时自然清除。

## 1.0.4 - 2026-10-05
- 修复生物型每日事件可见性与测试触发预览。
- 增加事件生物上限、48 格外渐进消失和许愿井石/木标签奖励。
