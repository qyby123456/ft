# 食武进化与材料构成升级（2026-10-12）

## 状态与范围

生产源码及中英 UI 已完成，离线编译、规则回归、严格类/成员链接和 JAR 保留检查通过。**尚未写入正式 mods JAR**，合并部署仍交给 dsh。仅面向 Forge 1.20.1 / ForgeⅡ v1.5.2，NeoForge 不变。**本轮不改武器 3D 几何或贴图**：材料构成由 UI 和真实属性体现，保留原有武器外观。

## 进化、技能与祝福

- 符合既有食武候选规则的普通武器最多进化 **4 次**，万味胚刃维持 **8 次**；保留 Create 工具/武器的既有排除规则。
- 普通食品插槽按阶段开放 **2 / 4 / 6 / 8 / 10** 个；万味系列原有 30 格保留。失败不销毁已安装食品，仍可查看/取下；新增安装受当前等级限制。
- 普通每个成功阶段学习 **2 项不重复被动**，优先从石像扩展后的 **6 项池**抽取，用尽时补全局未拥有池。万味沿用特殊抽取。食品祝福上限升至 **6 项**，允许跨石像构筑。
- UI 支持未绑定普通武器首次绑定，不清经验、食品、附魔和外来 NBT；原生系列不能任意重新绑定。10 个原生食武 Boss 系列另加对应固有被动，详解逐项显示。
- 多技能携带与学习分开；默认全携带，定制后不强行加入新阶段。至少保留一项，退级/洗点清理失效索引。
- 默认按住 **G** 开轮盘，鼠标/滚轮选择，松 G 或左键确认；Esc/右键取消，G 可重绑。轮盘仅选技；**J / Shift+J 原施放路径、耐久成本与服务端冷却保留**。

## 食品献祭与失败

每次尝试要达到经验门槛并选择当前石像对应种类的 **1 个食品**。UI 显示品质、成功率与风险；服务器重新校验后消费/抽签。创造模式保留不消费习惯。

| 当前 → 目标 | 品质0 | 品质1 | 品质2 | 品质3 |
| --- | ---: | ---: | ---: | ---: |
| 0 → 1 | 85% | 93% | 100% | 100% |
| 1 → 2 | 70% | 78% | 85% | 92% |
| 2 → 3 | 55% | 63% | 70% | 77% |
| 3 → 4 | 40% | 48% | 55% | 62% |

普通公式 `clamp(85 + 品质加成 - 当前等级×15, 10, 100)`，加成为 0/8/15/22；万味每级扣 7。优先读 Quality Food 的 `quality_food.quality`，无标签时按现有食品品质规则。

失败退 **一个进化阶段**（0 不再下降），回退对应技能/随机属性/选择；献祭仍消费。成功或失败均清零本阶段经验，需重新获取；门槛为 **100/250/450/700**，万味再接 **1000/1350/1750/2200**。无效请求、经验不足、异常历史先拒绝，不消费、不掷骰。

每座石像每日 **12 项任务，至少 3 项进化经验任务**；已有当日任务的完成/领取状态保留，不重置刷奖励。

## 三部件材料构筑

UI 分别替换 **刃部 / 握柄 / 核心**。每次消耗所选背包材料 **1 个**，不退旧材料；重复/非法编码拒绝。武器注册 ID、附魔、进化、食品、第三方 NBT 保持。

支持木板/原木/木棍、圆石/石头/黑石、铁锭、铜锭、金锭、钻石、下界合金锭、骨头、黑曜石、皮革、烈焰棒、绿宝石；未替换部位为原装。

| 权重 | 刃部 | 握柄 | 核心 |
| --- | ---: | ---: | ---: |
| 伤害 | 70% | 15% | 15% |
| 攻速 | 50% | 40% | 10% |
| 最大耐久/损耗 | 60% | 25% | 15% |
| 额外触及 | 70% | 20% | 10% |

实际影响伤害/攻速属性、Forge 实体触及、最大耐久、每次耐久损耗及材料被动，不是只改 tooltip。材料系数集中在 `FoodWeaponBuildRules.Material`。例：铁刃+木柄+原装核心对应伤害×1.075、攻速×1.05、最大耐久×1.135、损耗×0.9475、额外触及+0.195格。

- 换装按已消耗耐久比例 **向上取整**，不白送修理；投影破损时须先修复。损耗小数余量不因换材清零。
- 同种材料被动不重复叠加，混材可联动。铜+骨在共用 5 秒间隔内同时附加缓慢与凋零。其他效果含击退、燃烧、低血斩杀、减伤、冲刺抵箭、击杀回复。
- 箭射出时优先快照实际使用武器，空时退主手；命中读箭快照，不读后来换手武器。瞬发副手弩及模组投射物兼容仍需实机验。
- UI 显示真实伤害点数、每秒攻速、攻击距离、最大耐久、损耗比例，计入武器进化/食品属性但不计玩家临时增益。

## 食品组合能力

- **鱼×2+酒×1**：空中按潜行触发 3 秒腾空，按住缓升、松开缓降，30 秒间隔。不授创造飞行权限；换武器/死亡/换维度停止，**庄园整场禁飞判定优先**。
- **肉×2+奶酪×1**：命中敌对生物召唤最多 2 只友方狼，12生命/3攻击/最多30秒；20秒冷却且旧一组存续不能追加。离线/死亡/换武器/维度变化/远离时失效，重载清除，不变永久宠物，不掉经验战利品，不绕过 Boss 非玩家伤害免疫。
- 三件套+一个搭档食品使套装等级+1，最高 IV：茶↔苹果、肉↔奶酪、鱼↔酒、蔬菜↔能量，甜食/杂食配苹果。强化落实到原有效果等级/时长/伤害。
- 基础食品插槽强度提高 **50%**。
