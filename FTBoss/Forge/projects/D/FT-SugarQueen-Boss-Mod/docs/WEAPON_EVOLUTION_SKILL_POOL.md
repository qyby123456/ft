# FTBoss 武器进化技能池

## 生效规则

- 10 条石像路径：糖霜、血肉、山茶、陈酿、奶酪、牧群、电弧、菌肥、果园、潮汐。
- 第一次进化：在武器归属石像处获得对应的**基础技能1**，按 `J` 施放。
- 第二次进化：FTBoss 原生食物武器可在任意第二石像潜行右键，组合按**无序**处理；例如「糖霜+潮汐」与「潮汐+糖霜」完全相同。
- 第二次进化会把技能1替换为组合强化版，并新增技能2；`J` 施放技能1，`潜行+J` 施放技能2。
- 非 FTBoss 武器保持既定规则：任选一座石像完成一次进化，之后不能进行第二次组合。
- 完整矩阵为 `10 × 11 ÷ 2 = 55` 组，含 10 组同系专精与 45 组跨系融合。

## 技能2机制族与模型效果

| 类型 | 结算方式 | 视觉层 |
|---|---|---|
| 爆发 | 瞄准12格内引爆4.75格融合领域 | 双层地面法阵 + 爆裂模型 |
| 新星 | 自身周围4.75格融合震波 | 环形模型 + 两系高亮层 |
| 连锁 | 至多7目标跳跃，每跳伤害递减10% | 实体化电弧/轨迹模型 + 落点模型 |
| 突袭 | 前方12格扇形突进式群攻 | 翼步/激流走廊/猎群模型 |
| 护域 | 自身周围攻击并强化治疗、防御与增益 | 护盾、花园、果园或圣所模型 |
| 旋涡 | 瞄准点持续牵引并结算双路径特性 | 陈酿、腐潮或暗流旋涡模型 |
| 光束 | 最长12格贯穿沿途目标 | 独立立体射线模型 + 终点模型 |

模型效果直接复用并重新编排 FTBoss 现有 72 套独立法术模型，不退化为普通粒子；所有 55 组都在技能池中显式绑定主视觉与技能2视觉。
