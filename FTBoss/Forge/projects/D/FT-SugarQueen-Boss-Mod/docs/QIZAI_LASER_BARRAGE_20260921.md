# 祁崽第十招：万棱星狱

日期：2026-09-21

## 需求落地

新增独立范围技能 `laser_barrage`「万棱星狱」。它参考玄蓝天穹锁击的“先明确预警、再按锁点结算”和朵拉聚能枪的“瞄准、锁向、开火”节奏，但祁崽本体不会升空：整场留在地面、保留碰撞、保持可见与可选中，也不会获得额外无敌。

## 现行参数

| 参数 | 数值 |
| --- | ---: |
| 持续生成阶段 | 每轮 120 tick（6 秒），连续三轮 |
| 生成间隔 | 依次 4 / 2 / 1 tick |
| 光束数 | 依次 30 / 60 / 120，合计 210；单轮上限 120 |
| 强制玩家锁定 | 每 5 束一次，三轮分别 6 / 12 / 24 束 |
| 单束预警 | 14 tick |
| 光束淡出 | 6 tick |
| 技能维持范围 | 40 格 |
| 随机发生场半径 | 24 格 |
| 晶棱高度 | 祁崽起手点上方 3–10 格 |
| 射线最大长度 | 36 格 |
| 命中半径 | 0.45 格 |
| 单束原始魔法伤害 | 48 |
| 收招 | 第三轮后 20 tick，轮间无额外休整 |

普通时序下三轮生成期间分别每 20 / 10 / 5 tick 锁定某位有效玩家的**当时位置**；其他光束从范围内随机空中位置选择随机三维方向。每轮末束完整预警、开火和淡出后进入下一轮，总计 440 tick（22 秒）。预警后终点冻结，不继续追踪。终结难度加速时序但保留 30 / 60 / 120 数量，允许同 tick 生成多束。详见 `QIZAI_BARRAGE_TRIPLE_20260921.md`。

## 判定与安全

- 起手仍要求有效玩家与视线；成功起手后进入承诺施放，不会被普通取消、临时 NoAI、目标清空或暂时失去全部有效玩家打断。无人可打时，锁定束使用最近一次有效玩家的冻结位置，随机束照常完成；创造、旁观、死亡或离场玩家不会被结算伤害。
- 承诺施放只保护技能流程，不给祁崽增加无敌或减伤；庄园普通回场在技能完成前暂停，不传送玩家，也不触发转场清理。
- 每束在生成时和开火时都按方块碰撞裁剪，视觉终点、伤害线段与墙体阻挡一致。
- 玩家锁定光束瞄准碰撞箱中心；随机光束至少尝试取得 8 格有效长度。
- 每束仅结算一次。结算时临时清除受击无敌帧，随后恢复较大的既有值，既不会吞掉密集光束，也不会破坏玩家原本的受击状态。
- 技能状态机不调用祁崽的移动、传送、无重力、隐身、无碰撞或无敌接口。

## 特效

- 每束改用万棱星狱专属“星棱炮镜”发生器：深紫多面炮身、旋转镶边、放射稳定翼与前后聚能环，不再复用通用法晶或交叉面片。
- 预警不是两张交叉贴片，而是有真实径向厚度的细立体蓄能管；玩家锁定束附带红白旋转准星和刻度，随机方向束使用较细玫紫末端环。
- 开火采用“半透明外壳 + 紫晶边层 + 黄白热芯”三层立体束，并加入沿束移动的能量箍与终点冲击冠；任意俯仰角都能保持完整体积。
- 渲染分两批：星棱炮镜走 `QizaiContrast.MODEL` 不透明写深度，预警、光束、准星与冲击冠走 `QizaiContrast.TYPE` 高对比透明材质；每种材质每帧只获取/刷新一次父级缓冲，渲染器内部不调用 `getBuffer`。
