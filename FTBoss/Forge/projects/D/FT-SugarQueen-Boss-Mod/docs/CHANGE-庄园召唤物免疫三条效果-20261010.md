## 一、根因（已逐条验证）

庄园战的两只 Boss 的波次召唤物**直接生成原版实体类型**，于是被第三方 mod 按**原版类型 id** 命中：

| 召唤物 | 原来生成 | 命中的机制 |
|---|---|---|
| 屠夫「学徒」(kind 0) / 「队长」(kind 2)，持铁斧/钻石斧（锋锐 3/4），`setDropChance(MAINHAND, 0f)` | `minecraft:vindicator` | **摸金校尉**（`kaleidoscope_tavern:tomb_raider`）：`onLivingHurt` 里若受击者类型在 `#kaleidoscope_tavern:tomb_raider_disarmable`（白名单含 `vindicator`/`husk`/`zombie`）→ 概率把**主手武器缴械丢在地上**；**斩首**（`kaleidoscope_world_liquor:beheading`）：按 `#kaleidoscope_world_liquor:bosses` 判定"是不是 boss"，原版类型不在表里 → 概率**双倍伤害**、该次击杀必掉头颅 |
| 屠夫「腌肉尸壳」(kind 1)、糖霜女皇「焦糖结晶」(kind 1) | `minecraft:husk` | 同上两条 + **亡灵增伤**（`getMobType()==UNDEAD` → 亡灵杀手、Armamentarium 武士刀/死兆戟等的亡灵加成） |
| 糖霜女皇精英（`applyEliteGear(Zombie)`，粉甲 + 手持甜品，`dropChance=0`） | 走 `ManorHuskEntity`（husk 是 Zombie 子类，仍命中 `instanceof Zombie`） | 同上 |
| 雪黎「女仆护法」 | `touhou_little_maid:maid`（第三方类型，**无法换类型**） | 已有 `XueliMaids.onGuardHurt` 挡掉"非玩家伤害"，但**玩家自己带的斩首双倍**仍可一击抹掉护法 |

关键限制：这些名单里写的是**实体类型 id**，不是 Java 类 —— 所以"继承 Vindicator"不会中招，中招是因为**直接用了原版类型**；也**没法**把 `minecraft:husk` 从别人的白名单里摘掉（那会让全世界所有尸壳一起免疫）。只有换成自有类型后，才能主动把它们加进"boss"名单。
