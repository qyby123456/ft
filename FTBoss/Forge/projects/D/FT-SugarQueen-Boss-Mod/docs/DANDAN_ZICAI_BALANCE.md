# 蛋蛋法术范围与紫菜减益增伤（2026-09-19）

## 蛋蛋

仅 Boss 本体的铁魔法范围倍率从 1.0 提高到 1.5；命中判定、粒子圈、法术模型与预警读取同一倍率。

| 法术 | 原范围 | 新范围 |
|---|---|---|
| 暮烛收割 `candle_reap` | 锥形前向长度 6 格 | 9 格，锥宽与高度同乘 1.5 |
| 暮烛囚笼 `candle_prison` | 半径 3.5 格 | 5.25 格 |
| 烛月蚀魂 `candle_eclipse` | 半径 3.5 格 | 5.25 格 |

玩家使用对应卷轴的范围、其他 Boss 的倍率、伤害、施法间隔、持续时间均不变。蛋蛋原生技能此前已完成的范围提升保留：六重镰 13.5 格、坠星 6.75 格、漩涡 21 格，不重复叠加。Mini/巨型形态不使用此次 Boss 法术范围加成。

## 紫菜

`本次减伤前伤害 = 原伤害 + 当前玩家负面效果种类数 × 2`

- 0 / 1 / 3 / 5 种负面效果分别追加 0 / 2 / 6 / 10 点伤害（2 点 = 1 颗心）。
- 统计原版及模组注册为 `MobEffectCategory.HARMFUL` 的当前效果，不受紫菜施加减益池的黑名单限制。
- 同一种减益无论 I 级还是 V 级只算一种；隐藏的旧等级不会重复计数。增益和中性效果（例如发光）不计入。
- 每次伤害结算时读取，不逐 tick 扫描注册表、不缓存玩家效果数。净化后立即降低后续伤害。
- 覆盖平砍、毒雾爆发以及能归因于紫菜的投射物和法术。每个实际伤害事件加一次；有明确 Boss 上下文的无来源技能走同一辅助入口，避免重复加成。
- 增量不是独立真实伤害，继续受正常护甲、抗性等减伤及现有战斗保护约束。
- 仅紫菜本体攻击有效生存/冒险玩家时生效；其他 Boss、玩家武器、非玩家目标、Mini/巨型形态、取消或非正数伤害不增加。
- 命中后才施加的减益从下一次伤害开始计算。无归属的中毒、凋零和环境伤害不冒认为紫菜伤害，不改变其自然跳伤。
