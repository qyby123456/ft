# 祁崽第九招「绯星锁裁」（2026-09-21）

## 设计

- 参考玄蓝「天穹锁击」的“先追踪/预警，再冻结落点”与朵拉「聚能枪」的“追踪 → LOCK → FIRE”节奏。
- 祁崽本体全程留在地面：不移动、不传送、不改重力、不隐藏、不关闭碰撞，也不获得技能免伤。
- 光束来源不固定在祁崽身上，而是在玩家周围随机生成六个空中晶棱，形成不同水平角度与俯角的交叉火线。

## 当前生效参数

| 项目 | 数值 |
| --- | --- |
| 技能 ID / 顺序 | `prism_lock` / 第九招，接在「天陨星裁」之后 |
| 有效范围 | 祁崽周围 40 格 |
| 晶棱数量 | 6 |
| 随机位置 | 距目标水平 7–14 格，高于目标 3–9 格 |
| 追踪阶段 | 24 tick；六条细线实时跟随玩家 |
| 锁定警告 | 12 tick；落点冻结，红白交叉线不再跟随 |
| 开火 | 每 2 tick 一束，共 6 束 |
| 判定半宽 | 0.55 格，与可见粗光束一致 |
| 单束伤害 | 72 点原始间接魔法伤害 |
| 收招 | 光束淡出 8 tick，再恢复 20 tick；后续休整使用 `REST × 2` |

终结难度继续使用现有 `acceleratedTicks` 加速追踪、锁定、束间隔和收招。晶棱优先选择区块已加载、世界边界内、无碰撞且到目标无遮挡的位置；开火时再次做方块裁剪，墙体后的玩家不会被穿墙命中。

## 可躲避与中断

- 追踪阶段只负责告诉玩家“正在被瞄准”，不造成伤害。
- 屏幕出现“锁定完成”后，六束的终点已经冻结；立刻横移即可离开所有交叉线。
- 锁定前目标死亡、离场、切创造/旁观或超出 40 格会取消并清除特效；锁定后则完成已经承诺的六束，避免 Boss AI 清目标导致技能半途消失。
- 死亡、移除、NoAI、变体切换等通用取消路径仍会停止技能并关闭法杖动画，不留下幽灵光束。

## 实现与验证

- 服务端状态机：`skill/QizaiPrismLock.java`
- 集中数值：`util/QizaiPrismRules.java`
- 客户端几何：`client/render/QizaiPrismVisual.java`，复用 `QizaiMagicVisual` 已取得的单个 lightning 顶点缓冲。
- 静态检查：`checkQizaiPrism`（21 条）与 `checkQizaiPrismSource`。
- GameTest：`QizaiPrismGameTests` 3 项，覆盖六个随机锚点、追踪/锁点、祁崽保持地面与可选中、预警无伤、锁定后六束完整结算、锁定前取消不残留伤害。
