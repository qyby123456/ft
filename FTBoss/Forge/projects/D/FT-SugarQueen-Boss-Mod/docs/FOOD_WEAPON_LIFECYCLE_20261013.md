## 本轮规则

1. 每损失 25% / 50% / 75% / 100% 耐久各触发一次：失去一个非原始改装材料（核心→握柄→刃部）和最后一个食物配件。没有相应部件时跳过，不删技能、祝福或附魔，不返物品。脱材保持磨损比例，未耗尽时不因缩容整数舍入假破损。
2. 耗尽保留武器，禁止攻击、挖掘、右键或技能；石像入口保留。未绑定的外部武器耗尽后也能先绑定，避免永久无法修复。绑定是管理操作，不是使用武器。
3. 只要曾成功进化，永久禁经验修补和普通修复；失败退零、磨石洗零不解除。Mending 不选择该物品、不吞用于修补它的经验。铁砧两侧同类输入、双输入磨石、工作台拼合不能绕过。既有附魔保留，不靠 Unbreakable 关闭损耗。
4. 最初绑定石像类别受理修复。交付对应食物 2+等级、铁锭 2+ceil(等级/2)、青金石 1+等级；创造也实际消耗。进度随武器可交易，继续损耗不清任务。进化、实际退级、磨石清历史会删除旧任务并推进版本，回到旧等级不能复活支付进度。完成三项后领满耐久、开启新周期，但不找回已掉部件。
5. 修复专用包带武器 UUID 与修订号，校验真实库存、原绑定、距离/已加载区块、玩家状态和限流，全路径 ACK；旧 Action 不接受修复。协议 7，客户端/服务端需同时更新。
6. 成功进化时为新技能单次随机稀有度，按祭品品质 0/1/2/3 取总区间 0.85–1.10 / 1.00–1.30 / 1.15–1.55 / 1.30–1.85 倍。存档后不查询重抽、不失败重抽。主动技能同时缩放平伤和攻击系数，保持原 128 上限；伤害/暴击被动只缩放自身加成、连锁只缩放附伤，治疗/增益不缩放。旧技能无记录恒 1 倍，非法记录安全兜底。
7. UI 增加损耗/修复子页、三任务进度、供品倍率区间、技能稀有度和保存倍率。详情/修复/通用绘制拆为独立组件。
