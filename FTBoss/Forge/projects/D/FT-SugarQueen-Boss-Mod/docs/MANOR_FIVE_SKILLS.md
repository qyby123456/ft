# 庄园五位 Boss 技能扩展

适用：蛋蛋、折耳根、文玄蓝、柚子、柠檬猫。只增强 Boss 本体；不调整玩家武器、其他庄园成员、战利品、交易或地形。

## 基础强化

- 五位本体追加攻击属性总乘区 +40%；使用固定 UUID 的临时属性修饰符，重进世界不会重复叠加，迷你分身不获得此修饰符。
- 本体近战命中水平推动 1.50、上抛 0.55；这些是速度参数，不是最终飞行格数。
- 蛋蛋连瞬每段 28 魔法伤害，末段追加强化击退。
- 折耳根暗影突袭基础总量 112，保留原有物理/虚空分配与侵蚀，命中追加强化击退。
- 柠檬猫翻锅基础 100.8，水平推动 0.9、上抛 1.65；借招基数 78.4，重砍保留 1.5 倍系数。
- 玄蓝专属技能/飞轮主体伤害倍率 3.64；超能光束每脉冲总量 400（2026-09-17 按用户要求「减少到 400」，原 504），仍按原有四系分配。蒸汽水平推动 0.85，光束连招推动 0.55，超能光束推动 0.45。
- 柚子原有通用重击与施法冲击基础伤害提高 40%；本体近战与新技能另外使用各自规则。

所有伤害数字都是护甲、抗性、盾牌和第三方模组结算前的输入值，不代表实扣生命。折耳根原有连击虚空附伤继续生效；未整体翻倍持续减益、虚空侵蚀或飞轮额外固定附伤。

## 按玩家强度动态增伤

- 仅上述五位 Boss 本体及其归属明确的投射物，对当前受击玩家动态计算；多人不会取全场最高值，也不永久修改 Boss 属性。
- 增伤 = 10% + 20% × clamp((玩家生命上限 − 20) / 80, 0, 1) + 2% × min(正面 Buff 种数, 10)，总范围 10%–50%。
- 使用生命上限，不随当前受伤掉血反复变动；吸收黄心不计入生命上限。生命上限增益会通过实际最大生命值参与计算。
- Buff 按存活的不同正面效果计数；等级不额外加权，负面和中性效果不计数。每次命中重新读取，Buff 消失后下一击立即更新。
- 示例：20 生命上限/0 Buff → +10%；60 生命上限/5 Buff → +30%；100 生命上限/10 Buff → +50%。两项各最多贡献 20%，超过各自阈值不再增长。
- 在当前强化后的攻击伤害上额外乘 1.10–1.50，护甲、抗性等仍正常结算。近战、十个新技能、连瞬、飞轮及光束的直接伤害均纳入；旧技能明确由 Boss 发出的无攻击者虚空/火焰分段通过专用入口补算一次。
- 折耳根连击额外虚空按已经增幅的主伤害取 50%，不会二次乘动态倍率或重复增加连击数。玩家自己的武器、无归属环境伤害、蓝火/中毒/凋零/侵蚀等独立持续效果、食物 Boss 帮手、迷你分身和其他 Boss 均不套用此项。

## 主动技能随普攻成长

表中伤害是基础下限，主动命中还会与「当前攻击属性 + 主手对目标的附魔伤害」的 1.5–2 倍取较大值，不会因玩家 Buff 复制或 Boss 成长而落后于普攻基准。混合伤害技能先算总量后拆分，持续被动伤害不机械套用下限；详细范围及青衣三招见 `QINGYI_SKILL_SCALING.md`。

## 调度与安全边界

- 新技能和旧技能交替，四个技能机会内各出现两个新技能与两个旧技能；柠檬猫保留开场优先召唤食物 Boss。
- 柚子、折耳根、柠檬猫普通技能调度冷却 4–5.95 秒；蛋蛋、玄蓝保留自身更快的冷却。蓄力、连瞬、光束与新技能互斥，不叠加开启。
- 新技能方向和落点在蓄力开始时锁定，不追着玩家改预警。离开范围、侧移、利用实心墙可躲避；不破坏方块或清除掉落物。
- 仅攻击存活的生存/冒险玩家，不攻击创造、旁观、其他 Boss 或迷你分身。每段命中必须通过实际 hurt 返回值才施加新技能减益与击退。
- 新技能击退使用玩家击退抗性，发送速度同步。上下判定限制在中心高度 ±3 格；近战沿用原有推动规则。
- 死亡、移除、NoAI、退场、换变体、目标死亡/离线/离开 40 格都会取消新连招。只保存轮换序号，不保存半截施法或静态玩家引用。
- 特效复用已存在的原版粒子/音效及同步施法姿态；没有新增音频文件或资源包依赖。
