# 庄园入场演出无敌修复

2026-09-19：修复演出期间可被玩家扣血的问题。

## 原因

- 入场正确设置了 Invulnerable 和 NoAI，但麻雀及庄园托管 Boss 的 manorHurt 使用自定义扣血，绕过了原版 hurt 内部的无敌判断。
- 麻雀分摊和柚子分身分摊直接 setHealth，原来只在致死时给无敌对象保留 1 血，仍会消耗演出实体的生命。
- 即使最终被原版伤害流程拒绝，原先 hurt 前段也可能先记入受击计数或分摊。

## 修复

- 在 hurt 的最前端统一检查：仍在 HiddenBossIntro 演出中，或带有非终章的 Invulnerable 标记，拒绝一切普通战斗伤害。
- 该检查先于伤害限制、护盾回调、参与者登记、柚子受击计数、分摊和吸收护盾结算；近战、投射物、铁魔法及创造玩家攻击均不扣血、不扣吸收、不触发受击逻辑。
- 演出状态本身也作为依据，避免其他逻辑误清 Invulnerable 后出现保护空窗。
- 受保护的麻雀/柚子分身不参与伤害分摊，不靠保留 1 血冒充无敌，也不替附近 Boss 免费抵消伤害。
- 演出时长、特效和进入战斗的流程不变；完成后正常解除保护并恢复受伤。单独 NoAI 不代表无敌，已有过期冻结状态恢复逻辑保留。
- 管理员 genericKill 仍可移除演出实体；遗留终章成员仍按原规则把伤害送入共享血池，不锁住终章。

## 验证

`gradle -I tools/verification/manor_intro_protection_gametest.gradle build runGameTestServer`

包含真实入场实体、11 变体、近战/箭/铁魔法/创造玩家、吸收护盾、受击计数、分摊、自然演出完成路径、管理员移除和终章共享血池，并复跑双重确认入场测试。
