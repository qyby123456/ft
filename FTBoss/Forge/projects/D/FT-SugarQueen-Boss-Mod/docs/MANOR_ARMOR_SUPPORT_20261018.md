# 庄园 Boss 护甲减半与麻雀百分比回血移除（2026-10-18）

## 行为

- 十一位庄园主战 Boss 的实际护甲减伤读取结果乘 0.5，基础护甲、装备和 Buff 贡献一并计算后减半。例：30 → 15、50 → 25、31 → 15。原版护甲读数是整数，奇数向下取整。
- 仅对 variant 0–8、10、11 的非迷你、非巨型本体生效；不削弱麻雀本身、迷你分身、巨型形态或其他非庄园 Boss。
- 原始护甲属性及装备 NBT 不做破坏性修改，旧存档现存实体重启后同样生效，反复读取不会继续减半。属性检查器可能仍显示原始属性总值，本次调整发生在原版实际减伤读取入口。
- 删除麻雀每 3 秒为被支援 Boss 直接回复最大生命 0.5% 的调用，连 `heal(0)` 都不触发，不能因 Boss 最大生命增加而重新出现巨额回复。
- 保留每 3 秒三个随机 Buff、每 5 秒净化、增益共享、麻雀支援动作/音效及非治疗逻辑。原支援日志不再宣称治疗。
- 不改其他独立回血来源，如 Boss 自身技能、领域回复、已存在或共享的再生效果；不改护甲韧性、附魔减伤、抗性、护盾、技能减伤和限伤。

## 验证

- 5467 条实际 JAR 护甲入口/麻雀 Buff 回调与原始基线对照断言：不同 variant、迷你/巨型、奇偶与大护甲、反复读取、不同最大生命、删除治疗调用、三个 Buff 的数量/等级/时长保留。
- 197 条此前进场 Buff 复制回归、499 条领域客户端/网络/渲染生命周期回归，共 6163 条通过。相关主测试使用 Java 17 再跑一次通过。
- 只修改运行 `EasterBossEntity` 的 `sparrowTick`、支援 lambda，新增一个护甲读取覆写与一个无副作用规则类。所有其他既有方法逐一比较；其余 3318 个 JAR 条目逐条内容保持，包含最新炮台寿命、麻雀减伤、领域和进场 Buff 修改。
- 10 月 13 日旧领域服务端/数值测试带有当时的强化数值，在本次未改原始基线上同样失败（当前领域护甲返回 4 而非旧测试预期 8）。本次不回写旧领域数值、不将这些测试计入通过数；领域服务端 class 和纯规则 class 原字节保留。
- 测试采用实际方法字节码加隔离 Minecraft/Forge fixtures，不等于完整游戏内实战；未自动启动游戏或改存档。

## 工程与部署

- 主工程源码同步：`D:\ft工程文件\FT-SugarQueen-Boss-Mod`；修改前备份 `source-before`，修改后快照 `source-after`。
- 源码已有尚未进入当前 JAR 的 `ManorPhysicalDefense`，本次源码在其最终返回值后再减半，但部署不把该未安装体系一并引入，只调整当前运行版已有的原版护甲入口。
- `PatchManorArmorAndSupport.java` 为方法级增量工具；`build-test.ps1` 编译、合并和测试。禁止把 `classes` 或 fixture 中的实体 class 整体覆盖运行版。
- `deploy.ps1` 只写当前 Forge 1.5.2 实例，以写入当刻 JAR 为基线合并，持有协调锁和文件独占保护，完整备份、写入前后 SHA256 校验、失败回滚。不会使用本次旧基线整包覆盖后续无关改动。
- 备份与安装哈希见 `deployment.json`。不写桌面、fix2 或 NeoForge；重启客户端后生效。
