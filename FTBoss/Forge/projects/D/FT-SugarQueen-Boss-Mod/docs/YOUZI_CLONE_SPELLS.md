# 柚子分身的弱化专属魔法

仅柚子的迷你分身（variant=0 且 mini=true）开放三门已有专属法术：偶像连星、灵偶守御、星偶巡礼。法术 ID 仍为 effigy_volley、effigy_ward、effigy_procession，不新增卷轴或改变玩家法术。

- 伤害采用本体专属法术的基础威力与相同法术属性/配置计算，再乘 35%；持续脉冲也保存弱化后的伤害。
- 每次只施放一门，不继承本体双重施法。正常读条，不享受庄园本体的半读条。
- 首次攻击准备延迟 2～4 秒，并按实体编号错开起始法术；施法完成后间隔 10 秒，同门法术冷却为原来的两倍。
- 仅对 16 格内且有视线的有效敌人施法；目标丢失、死亡、NoAI、变成巨人或其他品种时取消。
- 灵偶守御只保护自身：伤害吸收 I（4 点护盾）持续 4 秒，抗性 I 持续 3 秒。已有更强的继承增益不被主动移除。
- 不开放雪黎自爆分身、其他迷你实体、终章巨人或终章成员。
- 不改变分身数量、生命、寿命、分摊伤害、近战、复制本体增益或再次召唤限制；分身仍不掉落法术卷轴。
- 本体与玩家的伤害、读条、双重施法、卷轴及特效保持不变，分身复用现有专属法术特效。

回归入口：tools/verification/youzi_clone_gametest.gradle；6 项 Forge GameTest 覆盖名单、全部三门施法、单发与间隔、伤害、护盾、掉落隔离、自动调度、读条取消、延迟领域与主人移除。
