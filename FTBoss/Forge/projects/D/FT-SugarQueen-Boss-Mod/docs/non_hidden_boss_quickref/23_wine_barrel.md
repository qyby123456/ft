# 酒魔·酒桶王

实体 id `ftboss:wine_barrel`｜判定箱 3.0 × 3.0｜召唤物「酒引」｜本体系**不会移动**（移速 0），位移全靠技能。
逻辑分布在 `WineBarrelBossEntity.java`（属性 / 冷却 / 状态机 / 光环 / 承伤）与 `boss/ai/BarrelTactics.java`（滚动 / 砸地 / 开塞的命中编排）。
小酒桶在 `entity/SmallBarrelEntity.java`，炮弹在 `entity/BarrelCannonballEntity.java`，分身在 `entity/WineBarrelDecoyEntity.java`。
手里那把**酒桶弩只是外观**（掉落率 0），装填动画只用来给炮弹齐射做预警。

## 3. 火伤回血（重要）

`getMsgId()` 里含 **fire / lava / burn / blaze** 任一子串的伤害，会按该次伤害的 **75%** 给它回血。
回血在 `super.hurt` **之前**结算，且**不管这一下最终是否打中**都回。所以别拿火系当默认输出手段。
它自己 `isSunBurnTick()` 与火焰动画都是 false（不会显示着火，但火焰伤害照吃——只是会被转化成治疗）。

## 7. 承伤

- `hurt()` 走 `BossDamageGate.gate`；58.0 的单次上限与 32.0 的反逃课距离**当前都不生效**（总开关关闭）。
- 500 点全局整下无效规则已取消。
- 流血 / 真实伤害类完全免疫。
- 抗击退 1.0，**完全免疫击退**。
- 没有专属无敌窗口。
