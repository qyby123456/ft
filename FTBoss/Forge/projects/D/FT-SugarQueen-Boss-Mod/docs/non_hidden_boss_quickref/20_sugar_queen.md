# 糖霜女皇（姜饼王）

实体 id `ftboss:sugar_queen`｜判定箱 1.2 × 2.7｜召唤物 `ftboss:sugar_queen_crystal`（糖霜水晶，仅主世界可召唤）。
逻辑分布在 `SugarQueenEntity.java`（属性 / AI / 光环）与 `boss/SugarQueenBoss.java`（阶段 / 召唤 / 冲刺 / 掉落，静态大脑，由 `BossHandler` 每 tick 驱动）。
近战前摇走 `boss/ai/BossMeleeWindup.java`。

## 5. 承伤

- `hurt()` 走 `BossDamageGate.gate`，自身**没有**额外单次上限，也没有自定义无敌帧。
- 58.0 这条单次上限**当前不生效**（限伤总开关关闭）。
- 500 点全局整下无效规则已取消。
- 流血 / 真实伤害类完全免疫。
- **拒绝一切负面效果**（事件层 DENY + 每 20 tick 自查清理）。
- 它打玩家时额外挂：饥饿 II 80 tick + 缓慢 I 60 tick。

## 7. 复制体

玩家重复召唤会生成「糖霜女皇·复制体」：360 血、悬浮、有自己的粉色血条、**不加入静态大脑、不召唤、没有二命**。
它会放 3 + 狂暴层级的铁魔法（再 +1），并在 3 格内近战（冷却 30）。
