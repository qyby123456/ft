# 边牧犬王 benger

实体 id `ftboss:benger`｜判定箱 1.7 × 3.5｜召唤物「牧羊哨」｜**这是第 9 位主 Boss**
逻辑在 `entity/BengerEntity.java`（技能 / 阶段 / 承伤 / 召唤），犬群在 `boss/ai/DogPack.java`，
流血联动在 `boss/ai/BleedLink.java`，震颤在 `effect/TremorEffect.java`。
它**不吃强化包**，但吃人数缩放；**出伤全部 ×2**，下表「实吃」已折算。

### 停用 / 不可达

| 项 | 说明 |

| 自定义小狗 `ftboss:benger_pup` | `summonPups()` 开头就是 `if (true) return;` —— **永远不会生成**；`PUP_CAP = 8` 已是死常量 |
| 「全群一起扑」 | `ACT_PACK` 从不被赋值 → `lockPack`、`DogPack.launchAll`、小狗的扑击都是死代码；狼群扑击现在**不召狗** |

## 5. 承伤

- `hurt()` 走 `BossDamageGate.gate`；它**不在**单次上限表里，反逃课也没登记 —— 但**当前都不生效**。
- 500 点全局整下无效规则已取消。
- 流血 / 真实伤害类完全免疫。
- 拒绝一切负面效果。
- **周期无敌 60 tick / 每 500 tick**：这条走 `isInvulnerableTo`，**没有"无视无敌"的豁免** —— 连 `/kill` 类伤害也挡得住。
- 创造 / 旁观的玩家永远不会被它选为目标。
