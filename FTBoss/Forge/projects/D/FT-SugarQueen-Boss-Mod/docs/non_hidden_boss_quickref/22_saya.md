# 沙耶（茶树古树）

实体 id `ftboss:tea_tree`｜判定箱 1.3 × 2.1｜召唤物「茶树种子」｜**移速 0，不会移动**（扎根）。
逻辑分布在 `entity/TeaTreeBossEntity.java`（属性 / 主循环 / 攻击 / 承伤 / 二命 / 掉落）、
`boss/ai/TeaTactics.java`（补员 + 茶心汲取）、`boss/ai/SayaBuds.java`（茶芽庇佑）、`entity/TeaMinionEntity.java`（小妖 / 守护茶芽）。

**她不参与 Boss 强化包**（与故障机器人同），只吃人数缩放。
她的所有出伤还会被「非隐藏 Boss 伤害 ×2」钩子放大一次（`NonManorDamageX2.java`），下表已折算。

## 3. 茶芽庇佑（核心机制）

| 项 | 值 |
|---|---|
| 数量 | **5 株**守护茶芽 |
| 单株血量 | 40.0（20 血 ×2 倍） |
| 生成位置 | 本体周围 4.5 ~ 7.0 格环形 |
| **效果** | **任意一株还活着 → 本体完全免伤**（在伤害门控之前直接 `return false`，一点血都不掉） |
| 破盾条件 | 必须把 5 株全部清掉 |
| 破盾表现 | 信标失效音 + 玻璃碎音 + 45 个暴击粒子 |
| 茶芽给本体的增益 | 每 40 tick 刷新 再生 II + 抗性提升 II 各 140 tick |
| 触发时机 | 进入二阶段时；二命重生后再来一轮 |
| 备注 | 茶芽不能被汲取，也不占小妖名额 |

## 4. 二命

首次致死时拦截死亡：血量回 **102.0**（= `最大生命 × 0.3`，按 340 基准），清空自身效果、重置根刺与飞沫冷却，
并**重新召出 5 株满血守护茶芽**（等于要重新破一次盾）。**每只实例仅一次**。
这次死亡**不给掉落**，也不计入连死怜悯。

## 6. 承伤

- **先查茶芽盾**：任一茶芽活着就完全免伤（连击退都不吃）。
- 破盾后走 `BossDamageGate.gate`；56.0 单次上限与 40.0 反逃课距离**当前都不生效**。
- 500 点全局整下无效规则已取消。
- 流血 / 真实伤害类完全免疫。
- 拒绝一切负面效果，并每 20 tick 自查清理。
- 本模组阵营实体之间的友伤被取消 → 她的尖牙与法术伤不到自己的茶芽。
- 没有额外无敌窗口。
