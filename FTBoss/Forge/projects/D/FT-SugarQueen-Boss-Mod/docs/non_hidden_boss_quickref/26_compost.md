# 炫彩答辩超人

实体 id `ftboss:compost_boss`｜判定箱 1.6 × 3.4｜召唤物 `ftboss:compost_summon`（仅主世界）
逻辑集中在 `entity/CompostBossEntity.java`（全部技能）、`entity/RainbowPoopEntity.java`（投射物）、`boss/ai/PoopCurse.java`（毒咒）。

## 6. 承伤

- `hurt()` **只调 `nullified()`**，不调 `gate()` —— 所以它**连流血/真伤免疫都没走到**，那套关键字表对它不生效。
- 500 点全局整下无效规则已取消。
- **无单次上限、无连击递减、无反逃课**（总开关关闭，而且它本来也没接那条路）。
- 拒绝一切负面效果 → 后果是它自己那个「吸收减益换增益」的机制（每 40 tick 数减益数量、换成增益，最多 V 级）**永远不会触发**。
- 本模组阵营互伤被取消，自伤也被取消 → 自己的沼气爆炸、投射物、召唤物都伤不到它。
- 没有专属无敌窗口，只有原版受伤帧 + 9 tick 受击动作。
