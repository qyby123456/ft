# 非彩蛋 Boss 技能与动作同步

## 范围

本次涉及糖霜女皇（姜饼人国王）、屠夫、沙耶、酒桶王、鼠群、故障机器人、炫彩答辩超人、苹果 Boss、benger。彩蛋 Boss 的源码、石像交易、掉落表和图腾二阶段规则不在本次修改范围内。

## 当前行为

| Boss | 动作与技能配合 |
|---|---|
| 糖霜女皇 | 近身权杖砸击在第 5 tick 命中，完整播放 14 tick；吟唱不再被受击动作覆盖；抬杖结束转入持续吟唱姿态。 |
| 屠夫 | 抬手 6 tick、下挥 2 tick，第 8 tick 命中，18 tick 后结束收招；重复的近身保险攻击不会刷新正在进行的挥击。 |
| 沙耶 | 根刺抬手 12 tick，沿起手方向逐段生长；毒雾前摇 8 tick，显示绿色路径，横移出起手瞄准点可以躲避；近身轻推第 6 tick 生效。原生技能与铁魔法不同时抢动作。 |
| 酒桶王 | 滚动前锁定朝向并显示路线；停滚后在砸地动作第 10 tick 结算，砸地完整播放 24 tick；喷酒、炮弹、火球、召唤在开塞第 10 tick 释放，完整动作 50 tick；6.5 格预警环和砸地判定一致。 |
| 鼠群 | 新增 10 tick 撕咬（第 5 tick 命中）和 18 tick 呼唤（第 9 tick 补充鼠群），命中才回血；大小鼠身份同步到客户端，正确选择模型与尺寸。 |
| 故障机器人 | 球种施法、召唤、阶段、回想、光束和衰弱均同步；成熟球排队，不覆盖上一颗待释放技能；近战/基础攻击延迟结算，黑球在第 16 tick 释放并保留收势；光束按 8 秒蓄力、3 秒引导映射现有动画。 |
| 炫彩答辩超人 | 炮击、抛射、投弹、弹幕、毒咒、燃气蓄力和俯冲互斥起手；炮击类对齐第 16 tick，燃气对齐第 40 tick；阶段变化或目标失效取消待释放攻击；移除没有技能结算的空抬炮。 |
| 苹果 Boss | 动作状态同步，补接普通攻击动画；分身、巨蛆及普通虫群在召唤第 19 tick 分别释放，不再提前生成后又额外召一波普通虫群。 |
| benger | 撕咬、横扫、飞扑、长嗥等现有动作状态同步；连续同名动作可以重新播放；行走/奔跑按客户端移动速度区分。 |

## 实现约束

- `BossActionState` 通过实体同步数据发送动作名、开始世界时间、时长、序号；不依赖客户端读取服务端字段，也不随每帧渲染递增时间。
- 动作序号变化时重置 GeckoLib 控制器；动作起手不额外插入过渡延迟，结束后使用短混合。
- `BossMeleeWindup` 只在命中帧结算一次；目标死亡、移除、换维度、切创造/旁观、超距、失去视线时取消命中。
- 受击不覆盖正在执行的主要动作。普通近战仍使用原来的伤害和命中事件链；没有统一抬高伤害或生命值。
- 技能粒子与声音使用服务端同步入口，没有新增网络包、贴图或音乐文件。
- 屠夫动画代码和生成器同步；鼠群新增动作只使用大小鼠共有的 `body`、`head` 骨骼。

## 自动验证

设置 `JAVA_HOME` 为项目 JDK 17 后执行：

```
node tools/model3d/verify_boss_actions.cjs
node tools/model3d/validate_anim.cjs --all --json
node tools/model3d/validate_anim.cjs src/main/resources/assets/ftboss/geo/big_rat.geo.json src/main/resources/assets/ftboss/animations/rat.animation.json src/main/java
node tools/model3d/validate_anim.cjs src/main/resources/assets/ftboss/geo/small_rat.geo.json src/main/resources/assets/ftboss/animations/rat.animation.json src/main/java
```

动作契约检查使用隔离的 Minecraft/GeckoLib API 替身编译运行实际的动作同步及近战调度类，验证计时、重复施放、死亡与失效目标取消；这不是启动 Minecraft 的集成测试。

## 游戏内验收

- 重启客户端后，逐只召唤上述 Boss；连续攻击 Boss，确认技能不会被受击动画切掉。
- 观察酒桶王的预警路线、落地冲击环和开塞喷射；确认碰墙结束冲撞，收招期间不偷偷叠放炮弹。
- 在屠夫、鼠群、女皇抬手时后退，确认脱离范围后不会仍被命中。
- 横移躲沙耶毒雾、绕开根刺路线；观察两只沙耶同时施法时姿势互不串用。
- 观察机器人不同球种的手势、连续球释放、光束转为落地衰弱；观察答辩超人升阶段时旧技能取消。
- 在中途进入跟踪范围、多人联机和低帧率下复查动作。离线预览与编译不能代替这一项。
