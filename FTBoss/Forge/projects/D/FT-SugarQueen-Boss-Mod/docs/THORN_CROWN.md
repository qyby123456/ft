# 荆棘头冠

- 物品：`ftboss:thorn_crown`，名称「荆棘头冠」，史诗品质，头盔栏。
- 来源：沙耶第二条命耗尽后必掉 1 顶；保留原有武器、石像与材料掉落。无合成配方。
- 防具：护甲 4、护甲韧性 3、击退抗性 0.1、耐久 528、附魔值 18；铁砧用藤蔓修复。
- 荆棘：受到实际近战伤害时，对直接攻击者造成 `clamp(实受伤害 × 25%, 2, 6)` 点荆棘伤害；每位佩戴者独立冷却 10 tick。伤害仍受目标减伤与无敌帧影响。
- 不反击已取消或被完全吸收的伤害、荆棘、爆炸、投射物、环境伤害、友方和禁止 PVP 的玩家；无反伤递归。不额外损耗耐久，普通受击仍消耗护甲耐久。
- 血色视界：仅检查当前本地玩家的头盔栏，中心约 19% 红色遮罩、边缘约 51% 深红遮罩；不依赖光影雾效，不覆盖快捷栏与血量 HUD。不闪烁、不改 FOV；摘下、死亡、旁观或切到其他实体视角时立即消失。

## 外观生成

`node tools/model3d/gen_thorn_crown.cjs <输出目录>` 同时产出立体物品模型、护甲 Java 模型、两份 64×64 图集、血红视野贴图与预览几何。只生成本物品，不改其他模型。

- `<输出目录>/assets/ftboss/` 对应 `src/main/resources/assets/ftboss/`。
- `<输出目录>/ThornCrownModel.java` 对应 `src/main/java/net/farmingtales/ftboss/client/model/ThornCrownModel.java`。
- `<输出目录>/thorn_crown.geo.json` 仅供离线预览，不作为游戏资源打包。
- 护甲与物品共用同一几何规格。头围内缘距离头中心 4.7 模型单位，给原版头部和皮肤帽层留出余量。

## 游戏验收

1. `/give @s ftboss:thorn_crown`，检查物品图标、中文说明、右键装备、头盔槽、创造物品页。
2. 穿戴后查看属性与第三人称头冠；切换第一/第三人称、GUI 缩放与光影，检查血红视野。摘下、死亡、重生、退出重进后不应残留遮罩。
3. 分别承受僵尸近战、骷髅箭、摔落、盾牌完全格挡和吸收之心完全吸收：只有实际近战伤害触发反击。
4. 双方戴冠互打，确认不会循环反伤；友伤关闭时不应伤及队友。
5. 击败沙耶第一条命不掉头冠；最终击败掉 1 顶，原武器与石像仍在。
6. 藤蔓修复与原版头盔附魔可用；仅持在手上或放在背包中没有防御、反伤或血红视野。
