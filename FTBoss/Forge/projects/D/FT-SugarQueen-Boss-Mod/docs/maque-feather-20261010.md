# 麻雀飞羽：频率与 5 秒禁疗

本次只调整 `ftboss:feather_fan`（千羽散华）的使用入口和命中效果，不重做模型或动画。

## 行为

- 法术的默认冷却从 16 秒缩短为 8 秒。已存在的铁魔法配置覆盖仍按该模组自身的配置优先级处理。
- 支援麻雀获得独立的飞羽施法入口：可战斗状态建立后约 2–3 秒尝试首次施法，之后两次起手至少相隔 8 秒。
- 使用同一场战斗、同一召唤者、32 格内非迷你 Boss 当前正在攻击的合法敌人；敌人须在麻雀 24 格内且可见。
- 不给麻雀设置原版攻击目标，不启用近战追击，不替换其治疗、净化、共享增益或代施法逻辑。
- 正在播放技能、治疗施法或替其他 Boss 代施法时不重叠起手。目标死亡、换目标、离开范围、遮挡、施法者失效或禁用法术时取消。
- 服务端读条期间更新瞄准，释放时继续走原有五路射线、墙体裁剪、友军保护、每次施法单目标一次伤害和原有流光特效。
- 成功命中且敌人存活时附加可见 `ftboss:heal_ban`，持续恰好 100 tick（5 秒）。敌人拒绝伤害时不施加。
- 再次命中把较短的禁疗刷新至 5 秒，不叠加时长，不削短已有的 30 秒或无限禁疗，不降低已有禁疗等级。
- 玩家通过卷轴/法术书释放飞羽同样使用命中禁疗分支。其他法术不新增禁疗。

## 工程范围

- 新增 `MaqueFlightRules` 与 `MaqueFeatherCombat`，通过 Forge 自动订阅 tick、卸载和停服事件。
- 保留原有饰品 `MaqueFeatherRules`；飞羽战斗使用不同的规则类，不影响祝福羽毛、手持治疗、物品冷却或掉落。
- 部署时只在最新 JAR 的 `ManorSpellEffects.hurt` 返回值接入命中钩子，只修改 `ManorSpellRules$Kind` 初始化中飞羽的一个冷却参数。
- 中英文只更新飞羽说明键；不使用旧整包覆盖当前版本，所有其他条目逐项 SHA256 比对保持不变。
- 正式目标仅为当前 Forge 1.5.2 的 `mods/qys-bosses.jar`，不写 NeoForge、旧测试实例或桌面历史成品。

## 验证边界

离线验证包括施法时间轴、失效取消、活动数量上限、冷却及重叠保护、禁疗刷新与长时状态保护，实际命中方法字节码的隔离执行，Forge 事件注册、当前 JAR API 引用和共享类无关方法保留检查。打包使用 JDK `jar --update`，随后检查 Forge ZIP 规则、JDK 本地头流式读取、CRC 与部署后逐项哈希。
