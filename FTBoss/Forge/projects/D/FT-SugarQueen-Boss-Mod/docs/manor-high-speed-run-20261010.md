# 庄园 Boss 高移速跑步动作（2026-10-10）

## 范围与动作

- 当前 `EasterBossEntity.MANOR_VARIANTS` 的 11 位庄园 Boss：柚子、蛋蛋、朵拉、功底、柠檬猫、青衣、文玄蓝、折耳根、紫菜、雪黎、祁崽。文玄蓝分别检查持枪与白轮，共 12 套持握配置。
- 依据实体实际水平位移判断跑步，不依据属性面板上的移速；进入阈值 0.180 格/tick（约 3.6 格/秒），退出阈值 0.145 格/tick（约 2.9 格/秒），带速度滤波、进入/退出迟滞和权重过渡。
- 连续 3 tick 达到进入阈值才进入跑步；连续 4 tick 低于退出阈值才退出。步频随移动距离推进，上限限制高速抽搐，异常位移/传送/时间跳变重置状态，同 tick 重复渲染不重复推进。
- 左右腿交替、受控前倾、肩髋位置联动。双枪/飞轮/厨具双持稳定握持，重镰、三叉戟、法杖和单手武器分别设置持械手摆幅，空手侧允许自然摆臂。
- 功底使用当前实际渲染的 17 骨骼 actor frame，保持 IK、头部朝向与右腕/黑切握点一致；不是只修改未被自定义 renderer 使用的普通玩家腿骨。
- 低速保留原动作；受击、攻击、施法、技能、登场、隐藏、离地、游泳、骑乘、睡眠、禁用 AI 和死亡等状态由原人物动作链接管。
- 麻雀不是庄园轮换 Boss。本轮不替换其浮空/支援/跑步动作，也不修改飞羽频率、跟踪飞弹、流光拖影或 5 秒禁疗。

## 并发整合与源码

正式包在制作过程中新增了 `RunAnimator` / `RunGait` 旧跑步层和蛋蛋专属跑步层。本轮不以制作开始时的完整旧包覆盖正式包。

1. 在最新正式 JAR 中，仅合并 `EasterBossModel.setupAnim` 的最终跑步调用与 `GongdiHumanoidRenderer.setup` 的 frame 调用。
2. 对既有 `RunAnimator.prepare/apply` 增加庄园变体提前返回，避免两套通用跑步同时叠加；非庄园分支尤其麻雀保留全部原方法内容。
3. 各角色已有施法、普攻、登场与专属动作的代码和挂接顺序全部保留。通用跑步最终执行，保护状态不改任何姿势。
4. 主源码同步至 `src/main/java/net/farmingtales/ftboss/client/manorrun/`，包含新层与兼容旧层的 Mojmap 源码，并同步主 `EasterBossModel` 入口。
5. 当前主工程不具备正式包所有历史人物装饰器与功底原生 renderer 的完整源码，因此本轮交付以方法级增量桥为权威重现方式，不声称一次主线 Gradle 全量构建可以重现整个正式包。隔离工程保留 SRG 编译源码、方法补丁、实际完整人物链探针和安全部署脚本。
