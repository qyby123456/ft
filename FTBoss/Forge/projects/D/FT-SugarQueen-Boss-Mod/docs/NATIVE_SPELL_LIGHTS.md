# 70 门法术的 Iron 原生光线适配

> 当前状态（2026-09-18 高压贯星崩溃修复）：高压贯星和离子轨道炮已停用 Soulfire Ray，改用 Trace；详细根因、顶点复现、回归与交付见 `PRESSURE_LANCE_CRASH.md`。下文末尾为光效初次开发的历史验收记录，不代表当前修复状态。

适配版本：Iron's Spells 'n Spellbooks `1.20.1-3.16.3`。本轮逐门核对非庄园 37 门、庄园 33 门，共 70 门注册法术。结论为 **23 门光线适配 + 3 门范围效果点缀，另外 44 门保留原立体表现**。

只修改表现，不改伤害、治疗、魔力、等级、冷却、掉落、卷轴与 AI。所有原生粒子均直接调用已安装 Iron 模组的实现，不复制其素材、不替换其 jar，也不生成带伤害的 Iron 实体。

## 实际 API 核对

- `TraceParticleOptions(destination, color)`：第一个向量是目标坐标，第二个是 RGB 0–1。`TraceParticle` 是向目标移动的短光痕，不是一颗就能连接全程的长激光。本轮在实际线段内铺设 2–12 个光痕，并保留枪尖、羽枝、灵偶、加速环和末端环等专属几何。
- `ZapParticleOption(destination)`：真正的原生闪电折线，用于雷电连锁和静电网。原生渲染器还会自行改变亮度，因此保留其原生闪电风格，不保证与自定义纯色线完全同色。该版本原生 Zap 网络编码会将坐标缩至 0.1 格精度；本轮通过已有双精度特效包传端点、在客户端直接构造 Zap，绕过其有损编码，并非修改 Iron 原文件。
- 高压贯星、离子轨道炮改用蓝青色 `TraceParticleOptions`。Iron 3.16.3 的 Soulfire Ray 在粒子顶点写入时会抛出 `Not filled all elements of the vertex`，已禁止从本模组创建；详见 `PRESSURE_LANCE_CRASH.md`。
- `SIPHON_PARTICLE`：使用原生血液汲取粒子搭配红色 Trace，形成血液流动。血线缝合的装饰流向从目标返回施法者，其余沿原有连接方向。
- 没有直接生成 `SunbeamEntity`：它包含原有范围伤害和预热逻辑，不适合仅为外观添加，否则会重复结算。
- 没有直接生成 `RayOfFrostVisualEntity`：它的实体生命周期和朝向绑定原来的冰射线，不能直接等同于本模组瞬发穿刺枪。冰枪/霜针使用冰色 Trace，保留已有冰晶枪尖。

## 接线、退化与性能

- 复用既有特效 S2C 包，不新增网络字段或包 ID；仅修改客户端如何解释已有法术的光线阶段。庄园第三法术的新增目标线也由服务端实际伤害成功路径发送。
- 客户端二次按实心方块裁剪线段；长光束和雷弧包围盒覆盖整条路径，避免只有起点在视野中才能显示。
- 在处理包时创建粒子，不在每帧渲染时重复生成。单条 Trace 最多12个，粒子减少设置最多6个；每客户端 tick 有加权预算，不再创建 Soulfire Ray 或其附带粒子。
- 原生粒子确认创建成功后，才隐藏原有简单长直线；枪尖、羽毛、灵偶、末端圈和线圈仍保留。预算不足、粒子最少模式、原生 provider 不可用或远坐标精度不足时保留自定义线作为兜底。
- `Trace` 的目标是 float：当转换误差超过1/64格时不使用它，避免远坐标光线歪斜；高压贯星和离子轨道炮也遵守此保护，自动保留原有完整几何光束。Zap 的目标使用 double。
- 死亡、退出、维度切换沿用原有模型清理；原生粒子由游戏粒子引擎管理，寿命 8–12 tick，退出世界由引擎清理；本桥接器不会长期持有旧世界。
- 原生桥仅在客户端且已加载 Iron 时调用；没有 Iron 时不加载其粒子类，仍有原自定义表现。调试可添加 JVM 参数 `-Dftboss.disableNativeSpellLights=true` 对比旧表现。
- 本轮没有改新法术注册表、伤害、冷却或卷轴模型。保留主工程其他并行任务的更新。
