# 柠檬猫：一次性献祭继承

更新日期：2026-09-21。适用 `EasterBossEntity` 的柠檬猫（variant 4），不适用迷你分身或终章巨人。

## 触发与范围

- 献祭前，每次「喊帮手」从糖霜女皇、屠夫、沙耶、酒桶王、鼠群中抽取 **两位不同 Boss**；先回收旧批，不无限累加。
- 常规情况下，场上实际存活的自有助战 Boss 达到 **2 只**后，在下一次原生技能判定时优先施放献祭；正常的“喊帮手”仍会让两位助战至少留到下一次技能判定，不在召唤当刻自动删除。
- **半血保底**：若生命降到最大生命的 **50% 或以下**时仍未成功献祭，会立刻触发。场上不足两位合格助战时，先回收不完整旧批并召唤两位不同食物系 Boss，随后在**同一 tick**完成献祭；若本来已有两位，则直接献祭，不等待技能冷却或下一次原生技能。
- 演出冻结、转场无敌、迷你/巨型或死亡状态不会生成保底祭品；恢复正常战斗后立即补触发。若实体生成失败导致不足两位，本次不消耗唯一献祭机会，后续 tick 会继续尝试。
- 门槛只数已登记、当前已加载且活着的自有 Boss；重复 UUID 不重复计算，生成失败、被击杀、失去归属时不能虚凑第二只。不足两只则不消耗献祭次数，之后正常召唤轮换可重新召齐两只。
- 只献祭同维度已加载、符合归属的助战 Boss；**麻雀、迷你分身、茶芽、小鼠、小酒桶不计数也不当祭品**。不影响野生生物、玩家或其他召唤者的队伍。
- 助战 Boss 退场仍执行原有的随主清理，小怪可能随同清掉，但不会因此被计入祭品或继承数量；不修改这套原有生命周期。
- 消耗用 `discard()`，不触发击杀掉落、经验、Boss 死亡奖励和二阶段复活。
- 没有召唤物时不消耗次数；冻结、演出无敌、死亡期间不能献祭。
- 献祭带短施法动作、召唤物向本体汇聚的末地烛粒子、图腾爆光与附近玩家提示。

## 一次性与持续时间

- 每个柠檬实体一生只能成功献祭 **一次**。
- 技能继承持续 **直到柠檬死亡/被移除**，沿用 `INFINITE_UNTIL_DEATH = true`；不改回旧版 30 分钟。
- 一次性标记、已获得的能力种类、绝对游戏时间截止点、强化与召唤轮换存入实体数据。保存、退出重进、卸载区块不会把一次性次数或时长重置。
- 从献祭成功开始，之后每次「喊 Boss 助战」只生成 **一只 Boss**。每只直接助战真正死亡时计 1 次；累计击败 **3 位**后永久停止召唤，原召唤槽改为在翻锅与借招间轮换。保存重载不会重置计数。超时、换批、转场或随主 `discard()` 不算“被击败”。
- 同种能力只继承一份；重复献祭或以后召出的新 Boss 不会补技能，也不会延长计时。

## 能力对应

只继承实际被献祭的类型，不是无条件给齐五类。召唤出来的女皇、屠夫按其助战复制体实际具备的战斗能力处理，不创建隐形 Boss、不转移战役掉落/复活/全局战斗管理器。

| 来源 | 继承的战斗能力 |
|---|---|
| 糖霜女皇助战 | 悬停追击、甜蜜/甜蜜之心光环、命中饥饿与减速、原版铁魔法进攻池、完整 5 个女皇专属铁魔法 |
| 屠夫助战 | 肉腿连击、交替强化命中、全套命中减益和强化增益、按实际伤害计算的吸血 |
| 沙耶 | 9–11 道根刺、茶毒飞沫、半血技能提速、焕新光环、随机增益轮换、生命成长、茶芽召唤/汲取、原版进攻/护体法术池、完整 7 个沙耶专属铁魔法；**不继承五株守护茶芽的完全免伤护盾，柠檬始终可受伤** |
| 酒桶王 | 3–5 发酒桶炮弹、火球、滚动冲撞/砸地/开塞喷射、酒雾减益、分阶段酒增益、火焰受伤回复、小酒桶/可选啤酒人召唤、原版火系法术池、完整 5 个酒桶专属铁魔法 |
| 鼠群首领 | 鼠潮召唤、召唤回血、奶酪增益、命中回血与随机减益；新小鼠的公共血池归柠檬，不依赖藏一只鼠王 |

只吸收对应的技能档案，**不复制祭品身上的有益效果**，保留柠檬已有的异常免疫增益检测。生命/攻击等基础属性不直接求和，原有庄园血池、奖励和图腾规则不变。

## 并行与清理

- 柠檬原有翻锅、借招、庄园法术继续保留；新增继承能力使用独立计时。
- 继承的 Boss 专属铁魔法复用独立预警/施放通道，完整技能池轮换，不占庄园法术槽。
- 原版 Iron 法术使用局部 `MagicData`，带前摇与持续施法生命周期，并继续遵守原版法术的概率/共享间隔限制，不覆盖原有技能状态。
- 继承召唤物带来源和截止时间，继承结束会回收；之后正常「单只 Boss 助战」及其召唤物不被这次到期清理误删。
- 继承结束时停止主动/被动和继承施法、回收继承小怪、清理继承技能产生的增益；保留原本就有的独立增益。柠檬不继承沙耶的完全免伤护盾。当前继承不按 30 分钟超时，已对敌人造成的伤害不会撤销。
- 死亡/退场会提前清理。卸载只取消内存中的未完成施法，保留已保存的一次性标记和截止时间。
- 为避免长期堆怪，继承酒桶小队上限 8；鼠群沿用 12/16 上限，每批最多补 6；茶芽沿用 3/5 编制。

## 验证入口

`tools/verification/gametest/LemonSummonSacrificeGameTests.java`：真实两只不重复召唤、下一原生技能自动献祭、未达标/失效实体/外来队伍/麻雀/小怪隔离、取消生成、不复制 buff、继承档案、献祭后单只助战、真实死亡去重计数、三次封顶及存档重载。

`tools/verification/check_lemon_summon_sacrifice.cjs`：计数/召唤/优先献祭接线、三位助战死亡封顶、死亡去重、停止召唤后的技能替换，以及“沙耶继承不能让柠檬完全免伤”；并复跑既有免疫增益与献祭特效校验。此检查已接入 `tools/verify_project.cjs`。

使用隔离工程运行：`gradle -I tools/verification/manor_integration_gametest.gradle clean build runGameTestServer --rerun-tasks`。

服务端 GameTest 不代替客户端画面、音效与整合包实战验收。
