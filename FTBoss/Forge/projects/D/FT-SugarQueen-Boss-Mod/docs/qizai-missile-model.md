# 祁崽星梭飞弹

独立代码网格模型：`QizaiMissileModel`。水晶协同飞弹采用苍蓝晶核，弹幕追踪飞弹采用紫晶晶核；两者共用银色四翼、镶金护甲与八面尖晶弹头。普通非追踪星矢保持原样。

## 渲染

- 实体长约 1.38 格、翼展约 0.71 格。尖端沿局部 +Z 轴，以插值后的投射物朝向转动，滚转独立于飞行方向。
- 弹体为独立、不透明的深度写入通道，保留明暗切面，不再用半透明菱形叠成亮团。固定弹体网格缓存，每枚 120 个四边形。
- 后方旋转的断续符环、双股细尾丝与脉动锥形尾焰共 76 个四边形，使用现有深度测试透明通道，不写深度、不穿墙。不使用堆叠粒子或屏幕贴片代替弹体。
- 只修改两个投射物渲染入口，不改实体同步、追踪、碰撞箱、弹数、伤害、护盾或传送逻辑。模型从实体渲染入口直接调用，不依赖新增网络包或贴图缓存。

## 验证

`checkQizaiMissileModel` 对两套配色检查完整 0–90 tick 动画的 722 个采样帧，包括有限顶点、透明度、面面积、尺寸、尾焰方向、面数预算及两个渲染入口。输出 `build/verification/qizai-missile/preview.png`，预览使用运行时同一份网格，分别模拟不透明深度写入与透明深度测试，不是游戏截图。

随构建执行现有祁崽技能、水晶、飞弹碰撞、弹幕追踪及战斗清理的服务器 GameTest。客户端视觉还需在实际整合包中观察，尤其是第三方光影与高速镜头下的效果。
