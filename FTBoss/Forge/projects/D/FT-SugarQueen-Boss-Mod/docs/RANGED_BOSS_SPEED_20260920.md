# 远程 Boss 移速下调

- 范围沿用 `EasterBossEntity.RANGED`：朵拉（2）、文玄蓝（6）。其它会施法的 Boss 不因此归入远程型。
- 两位的基础移动速度从实际生成后的 0.33 下调至 0.165，减少 50%。追击、后撤及其它依赖移动速度属性的寻路同步变慢。
- 仅修改变体初始化中的基础移速。近战 Boss、伤害、攻速、法术频率、射程、寻路倍率、瞬移和技能位移参数均不改。
- 速度药效和其它属性修饰符保留；在相同增益下，有效移动速度为修改前的一半。
- 修复只改 `createAttributes()` 不生效的问题：`setVariant()` 之前总会把基础速度重置为 0.33，现在远程变体使用独立常量 `RANGED_MOVEMENT_SPEED`。
- 旧存档加载时先恢复属性，再执行 `setVariant()`，因此已有远程 Boss 在重新加载后也使用新速度，不需要重新召唤。重复加载或切换变体不会叠加减速。
- `RangedBossSpeedTests` 覆盖分类范围、变体切换、旧存档迁移、重复保存加载和速度增益保留。
