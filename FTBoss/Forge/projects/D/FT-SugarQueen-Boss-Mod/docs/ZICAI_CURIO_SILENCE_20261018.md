# 紫菜：攻击随机沉默一件玩家饰品 5 秒

## 行为

- 紫菜主战本体（variant 8、非迷你/巨型）对生存玩家造成有效伤害后，从该玩家已装备的 Curios 功能槽随机选一件，沉默 100 tick（正常 5 秒）。创造/旁观、取消伤害、零伤害及其他 Boss 不触发。
- 近战、紫菜归属的投射物以及 `ManorMercy` 显式归属技能统一接入最终伤害事件。同一紫菜对同一玩家在同一游戏刻内的多段伤害只抽取一次，不会一招拆三段就禁用三件。
- 未被沉默的饰品与仍在沉默期的饰品共同参与随机；选到已经沉默的同一件时，只刷新至当前时间后 5 秒，不累加为 10 秒。连续攻击可以分别沉默多件。
- 只选已佩戴功能饰品，不选主手、副手、护甲、背包或 Curios 的纯外观槽。没有佩戴饰品则安全跳过。
- 受击后显示被选中饰品名称与 5 秒提示。

## 真正停用与恢复

不是只添加物品冷却。被选中的物品及全部 NBT 暂存到玩家 `PlayerPersisted.ftboss:ZicaiCurioSilence`，其功能槽临时置空；Curios 通过正常装备变更移除属性和佩戴状态，不再 tick 该饰品，通过装备查询触发的主动/被动也不再将它视为已佩戴。已经独立施加到玩家身上的效果不做无差别清除，避免误删其他来源的增益。

100 tick 到期归还原槽，保留耐久、附魔与自定义 NBT。封印期间该槽禁止重新装备其他物品。死亡事件的高优先级恢复先于 Curios 死亡掉落结算；退出、登录、重生也进行恢复。槽位消失/被外部模组占用时尝试归还普通背包；背包满则保留在持久化托管数据中，每刻重试，不删除、不强制掉地、不替换玩家其他物品、不复制物品。跨维度用主世界时钟，不会因维度时间差延长封印；时间回退或异常旧期限会恢复。

## 源码与构建

主工程：`D:\ft工程文件\FT-SugarQueen-Boss-Mod`。新增：

- `src/main/java/net/farmingtales/ftboss/boss/ai/ZicaiCurioSilence.java`
- `src/main/java/net/farmingtales/ftboss/util/ZicaiCurioSilenceRules.java`

`build-test.ps1` 使用现有 Forge 1.20.1 官方映射依赖编译 Java 17 字节码，再根据工程 TSRG 和真实继承关系转换为运行时 SRG 名称。验证时对测试夹具做相同转换，并加载候选 JAR 里的实际运行时类，不用重新编译的伪业务实现代替实际类。

`PatchZicaiSilence` 只新增 handler、内部记录与纯规则共三个 class，依靠 Forge 自动订阅注册，不改主注册类、Boss 大类或任何已有资源。所有原 JAR 条目逐字节验证相同，完整保留此前武器攻击/技能翻倍、Boss 护甲、麻雀支援、进场复制 Buff、领域与其他并行修改。

`VerifyZicaiSilence` 覆盖随机槽选择、整整 100 tick、刷新、多段去重、功能槽锁、饰品 NBT、恢复幂等、断线重登持久化、死亡恢复、槽位缩减、背包满重试、Boss 归属与排除条件；另验证 Forge 注解订阅和所有原始条目不变。所有新类通过 ASM BasicVerifier 和 Java 17 `-Xverify:all`。

部署脚本使用三把共享部署锁，先备份当前 JAR，再以该备份重新合并/验证，调用主工程受保护部署脚本，核对预期哈希并拒绝在游戏运行时安装。仅写当前 Forge 1.5.2，不写桌面、fix2、NeoForge 或存档。部署结果、备份及哈希在 `deployment.json`。

如果检查时游戏仍在运行，则只保留已验证的 `candidate.jar`，不覆盖实例 JAR；此时状态记入 `build-status.json`。退出游戏后可用 PowerShell 7 运行本目录 `deploy.ps1 -Target 'C:\Users\YOUR_USERNAME\AppData\Roaming\.minecraft\versions\FarmingTales_ForgeⅡ v1.5.2\mods\qys-bosses.jar'`，脚本会重新备份当前实例并合并，不直接覆盖更新期间出现的其他修改。

本验证为离线最小夹具和字节码测试，未启动游戏，不代表所有第三方饰品的实机兼容性已验收。实测可佩戴两件不同饰品与紫菜交战，观察每次命中后随机一件停用、5 秒后归还，并检查死亡/重登后的物品完整性。
