# 雪黎女仆与粉碎轮修复

- 粉碎轮仍沿用 `create:crush`（缺失时回退物理）、原伤害和持续时间，只在这次伤害结算期间取消受害者的受伤击退；不清空玩家原本的移动速度，不影响普通攻击的击退。
- 护法按召唤成功的 UUID 追踪，不再用雪黎周围 128 格是否扫描到来判定存活。区块卸载或暂未加载不视为死亡，确认生命值归零或实体被销毁后才移除。
- 女仆名单、最后位置和召唤冷却写入雪黎存档，重载期间保留护盾，并尝试加载掉队女仆最后所在区块以重新接管。旧存档中的已加载护法仍能按所属雪黎恢复。
- 每 10 tick 检查女仆；距离雪黎超过 16 格、卡墙或缺氧时，寻找雪黎附近安全落点传送，停止旧寻路并清除摔落距离。没有安全落点时保留原位置，不因此破盾。
- 护法另存直接召唤者 UUID，避免雪黎作为其他 Boss 的助战时，被战斗根归属覆盖。普通女仆和其他雪黎的女仆不参与这只雪黎的护盾或清理。

回归测试：`tools/verification/gametest/XueliGuardGameTests.java`，通过现有 `manor_integration_gametest.gradle` 的 `runGameTestServer` 运行。
