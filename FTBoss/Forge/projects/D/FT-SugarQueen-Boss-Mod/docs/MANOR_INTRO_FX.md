# 甜苹果庄园 · 立体召唤仪式

## 时间轴

沿用 `ManorIntroTimeline.DURATION_SECONDS = 46`，与现有《庄园·双轨坦克曲》开头约 46 秒前奏同步。台词仍在 0、10、20、30、40 秒发送；46 秒结束开场、解除既有演出保护、进入战斗，不调整音乐或 Boss 数值。

| 时间 | 演出 |
|---|---|
| 0–8 秒 | 厚度金属基环成形，十一枚主战成员立体徽章逐一显现，苹果徽饰升起 |
| 8–24 秒 | 双扇庄园门凝聚，彩色徽章绕行，苹果徽饰转动并上升 |
| 24–36 秒 | 深色石柱、金属镶边、尖顶与苹果徽冠组成的拱门长大到完整高度 |
| 36–43 秒 | 徽章轨道向内收束，中央苹果与冠冕聚拢 |
| 43–46 秒 | 门扇绕真实门轴向两边打开，整套仪式渐隐，不全屏白闪 |
| 46 秒 | 清理演出，原战斗接管，音乐按既有逻辑进入战斗段 |

## 模型与渲染

- `ManorCeremonyModel` 定义立体苹果（正背面切面与侧边）、叶片、冠冕、石柱、门扇、徽章、宝匣与有厚度的金环；`ManorCeremonyGeometry.intro` 编排时间轴，`ManorIntroMesh` 保留原调用接口。
- 独立 `ManorCeremonyRenderType` 使用 POSITION_COLOR、透明度混合、双面和深度测试；不写深度，以免挡住 Boss 实体。面片本身进行切面明暗着色，颜色不会在亮地面上被加法混合洗白。不会更改柠檬猫等其他效果使用的旧材质。
- 完整开场峰值 1426 个四边形提交，精简档 938；按距离超过 48 格或最少粒子设置精简装饰，保留立体门扇、十一徽章和主体。没有演出实体或逐 tick 粒子包。
- 128 格距离剔除，视锥包围盒 ±12 格、上方 27 格，客户端最多四场。每个渲染回调只获取一次同材质缓冲并统一提交。

## 地面与同步

Boss 在原来经过碰撞检查的可站立地面开始演出，仍识别台阶/半砖顶面，不把 Boss 额外抬高。不设置实体门碰撞，不改变地形、不强制镜头、不造成伤害。

开场继续走 `HiddenBossIntro` / `ManorIntroPacket`，开始包和序曲同服务端刻触发；每两秒补发当前状态。`PresentationClock` 使用单调计时，单人暂停时冻结，中途加入按已过时间接上，不重播序曲。结束、取消、登出、卸载及换维度按原链路清理。

网络协议为 8，开场仍保留包编号 1；新增 Boss 轮换包编号 6。联机客户端与服务器需要同版模组。
