# 鼠群：主从鼠王与奶酪装置

实体 ID：`ftboss:rat_boss`。主王、副王复用现有大鼠/小鼠模型，不新增模型或网络协议。

## 当前数值

| 项目 | 普通难度基础值 |
|---|---|
| 主王最大生命 | 20000 |
| 主王攻击 | 不攻击，不寻路 |
| 副鼠群共享生命 | 整群共用 400，不是每只独立 400 |
| 副鼠群数量 | 12 只；共享生命低于一半时补至 16 只 |
| 副王基础攻击 | 2 |
| 副鼠群命中减益 | 原鼠群随机减益池；每次命中随机一种，I～II 级，140～259 tick |
| 副鼠群承伤 | 正常伤害结算后 ×0.6 扣入共享血池，沿用旧小鼠承伤倍率 |
| 每轮装置 | 3 个 |
| 装置期限 | 20 秒（400 个服务器 tick） |
| 装置充能 | 0/100；每份材料增加 20，共 5 份 |
| 每个喂满装置伤害 | 主王当前最大生命的 12.5%，魔法伤害 |

主王和副鼠群各有一条血条；多只小鼠只显示一条共享血条，不叠十几条。主王血条显示护盾或装置倒计时。终结难度主王与副鼠群基础生命翻倍；副鼠群随主王多人血量倍率同步缩放，保持剩余血量比例。装置比例伤害随主王最大生命变化。

## 战斗循环

- 召唤后主王进入护盾状态，不攻击；同时生成 12 只原版小鼠组成副鼠群，使用原模型、贴图、撕咬动画。
- 攻击任意小鼠都会扣除同一副鼠群血池；所有小鼠同步剩余生命，不把伤害转给无敌主王。共享血池归零时整群消散，主王破盾并召唤三个桶形充能装置；杀掉或异常移除一只不会提前破盾。
- 整群共享原版受击冷却：10 tick 内同额或更低伤害不重复扣池，更高伤害只扣差额；同一范围攻击不会按小鼠数量重复扣血。带绕过受击冷却标签的伤害仍正常放行。
- 共享生命低于一半时补至 16 只；补召小鼠继承当前剩余血量，不恢复血池。新一轮机制结束才重置整群生命。
- 全部小鼠命中玩家都调用原 `BossHandler.applyRandomRatDebuff`：沿用毒、虚弱、减速、挖掘疲劳、饥饿、霉运、凋零及已注册的 armamentarium 负面效果池，不再使用此前副王固定减速＋虚弱/饥饿组合。
- 20 秒内手持奶酪或牛奶右键装置。支持 `forge:cheese`、`forge:cheeses`、注册名包含 `cheese` 的可食用物品，以及可扩展标签 `ftboss:rat_swarm_healing_food`。
- 材料正常消耗；牛奶桶等材料的容器返还。创造模式不消耗。每个装置有 4 tick 防重复交互间隔。
- 每个装置喂满后立即消失，并由喂食玩家触发一次 12.5% 最大生命魔法伤害；不会修复主王血量。
- 未喂满装置在期限结束时爆炸并消失。爆炸仅影响附近玩家，不破坏地形、掉落物或其他实体，不对主王造成伤害。
- 本轮装置全部完成或爆炸后，主王重新护盾，整群 12 只小鼠以满共享血量重新出现。重复至主王死亡。
- 不计武器额外伤害和外部魔法减伤时，累计喂满 8 个装置可击败主王，约三轮机制，消耗 40 份材料。

## 高配装备路线

- 破盾期间正常武器伤害不受鼠群专属限伤；高输出玩家可以跳过装置直接击杀。
- 护盾期间，玩家单次输入伤害达到主王当前最大生命时允许直接穿盾，仍进入正常伤害结算；不会识别或硬编码某一套毕业装备。
- 鼠群不适用全局“最终伤害超过 300 直接归零”规则，其他 Boss 不变。非有限数值不能通过穿盾门槛。
- 管理员清理用的绕过无敌伤害保持可用。

## 生命周期与归属

- 每一场通过主王 UUID 和本轮鼠群 UUID 绑定全部小鼠与装置，互不借血池、互不清理其他场次；上一轮卸载的小鼠重载后不会混入新一轮。
- 副王不提供 Boss 胜利进度、武器/石像/奖励宝箱或经验掉落；只有击杀主王才结算胜利。
- 阶段、剩余 tick、鼠群共享生命与上限、本轮 UUID、全部子实体 UUID、装置充能写入 Forge 持久数据；离线时间不扣倒计时。暂时找不到主人时保留 200 tick 加载宽限。旧单只副王存档按剩余生命比例迁移为共享鼠群，不无条件回满血。
- 主王死亡或销毁时清理本场全部副鼠与装置，并释放鼠群音乐；区块卸载保留子实体与阶段，等待重载。副鼠异常消失不会被算作击杀破盾，缺失 200 tick 后补召，保留当前共享血量。
- 旧版一般小鼠/柠檬猫小鼠仍走原有路径；普通主鼠会转换为此循环。

代码入口：`RatSwarmEncounter.java`、`RatSwarmRules.java`、`RatBossEntity.java`。
