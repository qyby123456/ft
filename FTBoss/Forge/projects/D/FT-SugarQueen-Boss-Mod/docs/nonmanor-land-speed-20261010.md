# 非庄园 Boss 陆地行走速度

## 规则

- 仅非庄园 Boss 的普通陆地行走/寻路速度乘 2；使用统一上限的通常输出由 0.1 提升至 0.2。
- 倍率作用于原上限裁剪后的有效速度，低速输入同样翻倍，零速保持零；不修改基础属性、速度药水或存档。
- 糖霜女皇、肉山、鼠群首领、苹果爵士、答辩超人、benger、潮宴鱼王的陆地寻路入口调用 `BossWalkingSpeed.speed`。
- 所有庄园 Boss（`EasterBossEntity`，含迷你和不可能挑战）、鼠群小怪及其他召唤物不加速。
- 水中速度、水中修饰符及阻尼保持原样；无重力飞行不加速。
- 故障机器人的八字悬浮仍为原 `BLOCKS_PER_TICK` 位移；答辩超人的空中环绕/俯冲、糖霜女皇的悬浮路径不改。
- 技能自行设置的冲刺、跳跃、传送、投射物速度不改；酒桶王和沙耶仍固定不走动。
