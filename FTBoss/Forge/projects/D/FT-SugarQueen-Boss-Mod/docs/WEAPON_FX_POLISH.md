# Boss 掉落武器特效优化（2026-09-18）

## 本轮边界

只调整玩家武器的技能表现、攻击命中反馈和特效传输。基础攻击、技能伤害、冷却、蓄力阈值、耐久、目标过滤、掉率均不改。
不改石像交易、女王掉落或图腾二阶段。已有武器无需重新获取，更新客户端和服务端模组后生效。

## 视觉变化

| 武器/技能 | 表现 |
|---|---|
| 常规 Boss 的 11 种武器技能 | 冰蓝、血红、翠绿、香槟金、青电、海蓝等双色渐变；扇形技能按朝向分段扫出，范围技能由内向外展开 |
| 朵拉脉冲枪、长枪 | 青电光芯、螺旋短尾、金色新星扩散环；连发枪使用独立的 3 tick 短曳光，避免光束堆积 |
| 酒瓶战锤 | 金色预备环、薄荷绿爆发环；保留玻璃碎裂音与少量玻璃粒子，减少遮挡性烟云 |
| 雪黎平底锅、擀面杖 | 玫瑰色分段弧光、双轨碾压光带；玫印、蓄力和格挡采用双色细环 |
| 黑切 | 保留展开、血怒、前摇和音效；下砸环由瞬时多圈改为逐 tick 扩散 |
| 暗影剑 | 保留原有传送法阵、光柱、动画；增加紫色扩散波，大幅减少墨团和烟云遮挡 |
| 河豚棒 | 保留完整毒云边界，以稀疏青绿气泡维持；每 10 tick 发一个描述包，不再逐粒子发送 |
| 庄园目录全部武器 + 常规 Boss 武器 | 成功的玩家直击追加主题色交叉命中火花；每玩家至少间隔 6 tick，群攻不会每个目标都爆一团 |

蛋蛋、柚子、柠檬猫、麻雀、玄蓝原有的专用技能渲染保留，本轮为它们补充通用直击反馈。
外部模组的四把三叉戟只补近战命中反馈，不接管其投掷/闪电特效。
黑切的公共落地特效助手也被 Boss 动作复用，因此对应落地环一起改善，但没有改 Boss 伤害或 AI。

## 性能与联机

- 新增 `ftboss:weapon_fx` 单向 S2C 通道，协议 1；不修改已有技能通道协议。
- 每个图形发送一个描述包，原版维度下包体不超过 82 字节。客户端按 tick 生成图形，与帧率无关。
- 手动按点到线段距离筛选同维度旁观者（48 格范围 + 图形半径），包含施法者；不向未安装此通道的客户端发送。
- 同屏最多 64 个活动特效。本管线每 tick 生成预算：全部粒子 192、减少 96、最少 48；24 格外再次减半，48 格外停止生成。
- 高频冲锋枪曳光寿命 3 tick；普通图形持续 5–12 tick，单粒子寿命不超过 14 tick。旋转处理顺序避免同一批特效长期抢占预算。
- 毒云、预备环同位置同主题去重；换维度、退出世界清空；暂停时不推进；不强制加载区块。
- 不使用全屏闪白、镜头抖动、新实体、爆炸伤害或额外贴图；少量原有音效与粒子仍保留。
- 预算只约束新管线，不代表其他模组/旧专用渲染的总粒子上限。网络包减少可由代码确认，实际 FPS/TPS 需游戏实测。

## 验证入口

- `gradle -I tools/verification/weapon_fx_checks.gradle build checkWeaponFx`：特效规则、包往返、庄园/非庄园/酒锤数值回归。
- `node tools/verification/check_weapon_fx.cjs`：注册、S2C、维度、生命周期、预算、目录覆盖和实际调用接线。
- 原有 `non_manor_weapon_wiring.cjs`、`check_wine_mace.cjs`、`check_xueli_player_weapons.cjs` 继续检查。
- `DoraSmgRulesCheck` 与独立 `XueliWeaponRulesCheck` 仍有加强前数值断言；本次备份的未修改源码也复现同样失败，不为让它们通过而回退伤害。最新 `ManorWeaponRulesCheck` 覆盖这两种武器的实际加强后数值。

未启动 Minecraft 做实机画面验收。建议在 152beta3 依次测试空挥/命中、范围技能、连发、河豚毒云、粒子三档、传送换维度，以及双人旁观。
