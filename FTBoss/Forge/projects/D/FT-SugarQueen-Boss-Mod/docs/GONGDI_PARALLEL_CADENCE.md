# 功底：诺手技能与铁魔法等频、并行

2026-09-19。

## 触发规则

- 功底本体的诺手技能使用独立触发通道，不再等待普攻收招、铁魔法吟唱或铁魔法冷却。
- 诺手技能基础间隔为 `ManorBossCombatRules.spellInterval(3) / SPELLS_PER_CAST`：当前为 `160 / 2 = 80 tick`，正常20TPS下4秒一招。旧代码为50tick再受近战型Boss规则翻倍，即100tick，并且可能被持续普攻收招一直阻挡。
- “持平”按基础技能数量节奏折算：铁魔法每轮最多两招、轮间基础间隔160tick；诺手每80tick提供一次原生技能机会。不是保证整场最终命中次数相等：铁魔法仍受吟唱及各法术冷却限制，诺手仍受目标距离、单招冷却、斩杀条件限制。
- 目标必须是同维度存活的生存/冒险玩家、可见且在原有11.25格技能范围内。目标无效、隔墙或超距时不消耗80tick冷却，重新满足条件时可立即尝试。
- 同一诺手技能前摇尚未结束时，不插入另一招诺手技能，不覆盖前摇、预警或结算；但铁魔法可以同时开始、推进和完成。
- 无AI、无敌、迷你、巨型或终章演出成员不获得这条独立触发通道。其他Boss的普攻与技能互斥规则不变。

## 保持不变

- 大杀四方、致残打击、无情铁手、诺克萨斯断头台的伤害、范围、流血、治疗和斩杀条件。
- 致残打击100tick、无情铁手160tick、断头台360tick的单招冷却；断头台击杀后30tick连招重置。
- 普攻节奏、铁魔法双发调度、铁魔法各自冷却、玩家武器与卷轴数值。
- 初始诺手准备时间仍为60tick；80tick是成功发起一招后的基础再次触发间隔。
