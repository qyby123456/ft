# Boss 对玩家击退调整

2026-09-20（初版）；**2026-09-24 再降一档**（见文末「2026-09-24 更新」）。

- 技能水平推力调整为原始力度的 25%，即在上一版减半的基础上再减半。
- 技能上抛/推力的竖直分量为原始力度的 50%；庄园五人技能中直接设置的最低抬升量也减半。保留已有速度，不对玩家总速度进行钳制。
- 原版受击路径此前未受技能减半规则保护。新增服务端伤害来源检查：本模组 Boss、召唤物和可追溯至 Boss 的弹射物造成伤害时，同 tick 的普通受击/近战附加击退也按 25% 处理。
- 显式技能击退标记调用上下文，避免与普通受击事件重复缩放。
- 玩家来源、玩家宠物/投射物、普通原版怪物和环境伤害不触发普通击退削减；非玩家目标不削，Boss 自身抗击退保持现有数值。
- 每次新伤害尝试清除旧来源，并在服务端 tick 结束和关服时清除临时记录，避免下一 tick 的击退误继承 Boss 来源。没有靠“附近有 Boss”判断。
- 功底拉人、禁锢、传送、Boss 自身位移和玩家武器主动位移不改；未接管原版爆炸直接写入速度或第三方模组自行写速度的路径。
- 不改变伤害、技能范围、冷却或玩家的移动速度属性。
