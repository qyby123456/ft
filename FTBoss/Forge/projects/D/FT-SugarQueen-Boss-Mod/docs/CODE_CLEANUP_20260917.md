## 构建和部署

- 修正 `build.bat` 中错误的经济模组标题、输出文件名和本机绝对 JDK 路径；支持 `build.bat clean`。
- `gradle/verification.gradle` 绑定到正常构建：校验空资源、JSON、纹理解码、开发备份混入；最终 jar 检查重复/缺失/陈旧条目，以及资源字节与构建输出一致。
- jar 使用稳定条目顺序、不保留源文件时间戳。未断言所有 Forge 重混淆产物已具备跨机器逐字节可复现性。
- `tools/verify_project.cjs` 汇总检查并传播失败退出码；日志统一到 `build/reports/verification/`。
- 图像检查使用 JDK ImageIO，避免原工具把 JPEG 内容的 `easter/xueli.png` 错当作损坏 PNG。本轮未改该素材字节。
- 部署脚本兼容 Windows PowerShell 5.1，脚本采用 ASCII，中文目的地由 Unicode 码点组成，避免 UTF-8 无 BOM 被按系统代码页误读。
- 移除运行中强制覆盖的 `-Force` 开关；等待脚本复用同一部署入口，不再通过“文件可以写”推断游戏已退出。
- 部署前预检全部路径；拒绝符号链接和目录联接，只额外放行经过 reparse tag 验证的 OneDrive Cloud 占位目录。
- 支持 `-NoBuild -ArtifactPath <已验证的独立构建jar>`，避免覆盖其他会话的共享 `build/`。
