### 独立被动三晶与不可打断天罚

- 三颗浮游法晶使用自己的被动状态与目标缓存，不进入 `QizaiMagic`，不调用 `playCast`，也不会用 `setTarget` 反写本体。
- 三晶的激光、追踪飞弹和护盾可与祁崽任意主动技能并行；主动技能清空目标或切换施法阶段不会让三晶停摆。
- 「天陨星裁」成功起手后进入不可软打断阶段：普通取消、目标丢失、受击造成的控制、临时 NoAI 和通用解冻看门狗都不能掐掉流程；技能每 tick 重新确认自身保护，直到三次天罚结算并完成收招。
- 天罚与「万棱星狱」期间暂停庄园普通防逃课召回，玩家不会被拉到祁崽身边；两个召回传送入口也会二次拒绝。万棱星狱即使暂时没有有效目标，也会以最近锁点和随机方向完成三轮，但不会伤害创造、旁观或已失效玩家。
- 万棱星狱的“不可打断”只保护状态机，不提供免伤；祁崽仍保持地面、碰撞、可选中和可受伤。
- `forceCancel()` 只留给死亡、换变体、真正的庄园硬转场、实体移除，以及迷你 / 巨型 / 终章等硬状态边界；硬清理仍会复位无敌、位置、视觉与待结算伤害。

技能顺序（按代码 `PATTERN`）= 星矢 → 落星阵 → 星十字 → 星矢 → 落星阵 → 星矢 → 玫瑰星陨 → 绯星祈愿 → **绯星指针 → 天陨星裁 → 绯星锁裁 → 万棱星狱**，走完一轮才回到开头。攻击后有24 tick固定收招，随后32 tick普通休整；专用技能按各自规则收招，终结模式会加速追踪、锁定与休整。普通模式各类技能按5/6后的无额外修正伤害：星矢 20、落星阵约33.33、绯星祈愿约53.33，绯星指针的束与星雨同样是 20（每段独立结算）；绯星锁裁每束原始魔法伤害 72，万棱星狱每束原始魔法伤害 48，均仍接受护甲、抗性及其他现有伤害处理。

⚠ 绯星指针那条有个容易做错的点：`QizaiSweepRules.angle` 是"每 tick 转固定角度"的公式，而且**客户端渲染复用同一个函数**

**没有跟着减的**（按既定口径）：收招窗口（`QizaiRules.RECOVERY` / 绯星指针 24 tick）与天陨的收招余韵，
以及各技能间的**演出拍点**（如星雨波数、弹幕数量）—— 终结难度改的是"节奏快慢"，不是"演出规模"。

## 特效与性能

- 红粉外圈为实际危险边界，内侧旋转星纹及收缩白圈显示倒计时；落晶后扩散淡出，不重复造成伤害。
- 服务端同步实体技能状态，客户端本地生成网格；迟加入观察者也能读取当前预警。没有常驻全局特效列表，不把旧维度状态带到新世界。
- 每帧每种材质只取一次顶点缓冲：实体模型走写深度批次，透明危险特效走透明批次；最多绘制12个祁崽。万棱星狱最多同步本轮120束，换轮清除上一轮；星棱炮镜、立体蓄能管、三层热芯束、移动能量箍、锁定准星和冲击冠均为专属程序化几何。绯星连奏复用同一个可淡出写深度模型缓冲绘制天穹镜与坠星核，再在透明法术图集中绘制三层束、能量箍和落点玫瑰冠；不恢复通用 TRACE。精简粒子设置仍保留玩家锁定线与危险边界。星矢自身使用8个晶体面。

- 2026-09-20 修正四视图人形部分的纵向UV：通用离线渲染器把纹理首行贴到了立面的底部，导致之前预览中的头脸和身体上下倒贴；现在为预览人形显式转换立面UV，基础层与覆盖层一致。运行时仍使用原版 `PlayerModel.createMesh`，不反转实际皮肤或修改其他武器的预览约定。
