# 朵拉的鸣脉冲锋枪

物品 ID：`ftboss:dora_nova_launcher`。已有这个 ID 的武器保留耐久、附魔和自定义名字，更新后直接使用冲锋枪模型与机制；普通 Bren 枪及旧 Bren 标记物品不自动转换。

- 主手按住右键立即全自动射击，松开停火；600 发/分，每 2 tick 一发，不再蓄力。
- 地脉弹匣 30 发，空匣自动换弹；潜行再按右键可以提前换弹。换弹 36 tick（1.8 秒），不消耗外部弹药。
- 保持右键会在换弹结束后继续射击；松开不取消正在进行的换弹，切走武器暂停换弹，拿回主手继续。弹量与换弹进度保存在武器 NBT，不跨枪共享。
- 单发基础伤害 5，14 格内不衰减，14～28 格线性衰减至 2.5；最远 28 格。实际伤害仍受护甲、减伤和既有事件影响。
- 射击期间潜行可减小散布；每发消耗 1 耐久。状态栏和提示显示剩余弹量、换弹状态。
- 只由服务端扣弹与造成伤害；射线遇墙和首个生物停止，不穿墙、不爆破，不伤害有主宠物、队友、创造/旁观玩家或盔甲架，遵守 PvP 设置。
- 独立伤害类型仅加入 `is_projectile` 和 `bypasses_cooldown`，保证高速命中不被原版受击间隔吞掉；不清除目标无敌帧，不绕过护甲、盾牌或无敌状态。
- 玩家击败非分身、非巨型、非禁 AI、非庄园终局成员的朵拉时掉落一把。遵守 `doMobLoot`，不重复添加已存在的同款掉落；该事件里旧 Bren 枪掉落被替换，不改普通 Bren 枪。
- 朵拉 Boss 主手在这把冲锋枪与聚能枪之间切换，副手保留长枪；冲锋枪连射、聚能枪蓄力狙击，详见 `docs/dora-arsenal.md`。玩家模型为 33 个方块、128×128 逐面贴图，保留 N 键视检。

## 验证

`node tools/verification/check_dora_smg.cjs`：数值边界、掉落条件、服务端保护接线、伤害标签、双语提示与模型生成一致性。

`node tools/verification/check_dora_weapons.cjs`：原长枪技能、双语资源、UV 与 GUI 边界回归。

实机验收：按住射击至空匣再续射、半匣主动换弹、换手与丢弃后取回、跨存档弹量、盾牌/护甲/队友保护、朵拉死亡掉落、第一/第三人称及左右手持握。离线预览不等同实机截图。
