## 如何使用机制资料

完整机制参考用于找规则与数值，精简速查用于快速定位，专题用于追问一个模块，审计和归档用于追溯。它们都不替代主代理认可的当前主线；存在冲突时先停留在已确认边界，不按文件新旧自行取舍。
