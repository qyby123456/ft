# 非庄园 Boss 专属武器技能

## 操作

主手持下列武器，按 **J** 释放专属技能。可在「选项 → 控制 → FTBoss · 武器」中改键，物品提示显示当前绑定。
默认不使用 G：当前整合包的 G 已绑定饰品栏。原有右键、潜行右键、蓄力装填与被动保持不变。
技能有独立冷却；同一种武器的所有副本共享玩家冷却，换武器、重登、死亡或切维度不重置。
成功释放消耗 3 点耐久，创造模式遵循原版免耐久规则；所有模式都受冷却限制。
电弧未找到可见目标时不消耗冷却或耐久。打开界面、死亡、旁观、睡眠、正在使用物品时不能施放。

## 范围与保护

- 酒瓶锤已独立重做：有效普攻攒酒压、J 消耗全部酒压锁点蓄势；取消旧强制醉酒与随机增益。详细数值、取消条件及模型见 `wine-bottle-mace.md`。
- 对应糖霜女皇、屠夫、沙耶、酒桶王、鼠群、故障机器人、炫彩答辩超人、苹果爵士、边牧犬王、潮宴鱼王。
- 不改庄园武器；河豚棒属于紫菜的庄园武器，不在本次新增列表中。
- 荆棘头冠是护甲，不算专属武器；酒桶弩·装填只是 Boss 外观件，不参与技能。
- 排除自己、双方判定的队友、被驯服/拥有主人的生物、同乘载具、盔甲架、创造和旁观玩家。
- PvP 必须同时通过服务端 PvP 开关及队伍友伤判定；所有目标需可见，爆发和电弧额外检查段落遮挡。
- 范围技能最多24个目标，电弧最多4个且不重复；伤害被拒绝时不追加减益、不计算吸血。
- 不清除原版受伤无敌帧，不强制扣血，不绕过禁疗，不破坏方块或地面掉落物。
- 特效采用服务端粒子和原版音效，同场玩家可见可听；没有新增自定义音频。

## 维护与验证

规则：`util/NonManorWeaponRules.java`；服务端：`skill/NonManorWeaponSkills.java`。
独立 C2S 通道：`skill/NonManorWeaponPacket.java`；客户端按键与提示：`client/NonManorWeaponClient.java`。
事件通过 MOD 总线初始化注册，不需改共享物品注册表或旧武器类。
客户端只发送当前物品ID；服务器重新核验主手、存活状态、瞄准、目标、伤害和冷却。

运行 `tools/verification/check_non_manor_weapons.ps1` 校验11件武器白名单、伤害和冷却边界、
扇形/射程、回血上限、庄园排除、双语提示、注册接线与安全约束。
再执行 Gradle `build` 检查 Forge API 与 JAR 资源。纯规则与静态接线检查不替代游戏内验收。
进游戏分别检查 J、按键重绑定、原右键、队友/宠物、墙后目标、冷却重登与死亡、酒桶弩装填保留。
