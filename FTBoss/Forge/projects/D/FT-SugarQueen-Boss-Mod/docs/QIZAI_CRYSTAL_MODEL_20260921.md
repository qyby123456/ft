# 祁崽独立法晶模型

## 外观与接线

- 独立网格真源：`util/QizaiCrystalMesh.java`，启动时缓存三套模型，不依赖物品图标、贴图展开图或通用菱形光片。
- 八棱切面晶体、斜切亮边、深色金属镶座、双层细金边、四支镶爪。慢速自转；独立实体附带反向环绕碎晶。
- 紫晶为激光，蓝晶为飞弹（额外双翼晶柱），宽体金晶为护盾。材质使用自己的克制配色，不再复用危险提示的橙红/亮黄色。
- 独立法晶实体通过 `QizaiCrystalRenderer` 绘制；连携水晶与绯星锁裁通过 `QizaiCrystalModelVisual` 复用精简本体。万棱星狱后续改用自己的星棱炮镜模型，不再复用通用法晶。
- 模型走 `QizaiContrast.MODEL` 不透明写深度材质；危险线与护盾细环仍走 `QizaiContrast.TYPE` 透明材质。本体互相遮挡正确，不会把背面光片全叠到正面。
- 世界渲染先整批模型、刷新，再整批特效、刷新；两种材质分别只取一次缓冲。实体渲染先写完本体，再切到特效缓冲，不复用已经切换的 consumer。
- 召唤水晶结束时缩小收束，而非整块高亮膨胀闪烁；移除水晶脚下纯装饰小法阵，保留目标和场地的真正危险预警。

## 不变项

不改实体碰撞箱、血量、法术伤害、激光宽度/预警、锁定目标、技能数量、时序或服务器状态机。低粒子设置不会省略水晶本体。

## 验证

`gradle checkQizaiCrystalModel` 检查三类模型、动画姿势、实体/召唤接线、写深度材质、有限顶点、不退化面、颜色和面数预算；直接用实际网格绘制带深度缓冲的四视图预览。

完整实体含碎晶 432/448/432 个四边形，召唤体 192 个；模型局部半径小于 0.8、高度 1.3 格。预览路径：`build/verification/qizai-crystal-model/preview.png`。这是离线正交预览，不代表已通过游戏内光影测试。

原有可见度、几何及技能源码守卫保留；缓冲检查按两个独立材质分别验证一次获取/刷新，不是取消缓冲约束。
