# 天陨星裁：独立「坠星圣冠」模型

## 模型与动作

- 独立模型入口 `client/model/QizaiSkyNovaModel.java`，不是通用水晶的放大版：五层八面陨星核、六瓣带厚度与倒角的分离外甲、双组倾斜分节封口星环、六颗卫星晶饰。使用真实三维面片，核心、背甲、侧面、金属边与嵌线分别着色；深紫、绯红、香槟金为本招独立配色，不修改其他法术的配色。
- 升空时模型逐渐显现；蓄力时外甲展开、星环反向旋转、核心长大。最后 12 tick 外甲收拢，模型加速俯冲，尖端在原本伤害结算时刻触地；不是先结算伤害再慢慢降落。
- 每次真实冲击重新触发外甲向外裂解、抛射碎晶和双层地面扩散环，8 tick 内收掉主体，20 tick 内余波全淡出。不再画旧的粗直光柱、大面积交叉地面线与通用卫星水晶。
- 固定 48 格外边界和真实五秒蓄力不变。收缩圈与十二个进度刻度保持可读，波纹只是命中后的视觉，不重新定义伤害边界。服务端伤害、范围、三次结算、冷却、保护及中断逻辑均未修改。

## 接线与预算

- `QizaiMagicVisual` 既有 SKY_NOVA 分支 → `QizaiAdvancedGeometry.nova` → `QizaiSkyNovaGeometry` → 独立模型；继续使用同步的本次起手/每次冲击时间戳、固定原点与悬停高度。没有额外实体、贴图依赖、网络消息或客户端积累状态。
- 所有模型面片沿用现有 `QizaiContrast` 双面材质和同一个 VertexConsumer。低特效只减少星环分段、碎片与尾迹，不删主体、六瓣外甲、星环厚度或预警边界。
- 静态主体完整 434、低特效 290 个四边形提交（含三角面）；完整场景上限分别 740 / 460。变换矩阵按部件计算，不在每个顶点重复求三角函数。
