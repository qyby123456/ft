# Astra 新增铁魔法体系 · 机制与数值

> 来源：`integ/spells/` 包（14 个类）+ `util/BossSpellRules`、`util/ManorSpellRules`。
> 数字全部取自代码常量；本文只写**当前生效**的值，不记版本沿革。
> 整理时工程内仍有并行改动，**以你在盘上看到的代码为准**。

## 0. 一句话概览

本模组给 **7 只常规 Boss** 与 **甜苹果庄园十位成员**各加了一套**专属铁魔法**：
常规 Boss 每位 5 个法术（共 **35** 个），庄园每位 3 ~ 4 个（共 **32** 个）；
全部注册成 Iron's Spells 的 `AbstractSpell`，**最高 5 级**、稀有度 **RARE** 起步、允许合成；
击杀时掉**全套卷轴**。

| 项 | 值 |
|---|---|
| 法术总数 | 常规 35 + 庄园 32 = **67** |
| 最高等级 | `MAX_LEVEL = 5`（两套都是） |
| 最低稀有度 | `SpellRarity.RARE` |
| 是否可合成 | `setAllowCrafting(true)` |
| 施法类型 | `CastType.LONG` |
| 战利品 | 击杀掉全套卷轴（见 §6） |

## 1. 通用框架

| 项 | 值 | 出处 |
|---|---|---|
| 射程 | `RANGE = 24` 格 | BossSpellRules:9 |
| 作用半径 | `RADIUS = 4` 格 | BossSpellRules:10 |
| 单次最多目标 | `MAX_TARGETS = 16` | BossSpellRules:11 |
| 吟唱时长 | `CAST_TICKS = 32`；**冰晶长枪 / 斥力放电为 20** | `castTicks()`:137 |
| 延迟生效 | 酒桶炸弹 `delay = 16`、深渊喷泉 `delay = 20`，其余 0 | `delay()`:139 |
| 每级法力 | `manaCostPerLevel = 10` | BossSignatureSpell:37 |
| 每级法强 | 伤害类 **+4**；辅助类 **+1** | :39 |
| 法力消耗 | = 各法术的 `mana` + 10 × (等级−1) | :36-37 |
| 法强 | = 各法术的 `damage` + 4 × (等级−1)（辅助 +1） | :38-39 |

> **等级只影响法强与法力，不影响冷却、半径、目标数**（那几个是常量或另有专门公式）。

### 目标过滤（统一口径）

不伤：自己、友军、队友、**自己的驯服宠物**、盔甲架、创造 / 旁观玩家、未开 PvP 的玩家，
以及**同属 ftboss 命名空间的实体**（Boss 之间不互伤）。需要视线。

### 命中标记加成

`bonusDamage(damage, marked)`：被标记的目标吃 **×1.5**。

### 辅助类法术（伤害为 0，走另一套结算）

| 类型 | 法术 | 效果 |
|---|---|---|
| **治疗** `healing()` | 茶花圣所 / 山茶重生 / 紧急重启 / 活体覆盖物 | 回血，数值 = 法强（1 级 4 ~ 6，5 级 8 ~ 10） |
| **护盾** `shielding()` | 果园神盾 / 冰川棱镜 / 醉人祝酒 / 深渊甲壳 | 给护盾，见下 |

护盾换算：`shield(power) = clamp(round(power / 4) × 4, 4, 40)` —— **4 ~ 40 之间、且是 4 的倍数**。

治疗类每级只 +1 法强，所以**升满也回不了多少**；它们的主要价值在附加效果。

## 3. 多段脉冲（扩展法术）

部分法术不是打一下就完，而是**按节奏连打数段**：

| 法术 | 段数 | 段间隔 | 首段时刻 |
|---|---:|---:|---:|
| 糖霜冰雹 / 荆棘巡礼 / 山茶重生 / 血色缝合 / 余烬吐息 / 陈年雷区 / 静电点阵 / 腐朽安魂曲 / 太阳果园 / 暗流绞索 / 裂潮回廊 | 3 | 10 ~ 20 | 0（或 20） |
| 猩红花粉 | **4** | 20 | 0 |
| 其余扩展 | 1 | — | 0 / 16 / 20 / 24 |

- 段间隔：荆棘巡礼与裂潮回廊 **10 tick**；余烬吐息与陈年雷区 **12 tick**；其余 **20 tick**。
- 首段时刻：王室碎裂 / 血绽 / 陈年雷区 / 裂潮回廊 **20**；审判之种 **24**；孢子喷发 **16**；其余 0。

## 4. 各族法术的实际效果

| 族 | 命中效果 |
|---|---|

| **自然（沙耶主招）** | 缓慢 **IV** 60 tick；**吸血**：把自己造成伤害的 **15%** 回给自己，单次上限 **6** |

| **闪电（机器人主招）** | **链式**：链目标数 = `3 + (等级−1)/2`，每跳衰减 **×0.8**（最多算 4 跳） |
| **自然（答辩主招）** | 中毒 I 80 tick；并在地面留**孢子场**：持续 **60 tick**，在第 **0 / 20 / 40** tick 各再爆一次 |

## 6. 玩家怎么拿到这些法术

| 途径 | 规则 |
|---|---|
| **击杀掉落** | 击杀某只 Boss 时，掉**该 Boss 全套**卷轴（每位一个法术一卷，**1 级**） |
| 触发条件 | `doMobLoot` 开启 **且** 击杀者或击杀归属是玩家 |
| 频率 | **每只 Boss 实例只发一次**（持久标记 `ftboss:signature_scroll_rewarded`） |
| 召唤物不算 | 卷轴只认 Boss 本体 |
| 女皇特例 | 女皇走 `LivingDeathEvent` 单独发（因为她有图腾二命）；**复制体不发** |
| 合成 | 全部 `setAllowCrafting(true)`，走铁魔法自己的合成体系 |
| 战利品表 | `allowLooting()` 返回 **false** —— 抢夺附魔**不会**多掉卷轴 |

## 7. 施法节奏（Boss 怎么放）

| 项 | 值 |
|---|---|
| 首个专属法术 | 开场等待 **60 tick** |
| 专属法术间隔 | **60 tick**，但实际冷却 = `max(160, 法术冷却 × 0.75)` tick |
| 专属法术优先 | 目标在 24 格内且可见时，**提前 20 tick** 抢占（压掉普通法术） |
| 原版法术（铁魔法自带） | 间隔 240 tick；**25% 概率**真的放，没抽中就 60 tick 后重试 |
| 互斥 | 正在施法（`IMagicEntity.isCasting()`）或已有排队的专属法术时，原版法术让位 |

## 8. 表现层

- **吟唱预警**：每 4 tick 打一次预警（`warning`），并在作用点画一圈该法术主题色的粒子环（16 点）。
- **释放**：`SpellVisuals.show(..., Phase.RELEASE, ...)` + 主题色光束 / 落点粒子。
- **主题色**：每个法术自带一个 RGB（详见规则表 `color` 字段）——
  例如女皇冰蓝 `0xA0E7FF`、沙耶粉 `0xEF6591`、酒桶王橙 `0xD99545`、机器人电青 `0x7EDCFF`、
  答辩黄绿 `0xB1E85D`、苹果金 `0xFFDC64`、鱼王青 `0x50DFC9`。
- **音效**：施法起手统一 `BEACON_POWER_SELECT`；
  收尾按 Boss 分（女皇玻璃碎 / 沙耶杜鹃叶 / 酒桶王空瓶 / 机器人三叉戟雷 / 答辩史莱姆块 / 苹果紫水晶 / 其余三叉戟激流），血系统一史莱姆块。
- **场次清理**：孢子场与庄园场地都做 `LevelEvent.Unload` 与 `ServerStoppedEvent` 清理，不跨维度残留。

## 9. 需要留意的实现细节

| 项 | 说明 |
|---|---|
| 射程硬上限 | 施法点距施法者 **> 32 格**直接放弃（`cast` 开头判定） |
| 目标上限 | 常规 16 / 庄园 12，**按距离排序取最近的** |
| 血量找回 | 自然系吸血按"**实际掉血量** × 15%"算（不是面板伤害），所以过量伤害不会虚增回血 |
| 护盾取整 | 护盾值一定落在 4 的倍数上，且夹在 [4, 40] |
| 等级夹取 | `level()` 把等级夹到 [1, 5]，**超过 5 级不会变强** |
| 庄园扩展段 | 只对**非辅助**的扩展法术生效（辅助没有脉冲） |
