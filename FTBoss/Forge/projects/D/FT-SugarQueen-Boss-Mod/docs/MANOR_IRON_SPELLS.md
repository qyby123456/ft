## 玩家获取与使用

- 玩家或玩家的宠物击杀对应正常 Boss，掉落该 Boss 的三张满阶原生铁魔法卷轴，各一张。
- 同一实体只奖励一次；分身、巨型演出体、NoAI 演出体、庄园终章替身不掉落；尊重 `doMobLoot` 和掉落事件取消。
- FT 创造物品栏提供全部33种法术各一张满阶卷轴，不再显示165个等级变体。
- 卷轴使用原生 `ISpellContainer`：纸、传奇墨水和学派触媒可撰写满阶卷轴；抄写台支持录入法术书并消耗卷轴；奥术铁砧不再提供升级结果。
- 全部固定传奇品质、单一满阶；威力、魔力、持续时间、治疗和护盾保留完整满阶数值，无等级成长。
- 玩家从铁魔法施法入口使用时沿用其法力、冷却、施法速度、打断和学派加成。每个法术拥有独立 ID 和冷却，不与蛋蛋武器右键共用触发入口。
- 原生配置仍控制启用状态、冷却、法力和法强倍率、制作许可；最高等级锁定为1（唯一的满阶形态），旧配置不能重新开启分级。

## Boss 施法

- 初次交战约 5–7 秒后尝试施法，三招轮换且各自计冷却；两次吟唱间至少留 4 秒间隔。
- 只在原技能没有占用动作时开始；吟唱会锁住原有攻击 / 追击技能，并使用已有同步骨骼施法动作与区域粒子预警。
- 目标丢失、换目标、死亡、NoAI、无敌演出、跨维度、超距或失去视线时取消，不在尸体或已卸载世界继续释放。
- Boss 使用同一满阶法术，不扣玩家法力，仍通过注册的 Iron `AbstractSpell` 执行。
- 功底四种诺手武器技能与铁魔法独立并行；大杀四方保留原生前摇、伤害、出血与外刃回血，不再被黑刃裂甲替换，法术冷却或正在施法也不会吞掉武器技能。
- 柠檬猫猛火翻锅、玄蓝蒸汽泄压、折耳根暗影突袭的入口改为对应独立法术，使用铁魔法预检查、预施法、咏唱、释放与结束回调，不再叠加旧技能伤害；未安装铁魔法或禁用对应法术时保留原技能回退。
- 麻雀保持支援定位，Boss 自动轮换不使用攻击型千羽散华；玩家可正常使用其卷轴。完整接线与技能替换说明见 `MANOR_IRON_CASTING.md`。

## 安全与表现

- 法术伤害走铁魔法学派伤害源，尊重无敌帧、友方 / 宠物保护及 PvP 设置；不重置无敌帧、不制造世界爆炸或破坏方块。
- 远程射线遇墙截断，区域命中同时检查施法者视线；定点技能锁定原位置，不自动追踪玩家闪避后的新位置。
- 辅助领域只帮助施法者、双向盟友和施法者自己的宠物，不能治疗敌人；不会复活死亡目标。
- 暮烛囚笼是牵引减速，不宣称禁止传送；虚空回响不绕过无敌、不使用虚空秒杀。
- 白夜禁疗复用 `ftboss:heal_ban`，可见图标与真实治疗拦截一致。
- 每世界最多 64 个持续法术实例；同一施法者同一技能替换旧实例。每次区域最多 12 个目标，粒子与脉冲数量固定，卸载 / 停服清理。
- 33 张独立 64×64 图标、中文 / 英文名称与效果说明由生成器维护，不改原武器模型或原有非庄园法术图标。

## 验证与维护

源参数：`util/ManorSpellRules.java`。玩法：`integ/spells/Manor*.java`。

```text
node tools/model3d/gen_manor_spell_assets.cjs <临时 resources 目录> <预览 PNG>
node tools/verification/check_manor_iron_spells.cjs
gradle runGameTestServer -I tools/verification/manor_spell_gametest.gradle --offline
gradle runGameTestServer -I tools/verification/manor_integration_gametest.gradle --offline
```

GameTest 使用真实 Forge/铁魔法注册表、容器、施法回调、伤害/治疗事件、Boss 状态机与掉落事件；33种庄园法术测试原生锻造、抄写和拒绝继续升级。
独立测试源集不进入发布 jar；`smoke-libs` 需准备铁魔法 3.16.3、Curios、GeckoLib、Player Animator 和 Iron's Library 对应依赖。
测试服务器会显式完成铁魔法配置同步初始化；普通服务器由玩家登录 / 数据包重载完成此步骤。
客户端图标、光影和整合包内战斗手感仍需游戏内观察，服务端测试不代替客户端视觉验收。
