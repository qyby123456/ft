# 非庄园 Boss 铁魔法施法节奏

2026-09-19 更新：常规 Boss 铁魔法咏唱时间减半，专属攻击法术的独立 Boss 基数翻倍，治疗/护盾不翻倍。

2026-09-20 更新（v177）：Boss 咏唱时长由「原始时长的一半」改为「原始时长 × 2/3」（比减半长 1/3），覆盖常规招牌法术、庄园招牌法术与原生 LONG 法术；玩家施法不受影响。见 `BOSS_CAST_TIME_20260920.md`。原生持续引导的持续时长与脉冲数量保留，瞬发法术仍瞬发。下列轮换间隔与冷却规则保持不变，玩家卷轴数值不改。见 `BOSS_COMBAT_BALANCE_20260919.md`。

- 适用范围由 `BossSpellRules.forBoss` 的专属法术表决定；庄园 Boss、召唤物和没有专属法术的实体不受影响。
- 原版铁魔法每次合格尝试仅有 25% 概率通过；成功尝试后同一 Boss 的所有旧法术入口共享 240 tick（12 秒）冷却，失败后至少等待 60 tick（3 秒）再抽取，避免连发队列每 tick 重抽。
- 狂暴、女王复制体、沙耶护体法术、酒桶连发、机器人充能球及黑洞使用同一限制；既有近战、召唤和非铁魔法技能不改动。
- 专属法术在开战 60～79 tick（约 3～4 秒）后首次尝试，此后公共起手间隔为 60 tick（3 秒），逐个轮换已注册且启用的专属法术，并跳过单招冷却中的法术。
- Boss 使用专属法术的单招冷却为铁魔法配置冷却的 75%，下限 160 tick（8 秒）；不改变玩家法术冷却、法力消耗、伤害或咏唱时长。
- 专属法术与旧铁魔法使用独立通道，不再设置专属优先窗口或相互等待。全部七类 Boss 的专属法术使用自己的蓄力状态及临时 MagicData，不写入旧铁魔法的施法槽、目标数据或动作状态；原生 Iron 通道仍一次只施放一个法术，避免覆盖正在引导的法术。见 `NON_MANOR_PARALLEL_CASTING.md`。
- 专属法术全部被配置禁用时恢复既有旧法术行为，避免 Boss 无术可用。轮换不固定法术数量，新增专属法术会随注册表自动纳入。
- 机器人旧法术被限流时沿用已有元素技能回退，不记录虚假的施法成功或追加回想法术。

验证：`BossSpellPacingGameTests` 覆盖抽取概率、共享冷却、防连续重抽、双通道独立、范围边界、玩家与庄园排除，以及专属法术调度；`BossParallelCastingGameTests` 验证攻击、技能、被动与施法并行。
