- 借鉴的是“原生结构完整、可替换内部部件、关键结构不能缺、选配改变功能、空间化查看”的原则。固定剑角色和材料联动是本工程自己的实现，不把新联动声称为原版胸腔的规则，也不导入其模组或美术资源。
- 当前只针对 SwordItem 及其子类；其它近战类型仍用旧三部件页。暂停的弓/法杖专属分类、施法、拉弓和射弹扩展不编译、不发布。

## 八个部件格

| 部件 | 必需性 | 作用 |
| --- | --- | --- |
| 刃口 | 必需 | 保留旧 EDGE；主要影响伤害、触及和材料被动 |
| 剑骨 | 必需 | 承重结构；影响耐久上限、损耗、伤害与触及 |
| 握柄 | 必需 | 保留旧 GRIP；握持与攻速 |
| 缠束 | 必需 | 维持连接；影响损耗和操控攻速 |
| 剑芯 | 选配 | 保留旧 CORE；材料功能与核心联动 |
| 护手 | 选配 | 耐久、操控与材料防护功能 |
| 配重 | 选配 | 平衡、攻速与耐久消耗 |
| 嵌饰 | 选配 | 引入材料功能或与剑芯接通；默认未安装 |

- 四个必需件任一个缺失：攻击、技能、挖掘和物品使用沿用不可用门禁；物品不销毁，石像交互仍保留。
- 耐久尚存而缺件：可以在材料页补装，不因“不可用”反过来锁死补装。耐久真的耗尽或存有 Broken 标记：先完成原有对应石像修复，再补装。
- 修复任务只恢复耐久，不自动长回丢失的部件。所有已进化武器原有的经验/普通修补限制保留。
- 状态与槽位性质分开：必需/选配不是安装状态。安装状态区分原生、加装、未安装、真正丢失；EverPresent 记录让选配空槽不被误写成“已脱落”。

## 原生与旧数据

- 原物品 ID、原模型、附魔、进化历史、食物插槽、技能稀有度与修复绑定不替换。原生铁剑可以看作铁质刃/剑骨与原生握柄；材质是 tier 推定，不等同于从第三方配方逆向推断真实零件。
- 首次读取旧武器仅做只读视图映射：旧 EDGE/GRIP/CORE 保持位置，其余支撑按原生完整结构解释。缺少新 NBT 不等于缺件。
- 原生格不发放免费“加装材料被动”。旧三部件的最终倍率默认保持，原有霜芯/钻石刃等组合不自动获得新联动或改变已损耐久比例。
- 第一次明确确认改装才写入新版本数据并开启联动；预览只修改副本。替换消耗一个真实库存材料、不返还旧材料；保持已损耐久比例，不降低损耗阶段、不提供免费修复。
- 掉件批次仅更新部件状态，由原生命周期统一结算耐久比例与已处理损耗阶段，避免上限 2→1 时跳成虚假的第四损耗阶段。
- 版本不兼容时保留物品数据并阻止覆盖；不是提示玩家重复修复可以解决。

## 材料与功能

沿用已部署的原版材料、灾变锭、铁魔法秘银和庄园 Boss 材料目录与掉落；不添加锌、黄铜、琥珀金、炽金等被用户排除的路线。每种加装材料在一次材料被动处理中按种类去重，不因多格重复叠出相同被动。

- 各位置对耐久、损耗、伤害、攻速、触及的权重不同，不是八个通用倍率孔。
- 已接入的材料攻击、防护、击杀与 Boss 材料功能沿用原有入口；原生部件不触发这些额外功能。
- 霜芯＋霜刃或钻石刃：确认改装接通后，耐久额外 +8%，损耗 -6%。
- 电容芯＋铜刃或铜嵌饰：确认改装接通后，攻速额外 +4%，触及 +0.10；全局材料触及上限仍为 +0.75。
- 拆失联动部件即断开；缺必需支撑时全部联动关闭。首版不提供直接拆除、自由拖拽或右键快装，避免误耗、误拆和绕过确认。

## 石像 UI

保留 490×300 面板和真实武器图标，材料页左侧改为八格四行的内部剖面，右侧显示当前→预览的伤害、攻速、触及、耐久与损耗。原有材料分类、9×2 库存格、翻页、完整候选说明和底栏确认保留。

- 实框必需、断框选配、标记点原生；缺件、选中状态独立表达。
- 点击部件只选中，点击材料只预览，底栏确认才消耗。等待 ACK 时不能改变提交上下文。
- 顶部区分结构完整、缺必需件与耐久耗尽；完整悬停集中列出缺失部件和补装/修复入口。
- 不需要替换、耐久耗尽、版本异常分别提示，不统一误报“先修复”。空格不再显示“未安装：原生材料”。
- 此为内部构成界面，不是已实现世界内动态换模。本轮不修改任何剑模型/贴图；原生手持外观保持。

## 网络与边界

石像协议从 7 升为 8，新 CavityAction 使用独立消息 ID 6，不重解释旧三部件 ordinal 编码。联机双方需要同版。

服务端验证真实石像与距离、存活/旁观状态、槽位范围、武器 UUID、剑腔 revision、真实库存材料 ID，再重新计算效果及消费。成功改装/掉件推进 revision；重放不再扣材。拒绝路径同步库存并 ACK。客户端 send 返回实际发送结果，未发包不进入永久 pending。旧三部件网络入口拒绝改装剑，其它类型入口保留。
