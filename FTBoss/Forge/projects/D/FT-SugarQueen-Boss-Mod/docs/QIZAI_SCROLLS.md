# 祁崽星术 · 铁魔法卷轴

2026-09-20。四个法术实际注册到 Iron's Spells 的法术注册表，不是改名纸张或只供 Boss 使用的伪卷轴。沿用现有招牌卷轴口径：传说品质、一级即满威力，不设计虚假的升级阶数；均属末影学派。

## 获取和使用

1. 在铁魔法卷轴锻造台放入纸、传说墨水和末影学派媒介，选择星矢、落星阵、绯星祈愿或星步。锻造台使用原生配方逻辑和当前整合包的媒介标签。
2. 卷轴可以按铁魔法原生规则直接使用；也可以在铭文台抄录到有空槽的法术书，抄录会消耗卷轴。
3. 装备法术书并选中法术，使用铁魔法施法键或手持绯星祈愿杖右键施放。使用法术书时正常消耗法力、进入冷却，接受法术强度和施法速度加成；直接卷轴施法的消耗沿用铁魔法原生规则。
4. 创造模式在本模组主物品栏搜索名称，可找到四张真实卷轴。

本次四张卷轴通过卷轴锻造台和创造栏获取，不启用庄园单 Boss 掉落，也不替换现有通关奖励。同仓库并行新增的星十字、绯星雨卷轴及追加战利品匣沿用各自原有接线，本次四个 `qizai_` 前缀法术与它们分开注册，不互相覆盖。

## 行为和特效

- 星矢：锁定起手瞄准方向，扇形三枚粉晶，0.8格/tick，最多60tick，不追踪、撞方块停止。玩家版本可以命中敌对生物，原Boss版本仍只攻击有效玩家；伤害来源保留玩家和法术归属。
- 落星阵：起手瞄准约24格内的实体或地面，向下寻找可见地面，锁定半径2.8格警告。移动视角和目标走位不改变已经出现的阵；施法结束只结算一次。
- 绯星祈愿：中心及左右三阵半径3.2格，中心间隔7格。侧面没有可见地面时不生成该阵。每次至多伤害12名有效敌人，每名只结算一次，保护自己、队友和自己的宠物，并尊重服务器PvP开关。
- 星步：沿视线水平方向短移，距离不超过5格，高差不超过1.5格。检查完整身体路径、碰撞、液体、危险落点和世界边界；被墙完全挡住时不开始施法，释放时再次校验落点。不提供无敌、回血或穿墙。
- 玩家法阵使用独立同步实体与Boss共用的粉白星纹/落晶几何；法杖在祈愿蓄力时展开咒页，释放或取消时回收。四个法术各有独立64×64图标及中英文说明。
- 原生取消施法立即撤销尚未释放的阵；释放后12tick淡出；施法者死亡、离线或离开维度后阵消失。法阵不写入存档，防止重载遗留攻击；实际伤害仅在服务端施法入口结算，不由视觉实体重复触发。
