# 万棱星狱：三轮递增

- 每次使用连续施放三轮：30 → 60 → 120 束，共 210 束；单轮硬上限 120。
- 各轮保持原 120 tick 活动期（普通难度），通过提高生成密度翻倍；高难度沿用时间加速，但不会因整除产生数量漂移，同 tick 可以生成多束。
- 每束保留原预警、锁定后不追踪、方块裁剪、伤害与淡出。每五束至少一束瞄准玩家，后续轮次的锁定频率也相应提高。
- 轮间等待全部预警、攻击和淡出完成，立即开启下一轮；只在第三轮后休整。普通难度总计 440 tick（22 秒）。
- 同步当前轮次、轮次起点、数量；客户端最多绘制本轮 120 束，保留专属 3D 激光模型。场地倒计时每轮重新开始。
- 无有效玩家、禁用 AI、死亡或取消均终止整组三轮；重新施放从首轮 30 束开始。
- 专项验证：规则检查、源码接线守卫及 QizaiLaserBarrageGameTests，覆盖三轮实际生成/发射/收尾、取消及重新施放。
