# 蛋蛋命中：周边三格随机传送

2026-09-20。

- 成年蛋蛋 Boss 对生存玩家造成实际生命值伤害后，在该服务器 tick 结束时随机选择安全落点；近战、拥有蛋蛋来源的投射物和法术均覆盖，不给玩家持有的武器或其他 Boss 附加此机制。
- 每次有效命中随机的是落点，不额外设置概率。一个玩家同一 tick 的多段伤害合并为一次传送，不改变原有伤害、技能伤害拆分或攻击频率。
- 目标与玩家当前脚部位置的三维直线距离不超过 3 格；至少移动半格。只选择已加载区块、世界边界内且身体有足够空间的落点，必须有可站立的碰撞面。
- 避开液体、岩浆块、仙人掌、营火、细雪、火焰、甜浆果丛和凋零玫瑰；没有安全位置便不传送，不使用远距离或无落脚点兜底。
- 传送使用服务端玩家同步，清除旧速度和摔落累计，附带传送粒子与音效。取消、零伤害、仅抛事件但未实际扣血、死亡、创造/旁观模式及跨维度的待处理命中不会执行传送。
- 安全落点搜索复用 `ManorSafeTeleport`，同时检查玩家身体覆盖的区块已加载；常规庄园传送的现有搜索范围不变。
