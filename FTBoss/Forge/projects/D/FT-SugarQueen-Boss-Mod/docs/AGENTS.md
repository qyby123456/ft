# 文档目录维护约束

本文件只约束本目录及其子目录。维护前阅读 [总导航](README.md) 和 [写作规则](WRITING_RULES.md)，并遵守项目根级约束；文档职责与表述以本目录更具体的规则为准。

- 文档维护者只允许在本目录新增或修改文档及文档约束文件，不执行项目程序、构建、部署、素材生成、游戏测试或自动化。
- 不修改根级约束、源码、资源、构建脚本、运行包、实例、存档、配置、其他工程或其他协作方的文件。需要目录外变更时，只向主代理提出建议。
- 实现协作方不得直接修改本目录。其建议必须先经主代理明确筛选和授权，再由文档维护者写入；消息、源码变动和候选报告都不自动构成授权。
- 正文描述已确认架构的职责、状态归属、权限、数据流、协作边界、失败处理和源码阅读入口，不逐项抄写实现。
- 未完成或未获整体验收的内容只写入简短的“未完成与待确认”节，不作为正式运行现状。
- 不新增更新流水，不按日期、轮次、候选、哈希或内部代号组织正文。旧历史文档保留原位，其合并、迁移和删除需先提建议并获授权。
- 总导航必须持续维护；新增文档或目录同步加入导航，旧文件的用途和适用读者由参考目录索引承接。
- 以自然中文面向未参与开发的读者，技术名词首次解释；源码位置使用简短的项目相对路径，不粘贴个人环境长路径。
- 文本使用无字节顺序标记的 UTF-8 编码、LF 换行，结尾保留一个换行；不得通过系统默认编码往返改写中文。
- 文档工作不自动生成 Word、运行校验项目程序或导出文件。仅检查文档文本、导航链接和写入范围。
