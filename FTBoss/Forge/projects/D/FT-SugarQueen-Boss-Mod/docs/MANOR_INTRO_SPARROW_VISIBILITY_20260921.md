# 庄园开场：隐藏麻雀本体

截图中的穿插来自开场演出的麻雀实体与中央纹章重合。开场仍保留实体作为位置、召唤者和难度的服务端锚点，但不渲染它。

- `HiddenBossIntro.start` 在实体加入世界前设置专用同步隐藏状态，仅作用于麻雀变体。
- `EasterBossRenderer.shouldRender` 跳过整个实体渲染入口，本体、手持武器、名字和阴影一起隐藏；不使用会留下装备的普通隐身效果。
- 演出完成、取消或清理时解除隐藏。原有 46 秒时长、开场模型和结束后的麻雀支援逻辑不变。
- 隐藏状态随实体数据同步，覆盖中途进入视野的玩家；不写入存档，避免重载后遗留永久隐藏。
- 普通支援麻雀、其他 Boss、玄蓝升空隐藏逻辑不受影响。

验证入口：完整 `build`（含 `checkManorCeremony`）及 `tools/verification/manor_intro_protection_gametest.gradle`。新增开场隐藏/同步恢复、取消恢复测试，并在原完成演出测试中检查恢复可见。
