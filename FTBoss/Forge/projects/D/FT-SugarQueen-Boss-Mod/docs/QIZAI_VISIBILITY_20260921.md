# 祁崽预警可见度增强

- 普通预警由浅粉白改为饱和橙红；收缩倒计时和束芯改为金色，水晶保留深紫主题，高束使用饱和蓝。
- 使用独立 POSITION_COLOR 半透明材质，取代加法发光：亮色地面不再把彩色预警加白。仍保留深度测试，不透墙、不写入深度。
- 地面圈、十字边线、天陨 48 格边界及计时圈加粗。固定边界不扩大；绯星边线向内加粗，保持真实束宽。
- 军械库激光、多角度棱晶锁定线、独立水晶预警增粗并提高最低透明度；锁定阶段不再依赖暗淡的脉冲线。
- 低粒子设置保留同样的颜色、关键线宽和最低亮度，不新增全屏闪白。
- 不改变伤害、技能范围、时长、数量、冷却、飞弹寻路或 Boss 皮肤。共享祁崽卷轴预警也同步获得更清晰的几何。
- 新增 checkQizaiVisibility：实际几何在雪地、草地、夜间三种背景的离线投影、像素可见性、线宽与材质/批次检查。离线预览不是游戏截图，光影包实机表现需进一步观察。
