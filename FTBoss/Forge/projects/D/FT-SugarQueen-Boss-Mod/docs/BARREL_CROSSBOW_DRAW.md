# 酒桶弩拉弦动作（2026-09-16）

## 实现
- 保留用户提供的 Java 模型、128×128 贴图、物品 ID、伤害和弹药规则，不转换 GeckoLib，不重画武器。
- `BarrelCrossbowModel` 在 Forge 模型烘焙完成后接入：固定桶身、左右弩臂、滑块、两段弓弦分别变换。
- 拉弦进度按物品使用时间计算，101 档姿势缓存，smoothstep 缓入缓出；不在渲染时推进计时，不共用玩家状态。
- 两侧弩臂绕根部镜像收拢 22.5°，滑块后移 16 模型单位，两段弓弦实时连接弩臂与中间卡扣。
- 长按 25 tick 拉满；快速装填 I/II/III 对应 20/15/10 tick。提前松手恢复空弦，不消耗酒。
- 拉满松手后保持张弦；发射后回到空弦。保持原有长按松手装填、再次右键发射的操作。
- 继承 `CrossbowItem` 使原版第一/第三人称识别持弩动作；装填与发射仍由酒桶弩覆写，不调用箭矢发射。
- 装填只在服务端扣除弹药并写入状态；同步原版 `Charged` 标记，兼容已有装填物品。
- Boss 齐射前增加 25 tick 拉弦，再保留原有 20 tick 的装填预告；不改变齐射冷却。
- Boss 进度使用 `SynchedEntityData`，客户端插值；滚动等动作期间收回，暂停战斗时不空放。
- 原图中的零面积侧面 UV 越界随弓弦拆分一并移除；删除 Java 不支持的 `on_shelf` 显示槽。
- 装填完成不再切换第一人称 display 偏移，避免武器瞬间跳位置。

## 资源再生成
`node tools/model3d/gen_barrel_crossbow_draw.cjs [输出目录]`

输入固定为 `ref/barrel_crossbow_draw_original.json` 与 `ref/barrel_crossbow_ready_draw_original.json`，不会反复拆分生成物，也不修改其他武器。

`node tools/model3d/check_barrel_crossbow_draw.cjs [工程目录] [预览 PNG 路径]`

检查 101 档姿势的左右对称、弓弦端点与弩臂同步、中间连接、滑块位移、静止姿势和 UV，输出五帧俯视及斜视预览。旋转使用工程公共 `cube_space.cjs`，动画常量从 Java 源码读取。

## 游戏内验收
1. 背包带啤酒，主手和副手分别长按右键：弩臂和弓弦逐渐后收，松手不足时间不装填。
2. 拉满松手：弓弦与卡扣留在后方，酒只扣一瓶；再次右键发射，恢复空弦。
3. 快速装填 I/II/III：模型动作与对应的装填时间一致；无酒时不启动动作。
4. 第一/第三人称、左惯用手、两名玩家各自拉弩：动作互不串台；未使用的另一把弩不跟随。
5. 酒桶王齐射前逐步张弦，保留一秒装填预告；射出后回到空弦。
6. 重载资源后复查模型和贴图；重新打开旧存档检查已装填酒桶弩仍可直接发射。

编译和离线预览不能代替实际游戏验收；最终交付说明需分别报告这两项。
