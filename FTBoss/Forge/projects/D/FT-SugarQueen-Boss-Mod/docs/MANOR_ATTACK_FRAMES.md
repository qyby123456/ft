# 庄园 Boss 攻击无视玩家受击无敌帧

`ManorAttackFrames` 在 Forge `LivingAttackEvent` 阶段判定伤害归属，在原版受击冷却检查之前放行庄园来源的伤害。不能只在 `LivingHurtEvent` 里处理，低伤害的后续命中可能根本到不了那里。

- 所有庄园 Boss 变体生效，包括独立生成的 Boss，不要求处于正式庄园战。
- 覆盖近战、原生技能多段伤害、铁魔法、投射物和有明确主人归属的召唤物及其后代。
- 无实体来源的技能沿用 `ManorMercy.withOwner` 的临时伤害上下文；庄园生成的实体闪电通过原版 `thunderHit` 结算并携带该上下文，不重复伤害。
- 只在每次庄园来源攻击到达时清除受击冷却；命中后仍由原版恢复受击冷却。不永久移除玩家无敌帧，不改变普通怪物、玩家武器或自然雷电的规则。
- 不绕过创造/旁观模式、玩家自身无敌标志、重生保护、护甲、抗性、盾牌或已取消的攻击事件。不改攻击频率、技能脉冲间隔和持续状态效果的原版计时。

验证入口：`tools/verification/manor_attack_frames_gametest.gradle`；用真实服务器玩家验证事件注册、连续命中完整结算与非庄园伤害的冷却隔离。
