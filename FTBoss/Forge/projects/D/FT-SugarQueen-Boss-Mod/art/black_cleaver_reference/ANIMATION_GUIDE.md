# 黑切血怒动画 · 编辑与接入说明

## 编辑入口

用带 GeckoLib 插件的 Blockbench 打开 `black_cleaver.bbmodel`，在动画面板选择 `animation.black_cleaver.blood_showcase` 即可查看完整循环；单独调整时选择相应短动作。所有动作均为实际骨骼关键帧，不是视频专用的平面变形。

命名统一带 `animation.black_cleaver.` 前缀：

| 后缀 | 时长 | 作用 |
| --- | --- | --- |
| `idle` | 3.00 秒，循环 | 常态核心微弱呼吸，握点和柄身不漂移 |
| `charge` | 0.40 秒 | 短促核心蓄能提示 |
| `slam` | 0.65 秒 | 常态蓄势、重劈，末尾交给 `recover` |
| `recover` | 0.30 秒 | 重劈后回稳 |
| `ready` | 0.45 秒 | 就绪脉冲 |
| `blood_pose` | 1.40 秒 | 0°→11° 四翼线性展开校准，不用于游戏触发 |
| `blood_enter` | 1.40 秒 | 核心蓄能、四翼错峰展开 |
| `blood_idle` | 2.40 秒，循环 | 稳定张开、双拍核心脉动、刃翼微回压 |
| `blood_slam` | 0.65 秒 | 血怒蓄势、快速释放、回震 |
| `blood_recover` | 0.30 秒 | 血怒重劈后回到张开姿态 |
| `blood_exit` | 1.40 秒 | 分层熄光、缓慢合拢 |
| `blood_showcase` | 9.75 秒，循环 | 交付预览，不注册到游戏控制器 |

曲线以 30 fps 加关键动作时刻烘焙，GeckoLib 逐帧线性插值；不是每秒只有几个生硬的折点。核心只在 XY 平面微缩放，Z 不缩放，以免红色嵌件脱离中心座。

## 血怒节奏

1. 入场前 0.16 秒核心收紧，随后回弹发亮；接缝先获得能量。
2. 左上、右上、左下、右下略错开，最迟约 1.36 秒张开到 ±11°，1.4 秒完整衔接循环。
3. 循环每 2.4 秒出现强、弱两拍；核心振幅约 5.5%，翼角回压不超过约 0.48°。不让四片厚刃像翅膀一样持续扇动。
4. 重劈在 0.28～0.30 秒停住蓄势，0.38 秒释放，0.42 秒达到随动角度峰值，再以回震和 0.3 秒回收表现重量。
5. 退出时先降低刃口强度，再退去刻痕和接缝亮度，闭合末尾仍保留很弱的核心底光。

预览里的重劈只有武器自身骨骼动作，没有伪造玩家手臂、命中目标或地面碰撞。0.38 秒是本动画的视觉释放点，不代表服务器伤害当前已与之同步。

## 发光曲线

`black_cleaver.effects.json` 是随模型交付的自定义效果数据，不是 GeckoLib 支持的内建文件。四个通道分别是 `core`、`rune`、`edge`、`seam`，对应同图集 UV 的四张独立遮罩；按秒采样其中强度，再传给客户端全亮渲染层。

正式采样循环时，骨骼动作与发光曲线共用相位，并将时间按各自循环时长取模；切换动作时重置或继承约定的相位，不可各自用独立墙钟计时。

这些遮罩在生成时已分离，核心、刻痕和刃缘不会强行用同一个脉冲亮度。旧接口合并贴图仍保留，但不能把旧合并发光层与新独立层全部叠加，否则会重复加亮。

Blockbench 里的默认主贴图可查看几何动画，但不会自动产生视频里的分层发光。MP4 / GIF 是使用真实几何、导出动作和这些遮罩进行的离线预览，没有实机光影包、泛光或粒子保证。

## 正式接入时的约束

本版已完成正式接线：`CleaverBloodVisualState` 为每把斧维护独立的 tick 时钟，`CleaverMotionData` 读取导出资源，`CleaverMotionPlayback` 处理启怒、循环、退怒和中途反向，`BlackCleaverGeoRenderer` 使用绝对姿态绘制并在绘制后还原共享骨骼。

- 旧渲染器的 `base + angle` 额外展开已移除，不再重复叠加四翼角度。普通与血怒重劈均由 `CleaverSkillController` 接收原有 GeckoLib 同步事件，发光层读取同一技能秒数。
- 保持现有每把 ItemStack 独立的状态，不能改成全局单一开合进度；快捷栏 GUI / 掉落物的绘制不得反向重置手持状态。
- 客户端 tick 推进状态、渲染帧只采样与插值。攻击动作优先，血怒待机让位，攻击结束衔接 `blood_recover → blood_idle`，避免循环重置劈砍。
- 血怒中途结束时，从当前姿态向闭合姿态平滑混合，不从完整展开第一帧跳起；快速开关还对核心振幅及发光强度限幅，防止多次中断累积放大。
- 普通技能名及时长保留原接口，但当前服务端的砸地伤害在触发动作时立即计算。正式接入本版 0.38 秒视觉释放点时，应单独审查技能判定时序，不能仅换美术资源就宣称命中同步。
- 不对 `root`、`grip_anchor` 写动画；整武器旋转以握点为枢轴，不平移、不缩放握柄。
- `blood_pose` 和 `blood_showcase` 是校准/演示用，正式控制器不注册它们。

本次保留原有伤害、范围、冷却、血怒获取和服务器命中时序；没有借模型部署修改战斗规则。后续如需让命中延迟到视觉释放帧，应作为独立玩法调整确认。

正式包通过编译和专项逻辑测试后，仍需在游戏内验收第一/第三人称、左右手及实际光影表现。可用 `/ftcleaver give` 获取武器，`/ftcleaver blood` 开启血怒，`/ftcleaver noblood` 检查退怒；右键验证重劈。测试命令需要 OP 权限。游戏运行中不得替换 Jar，部署须走工程进程保护脚本。
