# 庄园掉落武器：攻击力与技能伤害翻倍（2026-10-18）

## 范围

以当前 Forge 1.5.2 已安装的 `qys-bosses.jar` 为基线，在当前数值上再乘 2，不回退到最初版本的数值。

从实际庄园战利品目录核对 20 个不同物品 ID，排除 `ftboss:black_cleaver`（黑色切割者）、`ftboss:statue_youzi`（柚子小像），其余 18 个 ID 生效：

- 蛋蛋镰刀；朵拉鸣脉冲锋枪、地脉脉冲枪、鸣脉长枪。
- 柠檬猫双武器；青衣四把 `tridents_n_stuff` 三叉戟及四象归一戟。
- 玄蓝绿枪与白刃（共用物品 ID）、暗影剑、河豚棒。
- 麻雀祝福羽、雪黎双武器、祁崽祈愿法杖。

## 结算

- 主手物品攻击力按原有效面板翻倍，计入原版默认 1 点攻击；无 ADDITION 修饰符的物品也支持。四象归一戟此前不在公共主手强化目录内，单独按其原有效面板翻倍，不补发两轮旧加成。
- 只处理物品自带攻击属性，不放大角色其他装备、力量药水与额外锋利附魔；攻速及现有乘法修饰符保留。现有武器自动生效，不写入物品 NBT，也不会反复乘倍。
- 普通技能伤害及追加印记伤害走专用规则；枪械、玄蓝双形态与外部三叉戟走各自原入口，避免面板和通用受伤事件叠乘。
- 四象归一的玩家技能翻倍，Boss 分支覆盖的伤害计算原样保留。
- 四象归一戟的普通投掷命中同样乘 2，不遗漏原版三叉戟继承的命中路径。
- 内嵌 TnS 的回响固定附伤、星辰冲击附伤、风暴击杀闪电与引雷闪电在对应庄园三叉戟归属玩家时乘 2；攻击属性衍生的回响范围伤害已随面板提升，不再额外乘一次。非庄园三叉戟、Boss 与血腥契约的技能/吸血不变。
- 祈愿法杖是铁魔法施法道具：仅玩家造成的 `SpellDamageEvent` 在主手或副手持杖时乘 2，双持只乘一次；不修改铁魔法 JAR、法术等级、魔力或治疗，普通攻击由面板负责，不被法术钩子再次放大。法杖的加成按伤害发生时的持有状态判定。
- 麻雀羽和柠檬猫治疗、Buff 等级/时长、冷却、范围、耐久、控制效果不变。黑切和柚子小像的旧公共规则与原技能数值保持不变。
- 河豚毒云每跳 21 → 42，五跳 105 → 210；显示总量的保护上限 128 → 256，避免旧上限截断提示。

## 构建与部署

`build-test.ps1` 使用 Java 17 字节码，基于当前 JAR 方法级合并；只改 11 个已有主模组类、内嵌 TnS 的两个类共三个方法，新增 1 个纯规则类和 1 个定向伤害钩子。原有 3308 个外层 JAR 条目逐字节不变，未修改 Boss、模型、资源、掉落清单、黑切、小像与公共治疗规则。所有修改类另经 ASM BasicVerifier 检查操作数栈，内嵌 JAR 使用 JDK ZIP 工具重写。

`deploy.ps1` 在三把部署锁内重新备份当前 JAR、合并并验证，随后调用主工程 `tools/deploy_jar.ps1`，限定当前 Forge 1.5.2，带预期基线哈希和游戏运行检查。桌面、fix2、NeoForge 与存档不变。

- 以上为离线验证，不等同于 Minecraft/Forge 实机、GPU 或多人联机验证；未自动启动游戏。安装状态与备份位置见 `deployment.json`。

主工程同步文件包括纯规则、属性/法术钩子、所有相关技能入口、更新后的数值检查、方法级合并工具和本说明。原源码备份在 `source-before/`，完成快照在 `source-after/`。
