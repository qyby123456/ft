# Material rarity bonuses

额外数值只用于白名单内已支付、已装入、已解锁且整件武器可用的实物材料；原生参考格不额外给数值。一次属性查询会重新经过已有权威验证，不缓存武器权限或交易结果。先按最多27格做有界ID预筛；不含相关实物的武器直接返回零，不额外执行复杂验证。不新增tick、背包扫描或实体生成。

- 铁魔法31种原料：普通、卓越、稀有、史诗、特殊灰烬品质，分别法强+1/2/3/4/5个百分点，蓝量+5/10/20/30/40；墨水品质与较高阶合成原料设最低档。原料使用空白物品的原生品质，自定义NBT或附魔不能把品质抬高。
- 灾变24种、传奇怪物10种原料：按原生稀有度及Boss来源最低档，1至5档分别攻击+0.5/1/1.5/2/2.5、护甲+0.25/0.5/0.75/1/1.25、生命+1/2/3/4/5。不是复制Boss被动，不生成闪电、爆炸、召唤物或范围伤害。
- 同种物品ID只计一次；秘银碎片/粗秘银及指定金属粒/珊瑚碎片只按1档，避免碎料等同完整锭。
- 每把武器独立上限：法强+25个百分点、蓝量+200、攻击+8、护甲+4、生命+12。主副手用不同稳定UUID，分别生效；头盔等非手持槽不生效。
- 仅手持原料或放在背包不会有属性；移除原料、损坏武器、非法结构或数量不为1都会撤去加成。切换武器由Minecraft装备属性机制更新，不对玩家永久写值，不改NBT协议。
- 原料悬浮提示直接展示单件配件加成；武器属性通过原有装备属性提示展示。不会新增按键或输入框。
- 攻击属性是角色近战攻击属性，不宣称等量提高每一种模组弹射物/法术的伤害。灾变与传奇怪物材料的生命和护甲对各武器类型均适用。

额外源文件：util/WeaponMaterialBonusRules.java 和 item/WeaponMaterialBonuses.java。最终仍只改原有一个准入表class，另新增4个class（含两个纯规则record）；其他4118条目内容字节不变。
