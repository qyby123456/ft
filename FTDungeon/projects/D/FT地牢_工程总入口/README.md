## 刷新与核验

原线程会继续更新源文件，需要刷新时在PowerShell执行：

```powershell
& 'D:\ft工程文件\FT地牢_工程总入口\更新索引.ps1'
```

脚本只重建此总入口下的索引和快捷方式，随后核对目标、工作区和入口SHA256。整理结果见 `整理核验.json`；若活动线程在整理过程中更改入口，会单独列出，不回写或覆盖该源文件。
