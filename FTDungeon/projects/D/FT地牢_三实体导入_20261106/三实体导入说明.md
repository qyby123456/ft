# FT地牢 0.24.0：三实体导入

基于已安装的 FT地牢 0.23.0 三生成器合并版制作，保留混沌、月蚀、紫晶群系三种生成器；原工程与下载目录中的三份 bbmodel 保留。

- 幽灵尖啸：`ftdungeonmobs:ghost_screamer`，待机、移动、攻击动画，基础近战AI，24生命、4攻击。
- 矿石怪：`ftdungeonmobs:ore_monster`，待机、移动、攻击动画，基础近战AI，40生命、6攻击、8护甲。使用源模型实际引用的煤矿纹理。
- 骷髅商人：`ftdungeonmobs:skeleton_merchant`，待机、移动、交易动画，原版交易界面与交易存档，默认销售面包、箭和金胡萝卜。

各实体的刷怪蛋ID为实体ID后加 `_spawn_egg`，收录于FT地牢创造栏与原版刷怪蛋栏。

月蚀地牢新生成的补给商直接使用骷髅商人。经典地牢维度、月蚀地牢及混沌地牢中已有的村民，在实体开始正常tick时替换为骷髅商人；保留UUID、名字、坐标朝向、交易报价与使用次数、无敌/AI标记、标签和Forge持久数据。其它维度的普通村民不替换。替换在运行时完成，不离线编辑玩家世界文件。

保留全部132个原始方块组件、74个骨骼和9段动画。通过Blockbench内置Bedrock几何和动画导出器导出为GeckoLib资源。源模型与规范化模型及校验摘要保存在 `output/creature-import/`。矿石怪文件内有11张内嵌纹理，几何实际仅引用第0张；游戏资源仅导出被使用的纹理，原始文件完整保留。

本次只增加实体与刷怪蛋、替换商人，不自动扩大地牢随机怪池。完整游戏重启后加载新版本，联机客户端与服务器使用同一版本。

构建：`./BUILD.ps1 -Task build -Offline -GradleOptions @('-x','verifyDungeonArchitecture')`。

原工程的石棺已有共面重叠面，`verifyDungeonArchitecture` 会失败；本次保留该资源，并在原工程复现相同失败，日志为 `output/creature-import/baseline-architecture.log`。其余构建及运行测试结果见同目录日志和发布验证记录。Blockbench中已检查三份模型外观；尚未在完整整合包客户端验证实机画面与动画。

原生Forge GameTest已通过全部12项：新增实体属性、刷怪蛋、近战伤害、交易保存重载，三个地牢维度的旧商人迁移及主世界村民保留，以及地牢菜单、三生成器注册、混沌建造与传送、月蚀生命周期和存盘回归。迁移测试驱动实际村民tick，并通过Forge实体加入事件和原生实体管理器标记确认新商人成功加入，避免把未进入可见区块的实体查询结果当成迁移失败。日志：`output/creature-import/gametest-final.log`。

发布包：`release/FT地牢-Forge-1.20.1-0.24.0.jar`。安装脚本 `安装三实体版.ps1` 核对已安装0.23.0和候选包SHA-256，备份旧JAR后只保留一个活动FT地牢包；记录保存在 `release/installation.json`。不修改其它模组、配置或玩家世界文件。
