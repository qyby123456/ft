# 普通房掉落与定价

## 配置

配置位于 `data/<namespace>/loot_stands/<id>.json`。默认配置 ID 为 `ftdungeonloot:ordinary`，运行示例见 `src/main/resources/data/ftdungeonloot/loot_stands/ordinary.json`。

| 字段 | 含义与约束 |
| --- | --- |
| `category` | 必须为 `normal_chest`，不接受 Boss 类别。 |
| `dimension` | 允许补货与购买的维度 ID。 |
| `currency` | 实体物品 ID；不存在或为空气时停用，无账户余额桥接和备用币。 |
| `round_source` | `ftdungeon` 跟随入口火炬活动轮次；`manual` 使用本维度手动 SavedData。缺省为 manual，生产示例明确设置 ftdungeon。 |
| `loot_tables` | 1～32 个不重复的显式普通房宝箱表；路径须以 `chests/` 开头且不能包含 `boss`。 |
| `item_values` | 1～4096 项，每件基础价值为 1～1000000 的整数。未知注册物品不会被虚构出来；掉落后无价值项则不在展示台售卖。 |
| `price_percent` | 1～10000 的整数百分比，默认示例 50。 |
| `enchantment_level_value` | 每一级附魔的附加价值，0～1000000。 |
| `minimum_price` / `maximum_price` | 1～1000000，最大值不得低于最小值。超过最高价直接不上架，不压低到上限出售。 |
| `coin_min` / `coin_max` | 每箱每轮另附实体金币，0～4096，最大值不得小于最小值。可用于禁用金币或限制产量。 |

定价先计算 `(单件基础价值 + 附魔等级和 × 等级价值) × 商品数量`；可损耗物品再按剩余耐久比例向上取整，最后按百分比向上取整并应用最低价。完全损坏、空物品、币本身、单叠超过合法堆叠数和超最高价不售卖。运算用大整数，避免溢出意外变低价。NBT 被原样保留，但除附魔与耐久外不自动推断任意自定义 NBT、品质或技能的价值；需要用明确价表/其它集成再拓展。

## 不纳入 Boss

代码只使用管理员选择的普通房表白名单和明确绑定容器，默认池仅包含普通材料、食物和装备。不会扫描实体掉落表、Boss 奖励、全部宝箱注册表或已打开容器。

**白名单不是智能的 Boss 语义识别器。** 数据包作者仍不能把 Boss 战利品改名后混入普通表、在白名单表里嵌套 Boss 引用，或故意在 Boss 房执行普通箱绑定。路径过滤只是辅助防错。默认交付表没有嵌套 `loot_table` 引用；自定义数据包由管理员审核语义。未声明的现有箱子和 Boss 箱子保持原状。

## 结算和持久化

- 展示台保存本轮 ID、商品完整 ItemStack、数量、报价、货币与售罄状态；断线、卸载、读档不恢复库存。新放置的台子无绑定，破坏不携带交易 NBT，不能普通重放刷库存。
- 玩家待确认报价检查维度、坐标、方块实体实例、版本、目录版本和完整报价签名。副手交互不结算；超时和改价需重新预览。普通原版客户端长按可能再次发包，不声称识别鼠标是否松开。
- 付款仅取主背包与副手中的普通货币；商品只入主背包。先完整模拟扣费和插入，再核对库存快照、一次提交；无零钱返还需求，付款按金币个数精确扣除。
- 宝箱绑定和已生成轮次标记保存在宝箱 ForgeData，与容器物品同区块保存，避免把一次生成标记单独写在另一个账本。只有整份战利品和金币均能装下才生成，溢出不发半份、不扔地上。
- `/reload` 不自动刷新本轮商品；新轮次按新配置生成。未清空旧箱不会覆盖其物品，清空后本轮仍只能补一次。
- 原版容器可被管理员或其它模组搬运、清 NBT、复制，服务器异常回档也可能回退数据；本候选不承诺跨插件或跨区块掉落回档事务。地牢冒险保护由 FT 原模组负责，本模组不接管世界领地。

## 轮次桥接边界

默认仅通过反射读取现有 FT `DungeonGateData.get(MinecraftServer)`、`roundActive()`、`roundId()` 公开方法，不写其状态、不依赖旧包内部字段。已对本机 0.20.0/0.20.1 源码接口做只读核对；独立 Forge GameTest 验证的是缺失桥接时失败关闭和手动夹具生命周期，**不是完整 FT 模组联合验收**。

所有随机结果由台子持久种子/箱子坐标与轮次种子固定。货币或接口缺失不变通放币；空池也不单独产金币。手动轮次仅供建图测试或自定义地图，不会替普通玩家暴露重置命令。
