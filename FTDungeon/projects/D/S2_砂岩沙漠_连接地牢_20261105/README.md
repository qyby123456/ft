# 第二组：砂日古国·九域连通地牢

以第二组已验收的 01—09 九份砂岩房间源重新合并，不使用第 10 张总览代替拼装，不修改原始房间文件。

## 布局

入口双门庭院 → 旗帜列柱主殿。主殿分出三支：

- 主轴：积沙长廊 → 砂岩祭台厅。
- 西侧：单箱遗迹庭院 → 藏书蓄水室 / 折角灯龛廊。
- 东侧：树影跌水庭院 → 砂日纹饰宝藏室。

整体 162×31×190；九个房间、八条新建带顶灯笼通道，通道内宽 7 格，门口按原模块接口尺寸保留。各模块以不同底部高度对齐接口脚底，不旋转、不切开室内台阶。未使用的旧接口以切制砂岩封口，门框周边以砂岩补缝。入口原有门改为打开，便于静态通路检查。

联合房间与通道外侧为一层原版屏障，包含顶部、底部和入口站位。屏障不挡内部连接；无法限制旁观、传送或创造破坏。

## 文件与安装

- `sandstone-connected.nbt`：完整密集源，954180 个显式格，包含空气与屏障。导入会清除占位盒内原地形，不能直接覆盖正式建筑。
- `parts/`：16 片，各维不超过 48；`assembly.json` 记录共同原点和哈希。分片总状态与方块实体负载已逐格复核。
- `s2-connected-datapack.zip`：Java 1.20.1 数据包；函数 `s2_connected:assemble` 使用固定共同锚点，不可逐片独立旋转。
- `layout.json`：九份源路径/哈希、各原点、通道、门框补缝和全部声明室内变化。
- `qa/`：当前新组合的原生注册、模板回读、静态支撑与路线检查，不继承旧总览的世界验收结论。
- `overview-complete.png`：完整源渲染；`overview-cutaway.png` 仅为显示剖视，不是无顶导入源。

独立测试存档名：**FT 第二组 · 砂岩沙漠 · 九域连通地牢**。建筑已写入区块，无需执行生成命令。部署源底角为 `(0,-60,0)`，入口外站位 `(84,-55,1)`，朝南进入。

保留第一组及其他已有存档；不修改 mods、全局配置或 KubeJS。新存档为和平、创造建筑检查版，关闭随机刻和自然刷怪；**第二组没有复制第一组固定坐标的怪物/精英/Boss 数据包**，战斗配置需针对新布局另行制作。
