## 建筑

49×49 围墙庭院，57×65 覆雪地景，另有 32 格连接旧大厅的石路。冰封喷泉、四块霜花坛、十字石径、雪松、积雪廊架与长椅、冰湖、兜帽石像、灵魂灯和开放式铁栅拱门均使用真实原版方块搭建。

建筑位于现有 `ftdungeonmobs:dungeon` 维度，中心 `(0, 64, 80)`；旧落地大厅和返程门 `(0, 64, 0)` 保留。普通入口、个人返程记录、五档火盆和门的五分钟入场规则不修改。新增的可选挑战使用原版怪物，不读取或改动 FT 怪物的五档数值。

## 使用

1. 先完整重启游戏，让 Moonlight 载入全局数据包。安装数据包本身不会改建世界；如函数不在补全列表，先用 `/datapack list available` 检查，必要时执行 `/datapack enable "file/ft-frost-garden-1.20.1.zip"`。
2. 正常通过现有地牢入口进入旧大厅，保留个人返程记录。
3. 管理员执行 `/function ftfrostgarden:install`。安装前检查所有将被写入的方块和庭院通行空间；非原始平地、有建筑或已安装时拒绝覆盖。只在这条命令执行后生成庭院和连接路。
4. 从旧大厅南侧沿蓝灯石路前进，到达花园。管理员预览可用 `/execute in ftdungeonmobs:dungeon run tp @s 0.5 64 58.5 0 0`。
5. 玩家在院内执行 `/trigger ftfg.start`，开始 10 秒准备；队友在准备期间执行同一命令主动加入。三波守卫后出现精英「霜庭守望者」，胜利解锁北侧奖励桶。普通访客不会自动加入。
6. 沿原路回大厅，经原返程门返回；也可使用现有 `/ftdungeonreturn`。管理员中止挑战使用 `/function ftfrostgarden:reset`，不拆建筑、不重置已领取宝物。

数据包仅支持一个固定坐标庭院。`/place template ftfrostgarden:garden <x> <y> <z>` 可另放纯建筑模板，但不会迁移固定坐标挑战逻辑，也不会自动进行防覆盖检查。

## 安全与限制

- 只适配现有 Forge 1.20.1 地牢平地：Y=61/62 深板岩，Y=63 磨制黑石砖，Y≥64 空气。已经装饰过的目标区域不强制清空。
- 建造/挑战临时加载必要区块；只释放本包新增的强加载，不移除已有强加载。未开始挑战时没有强制常驻区块。
- 仅清理院内带本包专属标签的敌人，不对其它怪物、玩家、掉落物或其它维度使用范围清除。
- 每轮 5 分钟上限；参与者全部离开后 15 秒中止。胜利奖励只解锁一次，重打不刷新奖励。
- 冰使用浮冰、蓝冰与蓝色玻璃，不使用会融化的普通冰；雪使用雪块及雪层，不改变世界天气、时间或游戏规则。
- 原地牢没有天光，庭院补充原版不可见光源（10～11 级），让花坛在暗维度保持光照，且不以高亮光源烤化相邻雪层；不覆盖维度、天空或天气资源。
- 预览是从最终 NBT 方块导出的软件示意，不是游戏截图，不代表着色器或实机帧率。

## 工程与交付

- `tools/build_garden.py`：确定性结构、数据包、清单和验证生成器。
- `tools/render_garden.py`：读取最终结构和原版方块贴图的软件预览。
- `out/ft-frost-garden-1.20.1.zip`：可独立安装的数据包。
- `out/datapack/`：解包后的同一成品，包括两个 NBT 模板。
- `preview/`：整体、俯视与四向结构预览。
- `qa/`：结构、防覆盖、通行、资源和命令解析验证记录。
