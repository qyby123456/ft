# L2 · 霜雪花园中庭 · 北接口适配

仅适配并制作首批 L2 房间，不覆盖旧霜雪花园交付，不改 FT-Dungeon-Mobs 核心、不部署数据包/JAR、不写玩家存档、不跨聊天发送消息。

## 接口

- room.nbt：gzip Minecraft Java 1.20.1 单调色板结构，完整体积 21×12×21，5,292 条记录（含空气）。
- 围墙自主地面向上 5 格，庭院露天；12 格总高度包含大雪松和覆雪顶。
- 北接口：局部 Z=0、X=9～11、Y=1～3 全为空气。入口脚部 [10,1,0]，其下 Y=0 三列完整石砖。
- 模板内部 Z=1 有向南上升的石砖楼梯；主庭院脚部 Y=2，安全内点 [10,2,6]。干燥路线由北口到内点及绕冰泉的支路往返连通。
- 5×5 冰泉、四霜花坛、两雪松、廊架长椅、兜帽石像、枯树、灵魂灯及封闭冰湖都保留。原版花卉不是参考图里的自定义发光霜花；用隐藏原版光源保证低光环境存活。
- 水景共 17 格水源，池底和侧壁闭合，池顶浮冰封盖。浮冰不会融化；雪层全部有支撑且不直接铺在冰上。
- 无实体、方块实体、宝物、刷怪、命令方块、结构方块或拼图方块。

## 文件

- tools/build_l2.py：独立适配生成器，复用原工程的软件预览代码但不改原文件；从最终落盘 NBT 重新解码做预览。
- tools/VerifyL2.java 与 build.gradle：隔离 Forge 47.4.10 数据环境校验，检查原版方块状态、模板往返、水池六面密封与雪/植物支撑。校验 Mod 不部署。
- tools/deliver_l2.py：合并静态、真实原生格式和已查看四视图验收；只有全部通过才发布到 incoming/L2，拒绝覆盖不同文件。
- out/：本工程源交付；incoming/L2 是接入负责人读取的发布副本。

最终 incoming/L2 含 room.nbt、room.json、preview.png、qa.json，另附 four-views.png。预览主图剖切北/东侧上部墙便于查看内部；四向图和实际 NBT 围墙完整。软件示意不是游戏截图。

## 验收

实际 Forge 数据环境检查通过：37 个原版状态、5,292 格完整体积、17 格闭合水源、202 处受支撑雪层、8 株受支撑且有光照的花；入口至中庭和支路的 248 个干燥脚位连通。未打开玩家世界或进行整合包实机游玩。

接入时必须先检查整个模板体积/边界/占用，再依接入契约施工；不要因模板记录了空气就无条件清空目标区域。
