# 锈铜宝库地牢

按用户参考图制作的 Minecraft Java **1.20.1** 独立建筑。尺寸按 **X 宽 × Y 高 × Z 深** 为 **33 × 17 × 37**，含铜锈镶嵌墙、深板岩柱、三面金龛、三级宝台、中央双箱、四角火盆、四口悬钟、木桶堆与铁门前廊。主厅有完整屋顶，预览做了剖切。

这是原版体素尺度的重建，不是逐像素复制。1.21 铜格栅 / 铜灯分别用铁栏杆、金合欢活板门和红石灯替代；柜子用铜块、木桶和按钮组合。铜块均涂蜡，不再氧化。火盆为营火建筑装饰，不是 FT 竞技场火盆。

## 文件与导入

- `out/FT_Copper_Vault_20261101.zip`：完整交付包，含结构、数据包、两张预览、材料表、源码和校验报告。
- `out/ft-copper-vault-1.20.1.zip`：可直接安装的数据包，`pack_format=15`，无需解压。
- `out/FT_Copper_Vault_1.20.1.nbt`：Java 原版 GZip 结构模板，`DataVersion=3465`；不是 WorldEdit `.schem`。
- `preview/copper-vault-cutaway.png`、`preview/copper-vault-plan.png`：同一导出方块数据的剖切 / 俯视预览，非实机截图；铃铛、箱子的实体模型简化。

先在**测试存档**使用：将数据包 ZIP 放入该存档的 `datapacks`，进游戏执行 `/reload` 和 `/function ftcoppervault:help`。

创造模式玩家站在建筑西北角、最低基础方块的预定高度，沿 **+X 留 33 格、+Z 留 37 格、向上留 17 格**完整空气空间。区块全部加载后执行：

    /function ftcoppervault:build

函数先核查整个 20,757 格空域、区块、世界高度和其它实体，有障碍即拒绝施工，不会挖地。若站在 Y=64，基础从 Y=64 开始，地面方块在 Y=66，行走高度是 Y=67。入口朝北（-Z），成功后送到前廊。金压板可开双铁门。

也可用结构块或 `/place template ftcoppervault:treasury <x> <y> <z>` 直接放置。**原生命令绕过防覆盖检查**；本 NBT 含显式空气，会写入整个 33×17×37 包围盒，不要盲目放进已有建筑。结构块界面 48 格单轴限制内可容纳本模板。

## 安全边界

- 未安装到存档、全局数据包目录或房间生成池；未改动模组、核心、部署、现有建筑或游戏规则。
- 纯建筑，无自动刷怪、波次、结算、收费或 FT 挑战联动；没有 `tick` 函数、自动施工或常驻强加载。
- 独立版中央箱只配一份原版 `minecraft:chests/bastion_treasure`，四个边角木桶各一份 `minecraft:chests/simple_dungeon`；其它容器为空。首次打开时按原版规则生成，不另堆物品。
- 四个常燃营火有碰撞和伤害；金压板可能触发红石更新。灯背有真实红石电源，未强行保存无电的亮灯。
- 建造命令链低于原版默认 65,536 上限；自行调低上限、保护插件、边界和整合包方块事件仍需副本实测。移除数据包不会删除已放置建筑。

## 复现与质检

Python 3.10+ 可生成建筑；预览还需 Pillow、NumPy 及本机 1.20.1 客户端 JAR 中的原版模型 / 材质：

    python tools/build_vault.py
    python tools/render_vault.py --textures-jar "Minecraft-1.20.1-client.jar"
    python tools/make_m2.py --textures-jar "Minecraft-1.20.1-client.jar"

`tools/verify_native.py --classpath-file <ForgeGradle生成的1.20.1依赖classpath文本>` 使用本机缓存的原版客户端、官方映射和重命名工具制作仅供本地校验的派生副本，不修改原始游戏 JAR。交付不含游戏 JAR、映射、依赖或编译类。

校验覆盖：原生注册表和状态属性、NBT StructureTemplate 读写、双箱连接、29 个方块实体装载、按钮 / 铃铛 / 门 / 压板支撑、Brigadier 命令语法、全包围盒扫描覆盖、保护顺序、JSON / 函数引用、通路与压缩包完整性。

**这些校验不等于完整整合包实机放置或多人玩法测试**，本工程没有启动玩家世界。未向 image2.5 / wecodex 发起收费请求；原参考图与其它工程保持不变。
