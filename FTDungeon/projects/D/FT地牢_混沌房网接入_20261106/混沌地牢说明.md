# FT地牢：混沌房网接入

本候选为 Forge 1.20.1 / Java 17，版本 0.22.0。

玩家可选类型：

- 混沌地牢 · 强制连通房网：使用已归档的房网迷城R5，混合既有房间，通过成品交通模板连接，保留四层布局、支室、商店、守卫及终局Boss。
- 月蚀钟塔 · 四层随机地牢：沿用原生成器。

经典FT地牢已从注册表和选择菜单移除，也不再通过入口退回旧大厅。新门以及没有类型字段的旧门默认选中混沌地牢；保存为legacy且尚未绑定实例的门加载时转为混沌。其他未知或已绑定的旧类型保留原记录并拒绝进入，禁止重定向覆盖。

## 混沌生成流程

点亮门旁祭炉，管理员潜行右键完整入口门，在菜单选择混沌并点击生成。生成时将入口八格内1～16名非旁观玩家冻结为本局名单；人数决定完整体系房数量，沿用R5的max(1,floor(人数/2))规则。

门种子决定四个原版预烘焙R5布局之一，随后按原顺序分批放置全部房间和连接结构。这是原R5的四种布局选择，不宣称每次入场实时计算无限新拓扑。每份布局的原24室/层连通树、回环、楼梯及成品走廊数据保持不变。

所有结构放置和五个商店初始化完成前，门保持关闭。生成状态、布局、名单、入口和实例ID持久保存；重复点击不重新施工。每个存档当前仅支持一座R5混沌房网，后续进入复用它；其他入口要求使用原门，禁止覆盖玩家进度。结构放置失败会标记失败并保留现场。

混沌使用独立维度ftmaze:depths，与旧大厅和月蚀维度分离。只有冻结名单中的玩家可以通过门进入，进入时切为冒险模式。击败最终Boss后，原R5终点折返区调用本模组的个人返程逻辑，返回各自原入口位置并恢复原游戏模式；原入口被堵塞时保留返程记录。

原R5的怪物、商店和Boss设置随原函数移植；本次没有重做其数值与难度映射。保留FT旧方块和实体注册ID，以兼容已有存档中的建筑。删除经典生成选项不等于删除已有世界中的旧建筑。
