## 验证证据

- `qa/static.json`：20项静态断言，检查来源图完整哈希、全部3315个体积坐标、地基、双层屋顶、唯一北接口、干燥环路、安全点、水井/暗渠封闭、灯链墙钩及井盖支撑、禁用内容和无库存。
- `qa/forge-native.json`：隔离 **Forge 47.4.10 / Minecraft 1.20.1 / Java 17** GameTest。原生注册表及全部状态属性解码、`StructureTemplate`加载/保存、**0°、90°、180°、270°实际放置**，强制邻居形状/事件更新和水源流体tick，观察 **240 tick**。
- 每个旋转方向均完整保留 **3315条状态**、2个骷髅方块实体、33格封闭水源、18个闭合铁活板门、18格铁栅、4盏吊灯、30节锁链、4个墙钩和510格双层屋顶；**漏水0、掉落物0**。
- 原生碰撞体按0.6×1.8玩家体积核验。每方向 **141个干燥可达脚位**，入口、内部安全点、左右绕行、井后与后墙中央均可达。静态保守算法只认整格空气与整块地板，记录122格；它不把小型无碰撞装饰或闭合盖板当作整格地板，故数值不同，不是相互覆盖的假结果。
- `qa/roundtrip.json` 与 `qa/native-roundtrip.nbt`：原生往返后的3315条方块状态、2条方块实体NBT、尺寸、实体列表和DataVersion逐项一致；压缩字节或调色板顺序不要求相同。
- `qa/forge-run.log` 同时包含 `M07_FORGE_PLACEMENT_PASS`、`All 1 required tests passed`、`BUILD SUCCESSFUL`。首次服务器自动生成配置、缺失server.properties后自行建立、版本检查及旧API警告是测试环境日志，不是失败测试。
