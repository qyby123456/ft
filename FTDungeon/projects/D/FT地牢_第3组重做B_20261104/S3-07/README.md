## 门态、火盆及还原边界

参考图双门是闭合状态；本候选默认两扇门打开，保留玩家无需先交互即可进入的路线。这是明确的状态转译，不拿开门截图冒充原图闭门外观。门扇只高2格，是原版门尺度；未用不能开合的大木墙伪装可通门。NativeQA在原NBT门态下验证所有目标可达，再仅在内存把4个door状态的OPEN改为false，确认前外沿到后廊被阻断；不修改最终NBT、不声称测试了真实点击开门/红石/邻接同步。非门框全宽可走，真正瓶颈是2格木门洞。

火盆为真实lit campfire，接触可能受伤，位于石台Y8，离主轴x16侧移4格；它不是奖励容器。NBT方块实体只有minecraft:campfire的id，未含物品/配方/战利品/命令。不能把全室宣称无伤害块；世界火焰动画、烟雾、传播、伤害与雪冰行为未实机验证。默认Lodestone可能不显示完整营火动画，lit状态不依赖截图火焰是否可见。

冰笋/冰挂为方块近似，薄雪用整雪块或齐平雪地代替，山体为局部包围体而非整座地形；原图枯枝/纸地图细纹未复制。浅色板只是无字告示板视觉符号，木箱只是装饰，不虚构任务/奖励或隐藏机关。普通ice及snow雪层均为0，暖灯与营火周边用snow_block、packed_ice、blue_ice，未引入活水。
