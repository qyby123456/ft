# S1 外部进入与返回安装包（Java 1.20.1）

此包包含现有合并件的 33 个原始分片和 vanilla datapack 函数，不改变任何房间、家具、树林或屏障。普通玩家通过 `/trigger s1gate set 1` 进入、`/trigger s1gate set 2` 返回。管理员只负责安装，玩家使用 trigger 不需要 OP。

## 预留区域与安装

**安装函数会清空主世界整个闭区间 [9992,61,9998] 至 [10493,105,10139]。必须先预留无建筑、无容器、无实体、无其他工程强制加载任务的空地。包不会检查已有资产，也不会备份；请勿在已有建设区域运行。** 结构原点固定为 [10000,64,10000]，地面接待层站位为 [9995.5,62,10129.5]，返回台站位为 [9995.5,70,10129.5]，两层用带完整背板的原版梯子连接。清空范围和每个分片哈希见 installation-plan.json。本包没有在正式世界安装。

1. 将 `s1_access_1_20_1.zip` 放入目标存档的 `datapacks`，管理员执行 `/reload`。
2. 确认上述预留空地，再执行 `/function s1:install`。安装期间暂时加载分片范围；完成后自动解除这些强制加载。此安装命令只运行一次，重复运行会清空同一区域。
3. 将预留区外的步行道路整平并接至 y=62 的地面接待层。玩家可以从地面进入触发区，不依赖管理员先把玩家传送到高台。
4. 普通玩家在地面接待层或上层台面执行 `/trigger s1gate set 1`。目的地为合并件原起点 [10005.5,70,10129.5]，保留周界屏障。
5. 在结构内部执行 `/trigger s1gate set 2` 返回上层台面，再沿外部梯子下到地面接待层。返回功能覆盖整个结构范围，可用于正常退出与被困恢复。

tick 函数只对主世界指定接待台或结构内部玩家开放 trigger，并再次验证地点和已安装状态后传送。其他地点、维度、数值不触发传送。内部返回不要求特定门口站位。

`/function s1:disable` 关闭进出并解除安装范围强制加载，不删除结构。不要在仍有玩家停留内部时禁用。载入包只创建计分板，不会自动安装或清空世界。

结构范围以玩家与原版传送机制自然加载和 tick。安装函数不是地牢生成器，固定坐标需由管理员与其他工程隔离。移址需要重新生成并复核本包的所有坐标、边界、台面和证据，不应只手工改一处 tp。

## 验证边界

隔离测试报告由交付根目录的补充说明链接。自然移动采用服务器 FakePlayer，每个普通服务器刻调用原版 travel(水平输入)，验证原版重力、半格上台阶和梯子行为；它仍不等同于人类客户端游戏录像。入口连通站位与真实交互射线另有单独报告，不把赋予站位后的 use 当作自然行走。
