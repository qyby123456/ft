# FT 地牢 0.29.0：终点返程门与首领封印

基于小型群系修复工程，并合入 0.28.2 已验证的稀疏施工、预留边界复用及水域接口修复。适用 Minecraft 1.20.1 / Forge。

- 八种小型群系地牢和经典紫晶地牢：从入口房间沿房间连接树计算路径长度，选择路径距离最大的房间。走廊按实际折线路径长度加权，相同距离按房间 ID 稳定选择。
- 返程门只在所选房间内的安全区域放置，保留原始家具，不在入口平台生成返程捷径。旧实例再次进入时会移走旧入口旁的 FT 返程门。
- 首次有玩家进入终点房间时生成该实例专属的 FT 骷髅王。只有真实玩家击败已绑定 UUID 的首领，才记录胜利并解除返程门封印；普通怪物死亡、其他实例胜利、环境杀死首领不会解锁。环境击杀后允许重新挑战。
- 胜利记录保存在对应维度的 SavedData 中，独立于门的动画和方块开关；退出重进保留。门控制和服务端返程逻辑均检查击败记录。
- 中型地牢保留原有首领战及最深房间传送入口；月蚀与混沌保留原生终局流程和胜利状态。
- 本次仅更新模组文件，不直接改写玩家存档。旧实例迁移发生在游戏服务端下一次进入该实例时。

新增原生测试覆盖八种风格实际施工、九房连通、终点选址、入口捷径移除、击败前拒绝返程、真实首领生成与玩家击杀、击败后返程和胜利数据序列化。

构建：`./BUILD.ps1 -Task build -Offline`

原生测试：`./BUILD.ps1 -Task runGameTestServer -Offline -GradleOptions @('-PsmallOnly','-PgateTestDirectory=exit-tests-r2')`

## 验证结果

- `exit-tests-r3.log`：3 项必需 GameTest 全部通过，覆盖 72 间原始房间、32 组随机布局、八种风格的真实建造与击败前后返程流程，包含环境击杀不解锁和再次挑战。
- `package-and-gates-0.29.0.log`：发布 JAR 重映射和 `verifyDungeonGates` 检查。
- 全量 `build` 的 `verifyDungeonArchitecture` 在原有石棺模型上报告 `Sarcophagus coplanar overlap`。本次没有修改该模型；发布打包和返程门测试单独验证。
