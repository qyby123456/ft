## 风格落块

红绿棕羊毛拼棚固定在跨墙木框与贴墙木柱上；两只空炼药锅经连续双链吊在木框下。赃物意象以角落空桶箱、头骨、盆栽、空酿造台、贴墙空铁笼和黄色未点燃蜡烛表现。没有金币掉落、奖励库存、战利品表、裸火、液体或新增实体；没有哥布林、店主和交易逻辑。

柜台为七格独立木柜，四侧至少一格净空。四角柱嵌墙，不穿家具；货架和空笼贴墙一格深。两盏暖灯位于柜前走道上方，不占玩家头部净空。地毯转为地板内嵌红绿陶瓦，不增加路面碰撞。

1. 使用已配置 Python（Pillow 可用）运行 tools/build_room.py，再运行 tools/qa_static.py。
2. tools/run_native.py 使用 Java 17、Gradle 8.8 和本机缓存 Forge 47.4.10，在 qa/forge-run/ 独立 GameTest 世界验证，不启动玩家客户端。
3. 原生测试覆盖四旋转、注册表/状态/NBT 往返、100 tick 状态稳定、原生碰撞/支撑、柜台环路、空库存、零实体；增加移除灯链、移除锅链及堵路的负向探针。
