# 第二批 L3 / L4 / S3 独立房间制作

只制作三间结构模板，供主接入工程统一验收。没有修改核心模组、现有存档或部署目录；没有调用付费生图接口。

| ID | 房间 | 模板尺寸 X×Y×Z | 北入口脚部坐标 | 安全内点脚部坐标 |
| --- | --- | --- | --- | --- |
| L3 | 熔岩锻造大厅 | 23×14×23 | 11,1,0 | 11,1,5 |
| L4 | 蛛巢神殿 | 21×10×21 | 10,1,0 | 10,1,4 |
| S3 | 炼金实验室 | 9×5×9 | 4,1,0 | 4,1,3 |

三间均为原版 Minecraft Java 1.20.1 方块，DataVersion 3465。局部 Y=0 是完整地板，入口脚部 Y=1，入口北侧 Z=0，开口为三格宽三格高。放置时保留模板内入口脚下地板，不要把 preview 的剖切套用到 NBT。

## 内容与边界

- L3：四处熔岩瀑布和承接池全部侧向/下方封闭；玻璃护面保留熔岩可见性。中央巨砧、工坊、锻炉和静态矿车没有奖励库存。木材不进入此房间。
- L4：石质蛛神有头、躯干、腹部及八条完整落地石腿；四个垂茧、蛛卵和蛛网为环境陈设。唯一入口及绕行路线不铺蛛网。灵魂火为原版青蓝色，以绿色蜡烛与绿釉基座配色，不伪造原版不存在的绿火。
- S3：为避免7×7内设备挤占入口，合理扩到9×9，仍是小房。三座酿造台库存均为空，保留抄写桌一本工作记录；没有可领取的水瓶、奖励箱或战利品表。木架附近蜡烛不点燃，改用安全灯笼照明。
- 不预放 Boss、刷怪笼、命令方块、实体或自动运行函数。开口无门扇、栅栏门或凸出门框。

## 文件

每间 `out/<ID>/` 中的 `room.nbt`、`room.json`、`preview.png`、`qa.json` 是完整交付文件。`room.json` 保持统一接入字段。`qa.json` 包含 NBT SHA256、来源图片/提示词 SHA256、结构与通路检查、封液及防火检查、功能物品清单和原版方块资源校验结果。

预览由实际写入的 NBT 重新读取生成，左侧为剖视示意，右侧为完整封顶外观与地面可达图；不是概念图的复制，也不是游戏截图。原始概念图的细部做了可落地的原版方块转译，差异见各房间 `qa.json` 的 `adaptations`。

## 重建与交付

使用现有带 Pillow 的 Python 环境运行 `tools/build.py`。它复用既有 NBT 编解码、独立 NBT 解析和投影/材质预览工具。

`tools/build.py --publish` 仅在全部离线检查通过、且 incoming 内对应房间目录不存在时，将四个文件复制到主工程各自的 incoming 子目录。QA 文件最后写入作为完成标记，不覆盖其他房间或主工程文件。

未进入游戏实测，也未部署。最终运行时的方块实体适配由主接入工程根据 FT 运行环境处理；本模板保持原版命名。
