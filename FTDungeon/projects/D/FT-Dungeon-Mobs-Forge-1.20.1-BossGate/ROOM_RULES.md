# 房间怪物分级与冒险模式 · 0.20.0

Minecraft Java 1.20.1 / Forge 47.4.10，2026-11-02。

## 房间规则

| 房间 | 怪物等级 |
| --- | --- |
| 小房 S1、S2、S3、旧侧区 30_1 | 仅普通 |
| 中房 M1、M2 | 仅精英 |
| 大型/挑战房 L1、L2、L3、L4、旧大型场景 31 | 仅精英 |

按现有房间编号分类，不根据模板实际长宽猜测：M2 即使面积较大也仍算中房。后续 `M数字`、`L数字` 和 `CHALLENGE_` 前缀房间采用精英池，其他新编号默认普通；新种类接入时应同步审核。不会启用整合包里原先禁用的独立挑战扩展。

每点固定组仍为 1～3 只，每轮只生成一次；入口火炬 1～5 档每房目标仍为 2/4/6/8/10 点。组内只会选择同一等级的怪，空间不足就少放点，不改建筑给大怪让路。生成时分别检查怪物宽高、干燥支撑、房间边界和碰撞；大型精英不会被强塞到矮顶或窄巷。

## 怪物划分

参考用户指定的 [MC百科：灾变](https://www.mcmod.cn/class/5214.html) 及其[生物分类](https://www.mcmod.cn/item/list/5214-4.html)，并核对当前实例安装的 Cataclysm 3.31 注册 ID。这里的“精英”是 FT 刷怪池层级，不是给所有生物叠加同一种精英词缀；原版也没有统一官方精英枚举，下列原版分级是本项目的平衡规则。

| 来源 | 普通池 | 精英池 |
| --- | --- | --- |
| FT | 骷髅战士、弓手、法师 | 无；骷髅王不进入常规点位池 |
| 原版 | 僵尸、尸壳、溺尸、骷髅、流浪者、蜘蛛、洞穴蜘蛛、蠹虫、末影螨、掠夺者、苦力怕 | 女巫、卫道士、唤魔者、猪灵蛮兵、凋灵骷髅、烈焰人、劫掠兽 |
| 灾变 | 末影甲虫、渊灵、渊灵蛮兵、渊灵垂钓者、渊灵祭司、渊灵术士、观测者、骸龙、炽燃狂魂、再行魂尸、皇家魂尸、溺尸宿主 | 精英魂尸，以及可用于陆地房间的小 Boss：末影傀儡、炽燃遗魂、珊瑚傀儡、紫水晶巨蟹、徘徊者、珊瑚巨像、骸龙斗士、瓦吉特、冥行武弁 |

- 百科“生物”类中的精英魂尸按名称与战斗定位特例提升到精英，其余已接入生物按普通；百科“小Boss”类适用陆地房间的成员按精英。
- 不放末影守卫、焰魔、下界合金巨兽、先驱者、利维坦、远古遗魂、咒翼灵骸、斯库拉等完整 Boss，不放凋灵、末影龙、监守者；不放宠物、已移除实体或弹射物。
- 此次是干燥地面点位，不接入蓑鲉、水母莉亚、小海胆、章鱼共生体及水战小 Boss 沧溟巡守/巨钳守卫。溺尸及能陆地作战的渊灵保留；不自动造水池或召唤附属水中实体。
- 灾变是可选运行依赖，不捆绑其素材/代码。未安装时只从当前可用的同等级实体中选；精英池不会降级成普通池。
- FT 三种骷髅继续应用已有五档属性接口；原版/灾变使用各自原生装备、AI 和属性配置，不再乘一套未经平衡的新伤害倍率。点位密度随火炬增加，怪物记录本轮归属和档位；猪灵蛮兵在地牢不会自动僵尸化，生成后立即以触发玩家为目标。

## 配置和旧档

`config/ftdungeonmobs-spawns.toml` 新增 `normalMobPool` / `eliteMobPool`，完整示例见 `config-examples/ftdungeonmobs-spawns.toml`。只能从对应等级的安全白名单中删选，防止把完整 Boss、宠物或普通怪误配进精英房；可选模组未注册的 ID 在布点时跳过。空池或所有条目都缺失时退回可用的同级默认池；若要停刷，用 `enabled=false`。其他点数、触发半径、数量上下限不变。

0.19 的 `mobPool` 已由两个分池选项取代，不再生效；首次启动由 Forge 补齐新项，旧数值配置仍保留，停服编辑新池后重启。已布置的点不因改配置而重抽。

旧版存档会将未加命名空间的 FT 怪物 ID 转成完整 ID。首次更新时，仅将旧点尚未生成、且不符合房间等级的剩余名额换成同级怪；已成功生成数量、已消耗名额、点位坐标及已生成怪物都保留，不清空整轮、不重复发怪。迁移标记随世界保存，正常读档后不再抽取；新一轮全部按新池布点。若之后移除了已经保存进固定组的可选模组，该名额保留等待依赖恢复或新轮，而不静默换怪。

## 地牢冒险保护

- 无论从入口门、命令或其他传送方式进入 `ftdungeonmobs:dungeon`，生存、创造、旁观玩家均切到冒险模式；入场前模式保存到独立玩家持久数据，地牢内 `/gamemode` 也不能绕开。每半秒另作一次模式兜底。
- 登入、死亡克隆、重生和换维度均处理；地牢中断线重连不覆盖原模式。在任意其他维度退出、重生或登入时恢复入场前模式并清除临时标记，不碰其他维度的全局游戏规则。
- 禁止挖掘、放置、桶取放液体及工具改地形；即便工具有 `CanDestroy`、物品有 `CanPlaceOn` 也有事件层拦截。方块右键交互仍开放，但不调用手中物品的改地方块用途。
- 保留箱子、门、按钮、拉杆、祭坛等交互，以及空中用食物/药水/战斗道具和攻击怪物。血池祭坛单独兼容冒险模式的手持供品/掉落供品与空手确认，不再把地牢中的交互错误地当作建造；其他维度仍保留原有建造权限要求。近战攻击装饰、被动动物或玩家被拦截，避免借攻击拆盔甲架；不改变全局 PvP 选项。
- 地牢方块防爆默认开启，覆盖通过原生/Forge 爆炸流程处理的生物爆炸、TNT、火球与方块来源爆炸；清空方块破坏列表，保护建筑、容器及其内容，避免对应的爆炸掉落与爆炸点火。只保护方块，不让玩家或怪物免疫爆炸伤害，正常战斗仍保留。
- 生物破坏方块与踩坏农田另有事件拦截。上述防护只限 `ftdungeonmobs:dungeon`，不会执行全局 `/gamerule mobGriefing false`，其他维度的爆炸、农田和村民行为保持原状。无法保证拦住绕过 Forge 事件、直接写世界方块的其他模组或管理员世界编辑命令。

建议管理员在专用开发/测试世界搭房间，不在受保护地牢里切创造搭建。现有服务端建筑安装器仍能通过自己的安全预检放置模板，不会被玩家放置事件误拦。

## 验证

- `BUILD.ps1 -Task build -Offline`：编译、资源/建筑回归、重混淆发布包。
- `BUILD.ps1 -Task runGameTestServer -Offline`：七项原生 Forge GameTest，包括旧四项、分级/原生怪、冒险生命周期/保护及真实爆炸维度隔离测试，使用隔离世界，不打开玩家存档。爆炸测试直接执行真实 Level 爆炸流程并更换苦力怕、TNT、火球和方块来源，不等于逐种复演所有模组怪物的特殊攻击。
- 可选灾变验证：本地 `libs/cataclysm-3.31.jar`、`libs/lionfishapi-3.0.jar` 仅用于测试，设置进程环境变量 `ORG_GRADLE_PROJECT_cataclysmVerification=true` 后运行上述 GameTest，再恢复变量。不将依赖打进发布包；实际逐个验证已列入两池的灾变实体能在干燥房间安全生成。
- 服务端测试不能代替整合包真人联机、各法术与所有第三方交互的最终目测；已知边界见本文件与 `VERIFICATION.md`。
