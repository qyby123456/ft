## 可复现

运行 `./Run-QA.ps1 -Rebuild`。需要已缓存的 ForgeGradle 6.0.54 / Forge 1.20.1-47.4.10、Gradle 8.8、Java 17 和本机 Codex Python/Pillow。脚本每次使用本目录中新的独立测试世界，不清除旧存档。`JAVA_HOME_17` 可指定 Java 17 路径。

生成源位于 `tools/`；`nbtio.py` 和空 GameTest 夹具只读复用了既有 M5 独立工程，其余脚本和测试属于本目录。压缩包只收交付、源码与证据，不包含开发缓存或 GameTest 世界。
