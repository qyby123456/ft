# 黑曜试炼地牢 · Minecraft 1.20.1

参考用户提供的四张黑曜试炼图片，把单间概念扩展为可在游戏中放置的完整建筑。占地 **35 格宽 × 47 格深**，总高 **18 格**；NBT 的 XYZ 尺寸为 35×18×47。所有结构均使用原版方块，不依赖额外建筑模组。

## 设计

- 保留紫黑黑曜石、哭泣黑曜石柱面、镀金黑石、橙色熔岩与金边高火盆。
- 35×35 主殿，增设有顶入口前室与阶梯；完整建筑含双层封闭阶梯穹顶，预览剖去屋顶及近侧墙。
- 切角竞技台抬高一格，四座五格宽跨桥连接熔岩环内外，四面有台阶，不必跳熔岩进入中心。
- 四角塔柱、垂链吊灯、双侧补给龛及后殿奖励预留龛。三个木桶默认为空，留给后续任务/战利品配置。
- 试炼门采用抬起状态的铁闸及紫晶符文门楣，门下宽七格；没有锁死玩家的门或自动机关。

## 安装与放置

本次只生成独立工程和 ZIP，**没有安装到实例，没有打开、修改或写入玩家存档，没有替换 FT 地牢怪物 JAR**。

1. 先备份拟测试的世界。将 out/ft-obsidian-trial-1.20.1.zip 复制到该世界 datapacks 文件夹，游戏内执行 /reload。或复制到实例的 moonlight-global-datapacks 文件夹后完整重启游戏。二选一，避免重复安装。
2. 管理员先执行 /function ftobsidian:help 查看提示。在创造模式选择足够大的空地，站在建筑的**西北角最低基础高度**，前方 +X、+Z 方向分别留出 35、47 格，向上留出 18 格，确保所有相关区块已加载。
3. 执行 /function ftobsidian:build。函数按整数坐标对齐，对整个 35×18×47 空域逐格检查，并检查加载状态、高度及其它实体；任何障碍都拒绝放置。允许建造者本人暂时位于空域内。
4. 成功后将建造者送到入口前室。主地面比执行高度高三格，入口向北（-Z）。适合在原版平地或现有地牢维度的空白平地搭建，不会自动接通旧大厅。

例如站在 Y=64 的平地执行时，基础最低方块在 Y=64，主地面方块在 Y=66，玩家在 Y=67 行走。建筑不会主动挖去地下方块，也不要求清除脚下 Y=63 的地面。

结构管理员也可以执行 /place template ftobsidian:chamber <x> <y> <z> 单独放置模板。**此原生命令会绕过本包的防覆盖检查**，不要在已有建筑或正式存档中盲目使用。结构块可直接读取 NBT 模板，默认结构块 UI 的单轴 48 格上限内可容纳本结构。

## 安全边界

- 这是**纯建筑版**：无自动刷怪、波次、收费、传送门、胜利奖励或闸门开闭逻辑；不修改 FT 的个人返程、门的入场规则和五档火盆数值。
- 中央火盆由原版方块组成，是常燃建筑装饰，不是可交互的 FT 五档火盆。需要挑战联动时再单独接入，不冒充已实现。
- 熔岩为真实原版熔岩源，底面及四周封闭；中央使用地狱岩上的原版火焰。不更改 doFireTick 等游戏规则。玩家仍可能被火或熔岩伤害，后续不要在附近加可燃建筑。
- 无每 tick 函数，无常驻强加载，不扫描任何存档。加载数据包只创建一个建造检查记分板，只有管理员主动执行 build 才施工。
- 防覆盖检查约 29,610 次，只在手动建造时运行；完整命令链低于原版默认 65,536 上限，低配服务器可能在该次建造时短暂卡顿。调低过 maxCommandChainLength 的服务器应先在测试世界确认。
- 对普通 1.20.1 空气/洞穴空气/虚空空气区域设计；世界保护插件、不同世界边界、方块事件拦截及整合包流体/火焰改动仍需管理员在副本中实测。
- 删除数据包不会拆除已放置建筑。没有提供全局清理或粗暴回滚函数，避免误删他人建筑。

## 复现与质检

使用 Python 3.10+ 运行 tools/build_dungeon.py 生成 NBT、数据包、清单与静态检查。预览还需 Pillow，并使用本机 1.20.1 客户端 JAR 中的原版贴图：

    python tools/build_dungeon.py
    python tools/render_dungeon.py --textures-jar "Minecraft-1.20.1.jar"

几何检查覆盖坐标范围、双层穹顶、熔岩五面封边、火焰支撑、入口到四桥/竞技台/三处预留龛的两格净高路径。命令检查覆盖函数引用、JSON、整链长度及无自动 tick/施工设置；独立审计逐项核对全部 29,610 个空域坐标及防覆盖守卫顺序。

原生验证器使用 Minecraft 1.20.1 的实际注册表核对 22 种方块状态，用 StructureTemplate 读写 NBT，并在载入本包空气标签后通过 Brigadier 解析全部 29,665 条 mcfunction 命令，结果通过。它不代替完整整合包客户端、服务器或多人实测；未修改或启动玩家世界。

预览从导出的同一方块数据绘制，使用原版贴图并为可读性提亮；屋顶、近侧墙剖切，灯笼与锁链等小模型简化，非实机截图。不包含第三方 JAR、游戏程序或整套材质包。
