# 设计与验收约定

## 范围

独立 Forge 1.20.1 / 47.4.10 扩展，不修改 FT 地牢怪物、难度、挑战或已弃用火盆。交付可编辑 Blockbench 工程、原创像素图集、Java 方块模型、可构建源码和 JAR；本轮不自动部署或启动游戏客户端。

## 交易体验

桌面左侧显示玩家付款，右侧显示玩家获得物。第一次右键明确展示完整清单，间隔至少 6 tick 后、100 tick 内再次右键才确认；副手不触发第二次结算。确认绑定玩家、维度、方块实体实例、内容版本及报价。切换交易、库存、资源重载、重放、换桌或超时不能沿用旧确认。

一张桌子绑定一条交易。新放置或打掉后重新放置的桌子不绑定报价、库存为零，防止拆放补货。管理员通过命令绑定/设置库存，数据包定义付款与商品，两侧各 1—8 项，允许模组物品、物品标签付款及精确 NBT。常规玩家不改价、不免费领取。有限库存持久化；无卖家容器，商品来自配置，付款销毁，输出直接进入玩家主背包。后续外部经济/商人系统通过公开 API 和事件独立接入，不暗示已支持任意货币余额。

所有结算在服务端线程。先匹配所有付款再模拟扣款与装入奖励，全部可行后一次提交；背包满、付款不足或取消均不扣款、不掉地。重叠标签与精确物品采用最大流匹配，不靠可能误判的贪心顺序。

## 建模

深色厚木桌、黑铁包角/支腿、紫色桌旗和黄铜交易标记；左右独立浅托盘，中间账本/封蜡，背面与侧面保留结构。无火焰、火盆或骷髅捆矛造型。实际商品由客户端方块实体渲染器显示，不烘进静态模型；桌体不复制多套适应交易。

只学习本地 Handcrafted desk 的厚桌面/四腿分工、Goety template_altar 的底座/承重关系及其实际 UV，不复制原图或几何。来源仅本地研究，不因此声称取得第三方再分发许可。

生成前预算：桌体 ≤100 组件、≤600 声明面、单张 128×128 原创图集、无透明壳与动画展开。每桌动态预览最多左右各 3 件，完整清单仍以服务端报价为准。不把资源预算称为 FPS 实测。

验收包括真实 Minecraft JSON 解析、资源引用、Blockbench 重开与固定多视角/Display、Forge GameTest 结算回归和 JAR 审计。游戏端视觉、第三方领地插件及多人客户端未实测则必须明确说明。
