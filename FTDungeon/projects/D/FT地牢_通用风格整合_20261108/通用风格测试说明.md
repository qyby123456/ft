## 外部风格编写工具

`tools/style-author.py` 使用 Python 3.9+ 标准库，从内置 forest/desert/frost JSON 派生外部配置。必须明确 `--output`，父目录须已存在；独占创建，拒绝覆盖已有文件或符号链接。不自动部署或选择正式配置路径。新 ID 不得与内置 ID 重复。

```powershell
py -3 tools/style-author.py --id ftmossgen:slate --title 石板遗迹 --base-style frost --geometry '[]' --output verification-style/slate.json
py -3 tools/style-author.py --spec '@author-spec.json' --output verification-style/custom-style.json
```

`--spec` 接受内联 JSON 或 `@文件路径`，示例内容如下：

```json
{
  "id": "ftmossgen:slate",
  "title": "石板遗迹",
  "baseStyle": "forest",
  "icon": "minecraft:obsidian",
  "capBlock": "minecraft:polished_blackstone_bricks",
  "barrierBlock": "minecraft:purple_stained_glass",
  "palette": {"minecraft:oak_log[axis=y]": "minecraft:oak_log[axis=x]"},
  "enemy": {"melee": "minecraft:husk", "ranged": "minecraft:stray"},
  "boss": {"type": "minecraft:husk", "name": "遗迹守卫", "health": 240, "damage": 12},
  "geometry": [{"block": "minecraft:oak_log[axis=x]", "mode": "air", "role": "room", "from": [1, 20, 1], "to": [3, 20, 3], "spacing": 1}],
  "roomCooldownTicks": 2400,
  "instanceCap": 48
}
```

独立参数 `--title`、`--base-style`（别名 `--baseStyle`）、`--palette`、`--enemy`、`--boss`、`--geometry` 可覆盖 spec 对应项。后四项接受 JSON 或 `@文件路径`。palette 合并基础映射；geometry 替换全部装饰（`[]` 清空）；enemy/boss 缺省字段继承基础值。其他配置保留。

工具执行 ID、JSON 字段、数字范围、坐标、模式和 blockstate 语法基础校验，拒绝常见 AIR/流体/水浸目标；离线无法确认模组注册表、合法属性、完整实心碰撞或 BE，实际配置仍须 Profiles.validate 与 Catalog 加载。完整 blockstate palette 键优先于普通方块 ID。装饰仅增加安全区域的显式 AIR，合法坐标也可能被保护规则跳过，示例不保证实际增量。

新几何自定义仍需隔离服务端连接端口和独立碰撞脚点 BFS 验证，核对完整玩家通路、最低 eligible 房间最远门户和冻结距离，再验证真实建造、门绑定、持久化。成功生成 JSON 不代表几何可达或原生验证通过。
