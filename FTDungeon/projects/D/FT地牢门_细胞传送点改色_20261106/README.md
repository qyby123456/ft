# FT 青蓝传送地牢门

基于已有 FT 返回地牢门的独立改色候选，参考 Mine Cells 传送点的暗色石材、冷色魔法感。不是精确复刻，未复制 Mine Cells 模型或贴图。

- `ft_teleport_gate_cyan.bbmodel`：可编辑模型，内嵌首帧贴图，181 个组件，几何和 UV 未变。
- `resourcepack/`：运行资源。贴图为 128×128 主图集及两张 16×256 动态序列，16 帧，3 ticks/帧。
- `FT_青蓝传送地牢门_可选资源包_1.20.1.zip`：已有返回门外观替换包，未自动安装。
- `preview/`：原版对照、正背左右、开启/闭合态、动画。软件渲染，非游戏截图。
- `verification.json`、`audit/`：离线几何及资源检查。

保留原有 3 格宽、4 格高门框、颅骨、绞盘、链条与铁闸；暖灰锈色改冷灰蓝，骨饰改冰骨白，壁灯改青蓝魂焰，传送面保留原动画并改青蓝。新增几何为 0。

模型默认闭合，在 Blockbench 隐藏铁闸组可看开启态。可选资源包保留共享动态铁闸的原版金属材质，以免影响入口门，因此游戏中闭合/运动铁闸不完全等同软件全改色预览。

可选包针对 FT Dungeon Mobs Forge 1.20.1，手动放入 resourcepacks 并启用。这是已有返回门的外观替换，不是新注册方块，不含新传送目标或冷却逻辑。未修改 jar、原源码、原素材或存档。

为避免等级色叠乘，返回门静态/物品模型的传送面移除 tintindex，因此固定青蓝不再显示原等级色。入口门不受影响。

Blockbench 内嵌首帧仅用于编辑，运行时动画由 PNG 和 mcmeta 提供。未新增自发光材质、光源或 Mine Cells 旋转法阵渲染器。未启动 Minecraft，未做实际传送、客户端视觉或 FPS 测试。
