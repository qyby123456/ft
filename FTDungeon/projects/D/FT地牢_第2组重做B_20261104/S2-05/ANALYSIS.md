# S2-05 走廊单张分析

原图是平直狭长的有顶砂岩通道：中轴三盏吊灯、两侧反复门肋与上方横梁、橙色横墙带及符号、分段地纹。远端拱门通向室外，近端为拍摄位置但功能上保留同宽接口。积沙和陶罐贴墙，枯灌木在路边，中央贯通，不是房间/高台/列柱大殿。

独立从空结构建立 15×12×41，内墙间净宽9格，门肋位置净宽7格，两端拱门净宽5格、声明净高4格。厅面与两个接口脚部均Y2，不沿用上一张前低后高。中心X6..8三格宽的直行带从Z0贯通Z40，不放障碍。六道附墙门肋代替独立柱，平顶与门肋相接。

原图太阳光从左上局部缺口进入，本模板在屋面实际开两处2×3采光缺口，保留其余屋面，不声明完全封闭。屋檐角的侧面雨雪、光传播、刷怪和外部地形均待未来集成验证。三盏灯的吊链分别从Y7灯体连至Y10实顶，避开采光缺口。

原图沙堆的斜坡用实心砂岩、下半砖和被下托的真实沙块近似；并非重力悬空沙。陶罐使用陶瓦加花盆，符号以錾制红砂岩近似。原图视角透视、细碎风化、陶罐纹理和光束不逐像素复刻。无箱、旗、书架、水、实体或机关。
