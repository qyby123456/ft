# 冷蓝囚砌 · masonry 八件组

## 范围与交付

目标为 Minecraft Java 1.20.1 / Forge 47.4.10 / Java 17，命名空间由主工程使用 `ftdungeonprops`。本线只提供八款原创建筑素材的输入定义、图集、映射、可复现生成器及离线预览；未改动共享代码、正式模组、存档或当前 Blockbench。

六个交付文件均位于本目录：

- `definitions.json`：严格八项、与合同顺序一致的定义数组。
- `atlas.png`：RGBA 128×128；4×4 格，每格 32×32，全部像素 alpha=255。
- `tilemap.json`：十六个图块的位置、用途、重复轴、色板及投影 UV 约定。
- `make_assets.py`：只向自身所在目录及其 `work/` 写入；不需要参考图片或网络即可重建资产。
- `DESIGN.md`：本说明、预算、安装方向、整合注意与实际检查记录。
- `contact-sheet.png`：八款的离线软件三分之四视图、接缝/叠接/挂墙示意及完整图集。各格自适应取景，不代表统一展示比例。

`work/` 仅为 QA 中间产物，不应随正式资源包发布。主工程负责最终 Java 资源、原版状态族、可编辑工程、碰撞、注册、标签、合成、掉落与语言；本线没有声称已完成这些整合。

## 材质与像素语言

主色遵循合同的 `#253744 / #354c59 / #4e6570 / #74858b` 冷石，深缝 `#141d27`，铁 `#252b35 / #59626a`，锈 `#784936 / #b4794e`。中间石色和低饱和青灰仅作为过渡；黄铜与矿物灰白限量使用，不依赖发光保证可读性。

- 砖墙使用四个 8px 高砖层，16px 长错缝砖、连续的双像素灰缝及有限大石面。亮边方向与砖面成组凿痕明确，不逐像素散布小噪点。
- 潮痕在明确位置形成有宽度的膜状簇；石灰从砖缝垂落并保留次级灰边。
- 裂纹为连接的阶折路径，有局部亮断面、缺角和两处铁补钉锈痕。补钉不增加无意义几何。
- 镶线为一像素哑光黄铜菱线、深铁嵌槽与四个素切石角标；中心少量铜绿不发光。
- 柱身纵向刀痕成段分布，无横向假柱帽带；檐口用面带、刻纹和滴水线区分层级，四枚齿饰才使用真实几何。

材质图集仅一个、静态一帧，无透明、额外发光图集或动画依赖。16 个图块均有引用且内容互异；原图集只含 17 种 RGBA 色。基础 RGBA 数据为 16,384 像素 / 65,536 字节，不含 mipmap、游戏拼图集和 GPU 对齐，不能据此声称显存实测值或 FPS 提升。

### 柱体叠接

核心为 `[4,0,4]..[12,16,12]`，四侧各两条独立结构棱，总共九盒。每侧两条棱之间为真实 2 单位宽凹槽；角部也有实际退让。上下均为面积 112 模型单位² 的同截面，四向旋转严格对称；柱段无横跨边界的附加柱帽。核心和棱条均从 y=0 连续到 y=16，纵向图块首末行相同，允许连续堆叠。

### 檐口贴墙

NORTH/front 为 z=0，SOUTH/back 为 z=16。8 盒包括上冠、连续雕带、挂墙后跟、下滴水条及四枚齿饰。后平面完整覆盖 16×16，与墙体在 z=16 接触；最前伸至 z=6。没有嵌入墙内或超出单格；无需伸进相邻方块来隐藏接缝。

齿饰在 x=1..3、5..7、9..11、13..15；齿间以及跨连续檐口边界均保留 2 单位真实空隙。左右结构截面相同，可排成直线；这是直线壁檐，不承诺内外转角自动适配。游戏是否要求背后有支撑不在本线实现范围，不能把挂接意图宣传为已实现支撑检测。

### 底材一致性

楼梯、台阶的 `base` 严格为 `prison_blue_bricks`。预览每个盒的每一面均使用图块 0，无替换顶材、亮度或缩放版本；32×32 基础纹理在 y=8 切分处恰为原有砖缝。主工程应原样提取图块 0 供原版父模型使用。

## UV 整合重点

预览采用每模型单位 2 texel 的块内投影 UV。小体块只取全块对应坐标的子区域，**不能把完整 32×32 图块拉满每个窄棱、齿饰或薄檐面**。否则像素密度和檐面刻带位置都会变化。完整数学约定在 `tilemap.json`：

- north `(16-x,16-y)`；south `(x,16-y)`；east `(16-z,16-y)`；west `(z,16-y)`。
- up `(x,z)`；down `(x,16-z)`。
- 本地模型坐标乘 2 得图块像素坐标；转 Java 0..16 图集 UV 时，图块像素原点除以 8，再加本地投影坐标除以 4。
- 檐冠 y=13..16 对应立面纹理行 `[0,6)`；雕带 y=9..13 对应 `[6,14)`；齿饰 y=10..13 对应 `[6,12)`；滴水条 y=7..9 对应 `[14,18)`。
- 柱端、檐顶及仰底使用明确的 face 覆盖，不得把所有覆盖简化为盒默认图块。

按该投影且排除源体积内部遮挡，八款共采样图集中 10,080 个不同 texel，即 61.5234%。这是本线源投影覆盖估计，不是最终导出模型 UV 或 GPU 使用率；其余像素不是透明空白，且合同固定要求 128×128 图集。

在本目录运行 PowerShell：

```powershell
& 'C:/Users/YOUR_USERNAME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' './make_assets.py'
& 'C:/Users/YOUR_USERNAME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' './make_assets.py' --check-only
```

依赖为 Python 3 与 Pillow。参考位图不参与重建。展示文字优先读取 Windows 微软雅黑，其他平台会回退字体，因此跨平台接触表文字的像素级一致不作保证；定义和材质不依赖字体。`DESIGN.md` 为随附静态说明，生成器重建的是定义、图集、映射、预览及 QA 记录。
