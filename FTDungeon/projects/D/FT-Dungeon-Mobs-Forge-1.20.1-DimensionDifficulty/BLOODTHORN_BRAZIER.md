# 第二种火盆：血棘祭炉

熄灭 / 未开启状态保留，当前 0.15.0 改为火盆持续控制入口，并加入门色联动和首人进入后的五分钟锁定；模型说明见 `BRAZIER_UNLIT.md`，完整入场规则见 `DUNGEON_GATES.md`。

适用于 FT 地牢怪物 0.19.1、Minecraft Java 1.20.1、Forge 47.4.10、Java 17。

## 获取与摆放

- 创造栏：FT地牢怪物 / 功能方块，搜索“血棘祭炉”。
- 指令：`/give @s ftdungeonmobs:bloodthorn_brazier`。
- 工作台配方：`骨头 铁锭 骨头 / 铁锭 烈焰粉 铁锭 / 磨制黑石砖 磨制黑石砖 磨制黑石砖`，产出 1 个。
- 只占一个方块位置，可在其上方直接放置方块；需要下方方块的顶面坚固，不允许放入流体。失去底座后掉落自身。
- 默认熄灭，不发光；1～5 档发出 14 级方块光照。碰撞、选取范围为盆体的 `0,0,0 → 16,10,16`，火焰无碰撞；不造成接触伤害。

## 地牢功能

- 把火盆放在入口门底部中心 6 格内，入口读取最近已加载火盆，包括熄灭的火盆：0 档关门，1～5 档持续开门，切换已点燃档位不会关门。这里的 6 格只用于门控制器选取，不是怪物加成范围；门外邻近怪物不受影响。
- 本轮未锁定时，普通和潜行主手右键均按 `熄灭 → 1 → 2 → 3 → 4 → 5 → 熄灭` 调档。门框火炬也委托最近火盆执行同一交互，不再独立开关大门；返程门始终开放。
- 第一个玩家成功传送后，锁定本轮档位及入口 6 格内的两种火盆，同时开启 6000 个服务端游戏 tick 的入场窗口（20 TPS 下五分钟）。后来玩家入场不延长窗口；截止后拒绝新进入并关门，但不影响返程。存档重载保留截止时间与成员，离线且仍在地牢内的成员不会被提前移除。
- 窗口结束且本轮成员全部离开地牢后才解锁。锁定时拒绝调档、破坏火盆及其底座、放入替代火盆、爆炸和活塞移动；管理员强制改方块不属于保护范围，但不能改变已冻结的本轮难度。
- 与旧竞技场长矛火炬兼容 ID 共用 `ArenaDifficultyApi` 和位置索引存档；旧 `arenaRadius` 现已废弃，不参与难度计算。档位不写入掉落物，重新摆放从熄灭状态开始。
- 入口选择控制器仍按距离和坐标排序，包括最近熄灭火盆。地牢内部不再按最近火盆选怪物档位：未锁定时最后一次显式有效选择控制整个维度，只刷新自动难度怪物，不覆盖管理员固定档位。活动轮次同样锁住地牢内部火盆。
- 火焰颜色与档位同步：1 苍蓝 / 2 翠绿 / 3 鎏金 / 4 紫焰 / 5 猩红；入口和返程传送门表面同步本轮颜色，右键提示使用同色文本。不染色盆体、血痕或大门黑铁结构。
- 旧 DSH 长矛火炬的模型、动画、贴图和自定义渲染已移除，旧创造栏入口与配方取消。旧 `arena_torch` ID 仅兼容存档：原下半部使用新祭炉模型、上半部隐藏且无碰撞；仍保留旧双格状态，建议挖下重放为单格。旧物品直接放置新祭炉，挖掘旧摆放也只掉一个新祭炉；旧 BE 类型仅保存惰性兼容壳，不再运行骨骼动画或渲染器。
- 骷髅实体及其资源不变。未修改或启用单独的 `FT地牢挑战` 扩展，未加入波次挑战、自然生成或自动改写地牢结构。

## 模型与性能

- 原创黑铁方盆、四足底座、方颅骨饰、血痕与阶梯血焰：43 个长方体、217 个可见面；几何、尺寸、Pivot 均为整数网格，旋转为 0 度。
- 原始 Blockbench 工程保留 14 组层级。游戏使用原版 Java 方块模型；编辑分组不会冒充运行时骨骼动画，也不需要新的 GeckoLib 方块实体。
- 本体贴图 64×64；五色火焰各 16×256，16 帧，每帧 2 tick，总长 32 tick（1.6 秒），无插值。11 个血焰体块关闭逐面方向阴影，仍遵循游戏光照，不宣称着色器自发光。仅新增四张火焰贴图；第 5 档复用原猩红图，几何与本体不复制。像素色阶、逐帧图案与亮暗关系均保留。
- 运行命名空间：`ftdungeonmobs`；不依赖或覆盖 `ftboss` 资源。原作目录和本工程 `model_sources/bloodthorn_brazier/` 保留编辑源。
- 构建时 `verifyBloodthornAssets` 使用 Minecraft 1.20.1 的 `BlockModel` 解析模型，同时检查几何、逐面 UV、五档 blockstate、动画、物品、配方、掉落和语言绑定。完整客户端观感、放置和右键交互仍须实机验收。

## 实机检查清单（待验收）

1. 用 `/give @s ftdungeonmobs:bloodthorn_brazier` 获取并放在石头上；在其正上方放石头，确认不需要第二格空间，地面移除后只掉落一件。
2. 无门处及门旁主手右键连续六次，均应熄灭→1～5→熄灭；潜行交互和门框火炬遵循同一调档规则。确认点燃保持开门、熄灭关门，火焰与传送门表面按苍蓝、翠绿、鎏金、紫焰、猩红同步切换；熄灭应无火焰、无动画、不发光。
3. 在 FT 地牢远近两处生成自动难度骷髅，切换档位观察全维度即时刷新；主世界 / 下界邻近怪物和手动固定者不受影响。
4. 保存重开后维度档位保留；熄灭或移除火盆不回退难度，只有下一次有效选档或按规则开启新一轮才切换。
   本轮已有玩家进入时，应拒绝改档和正常破坏；用两名玩家确认后入者不延时、五分钟截止拒绝进入、返程可用，离线成员及保存重载不解除锁定，全员离开且窗口结束才可重新调档。
5. 检查背包、手持、地面物品和 0 / 14 级光照；旧火炬不再显示原模型，挖下/旧物品摆放应得到单格新祭炉。若用于独立服务器，客户端和服务器同时使用 0.14.0 后再测试档位与颜色同步。
本版 0.19.1 的难度作用域见 `DIMENSION_DIFFICULTY.md`：只影响整个 `ftdungeonmobs:dungeon`，取消所有维度中的火盆周边半径加成；门口 6 格仅用于选择门控制器。
