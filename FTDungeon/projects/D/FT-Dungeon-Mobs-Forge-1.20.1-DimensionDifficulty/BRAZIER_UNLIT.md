# 血棘祭炉：熄灭 / 未开启状态

为 Minecraft Java 1.20.1 / Forge 的 FT 地牢怪物增加独立熄灭态，原独立候选版本为 0.13.2；当前整合版本为 0.15.0，以下候选隔离构建和未部署说明保留为历史证据。

## 0.15.0 当前规则

- 未锁定时普通或潜行主手右键均循环六档；门框火炬委托最近火盆执行同一交互。入口由最近火盆（含熄灭）持续控制：熄灭关门，点燃保持开门，门面颜色随档位变化。
- 首位玩家成功进入后冻结本轮难度，入口附近 6 格内火盆不可调档或正常破坏。6000 游戏 tick 的入场窗口只启动一次；到期关闭入口，返程始终可用。窗口结束且本轮成员全部离开后解锁，离线及存档重载不重置本轮。
- 熄灭资源逐字节保留，不覆盖原始交付文件。构建、部署与完整验收以 `VERIFICATION.md`、`DEPLOYMENT.md` 和 `DUNGEON_GATES.md` 为准。

## 0.14.0 整合规则（历史，已被 0.15.0 替代）

- 门旁普通右键只开关门，首次开门可把熄灭火盆点燃至 1 档；已点燃的档位保持不变。空手潜行右键只调档，不开关门；无门处普通右键仍可调档。
- 六状态、熄灭模型、光照、旧状态兼容和难度来源筛选均保留；不覆盖熄灭模型原始交付文件。正式构建、安装及验收记录以 `VERIFICATION.md`、`DEPLOYMENT.md` 和 `DUNGEON_GATES.md` 为准。

## 使用规则

- 新放置和物品显示使用 `tier=0`：没有火焰、没有动画、方块光照为 0，炭块呈冷黑色。
- 主手右键按“熄灭 → 1 苍蓝 → 2 翠绿 → 3 鎏金 → 4 紫焰 → 5 猩红 → 熄灭”循环。
- 点燃时保留原先 14 级光照、五色动画、几何、UV、碰撞和掉落规则；熄灭有灭火音效。
- 熄灭祭炉不参与周围普通怪物的难度选择，不会遮挡该用途下较远的已点燃者。入口控制规则不同：最近熄灭火盆会使入口关闭，不越过它选取更远的点燃火盆。本轮已经冻结的地牢难度不随其改变，不强制传送或重置进度。
- 旧存档的 1–5 档保持原状态；旧 `arena_torch` ID 的上下半部也补齐 0 档，兼容原隐藏上半部。
- 怪物自身的难度范围仍是 1–5；0 仅表示火盆未开启，不新增“零难度”。服务端 `ArenaDifficultyApi.setTier(level, position, 0)` 可在未锁定时熄灭；锁定时该接口拒绝改档。

## 模型与性能

- 熄灭：32 个整数长方体、161 个面、11 组、1 张静态 64×64 贴图。直接剔除原来的 11 个火焰体块，不通过透明贴图隐藏整套火焰。
- 点燃：仍是原先的 43 个长方体、217 个面、五种 16 帧火焰。五档点燃资源逐字节不改。
- 新增一张 64×64 的静态熄灭贴图。仅冷却炭块 UV 使用的 11 个像素；金属、骨饰、血痕、Alpha 与其余像素不变。不增加动画副本或动态渲染器。
- 编辑源：`model_sources/bloodthorn_brazier/bloodthorn_brazier_unlit.bbmodel`。原点燃工程不覆盖。
