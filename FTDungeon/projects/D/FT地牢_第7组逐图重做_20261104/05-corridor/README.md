- 静态检查覆盖 645 列完整顶盖、两侧墙无洞、十个连续菌柄灯、主路净空、20 水的底板/封边；锚固为所有结构实体的六邻接连底，不是工程受力模拟。

## 限制与差异

世界放置、邻居刻、随机刻、流体刻、光传播、交互、运行时旋转全部 NOT_RUN。静态 canSurvive 用实际原版标签、亮度 15 假设，不保证真实光照或长期生长稳定。菌丝/藤蔓/小菇可能扩散，骨粉、拆支撑、水桶、破坏水池封边均未测。

原图不规则水洼简化为矩形；原版紫晶近似荧光紫菇而不发动态紫光；没有青色发光根丝、孢子、雾或非原版资源。墙体/地面拼接更规整，藤蔓靠墙高处而未复刻细长黄根。菌光体照明比概念图偏亮暖色，不声称重现原图气氛。
