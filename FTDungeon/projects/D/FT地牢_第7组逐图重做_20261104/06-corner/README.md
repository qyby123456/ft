## 装配特别警告

世界原点未指定，两口外侧未知。L 形仍使用矩形原版模板，非占地象限也含显式空气：普通原版放置会清除该象限已有地形。必须预留/检查完整25×14×25包围盒并拒绝冲突，不得盲放。只有显式实现“跳过非占地象限空气”的定制放置器才能减少预留体积；本包没有实现或部署这种放置器。`qa/footprint.json` 和 `assembly.json` 同时记录此风险。

## 校验和媒体

- `verify.py --run-dir <全新绝对目录>` 在隔离副本编译执行 `NativeRoomAudit.java`：原版注册表/属性、StructureTemplate读写、实际原版标签通过；49处静态canSurvive、17个目标往返路径通过，942个可达半格节点。
- 玩家模型0.6×1.8，脚面y2、半格采样，逐边扫掠原版碰撞并检查返程，排除水中/无支撑节点；不等同实际服务器玩家导航或任意位置均可达。
- 静态几何确认真实L投影、非占地全空气、456列全顶、两臂中线净空、8源水底板/四侧封边。结构面邻接连底不等于工程受力或世界物理验证。
- `qa/duplicate-review.json` 对32个冻结既有模板做去材质几何四旋转精确比较；无精确重复不等于视觉语义完全不同。
- `capture.mjs` 生成实际Lodestone外壳、剖面、转角细节，不是AI示意图或游戏截图。`qa/media-bindings.json` 绑定源NBT、显示NBT和截图哈希。
- `views/PREVIEW_ONLY_cutaway.nbt` 仅把y13顶盖、x<=1及z>=23近墙的y>=2位置改为空气；逐格清单和两个NBT哈希在 `views/derivative.json`。不能登记/放置剖面。`views/*.png` 是额外软件渲染，不冒充Lodestone。
- `qa/latest-native-run.json` 指向最终NBT自检，历史隔离副本不作为候选。`connections.json` 列出两口空气/地板格；`rotated-connectors.json` 给出四个本地旋转后的格位、法向及口外一步，不是运行时旋转放置实测。
- `finalize.py` 绑定前序验收、源NBT、当前原生报告、实际媒体、air-only派生与锚固，生成manifest、校验和及可回读ZIP。制作者自检不得冒充独立验收。

## 明确限制

世界放置、邻居刻、随机刻、流体刻、光传播、交互、运行时旋转全为NOT_RUN。静态生存用实际原版标签和亮度15假设，不推断实际光照或长期生长稳定；菌丝/藤蔓/小菇有扩散风险，拆支撑、骨粉、水桶、破坏池边未测。
