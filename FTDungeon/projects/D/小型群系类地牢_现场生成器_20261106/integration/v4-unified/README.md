# Independent unified candidate acceptance evidence

This experiment freezes exact runtime/core/catalog inputs under `staging`; no owner sources, original room bytes, accepted flags, old integration seals or formal Minecraft instance are modified. JAR `e6ca2da6399ce75ca3dca73236557d002d3f3584c93a0772602279855894dbdd` is installed alone into fresh ordinary Forge servers.

`installed.py` runs actual nine-original candidate commands at root orientations 0–3. Orientation0 is stopped at a partial saved BUILDING prefix and explicitly resumed by another normal JVM; automatic resume is rejected. One random-world orientation3 plan is safely rejected by runtime envelope budget before build; its exact seed/request/plan is preserved by `PlanBudgetProbe.java`. A separately labeled seed0 run supplies the fourth successful installed orientation, without erasing that refusal.

`readback.py` independently decodes saved Anvil chunks and FTD4 journals, comparing every original source cell, native raw/default BE fields, full enclosure and one-block exterior fluid/fire observation. Raw dynamic differences remain visible. The native test independently recomputes wall/stair neighbor updates and checks bounded surviving S8-08 vines; observed dynamic changes are not blindly ignored. Persistent force-ticking observations are checked from the actual installed journal.

The native runner copies completed stopped worlds before testing. `IndependentNativeTests` replays each owner-proposed path in independent 0.05 native moves using a 0.6×1.8 FakePlayer and maxUpStep0.6; only the initial point is set directly. Chunks along each path are loaded before movement. The initial no-prefetch failures are retained as harness artifacts, not blamed on source rooms. Door use/toggle/restore and native container menu construction are performed on copied worlds. This is not a human/network UI test or certification of every approach position.

`GlobalReturnTests` independently tests every actual corridor seam both ways and composes complete entrance-to-each-original-target-and-return paths without interior teleport. `FullMatrixTests` additionally places all nine exact originals in all four rotations, retaining all148 original targets per rotation and all2200 frozen directed/return matrix cases. It independently replays every returned physical path and runs force-ticked native fluid observations. Those isolated scenes complement, never substitute for, actual command/installed/global evidence.

Coordinate semantics are explicit: frozen route points are block-index feet anchors; physical center is local(x+0.5,y,z+0.5) transformed rigidly with the room. Declared input coordinates and IDs are preserved. Literal continuous stair-band coordinates receive no half-block shift. Full-width bands are sampled at transverse0.05 and native swept0.025 with three-block headroom; sampling is not proof for all real-valued coordinates. S8-07's interior doorway narrows the original north width; exact failed lanes, source hash, actual coordinates and native collision boxes are retained in `ISSUES.json`. Passing central routes does not waive this limitation.

`final-evidence.json` summarizes exact evidence; `ready.json` seals the evidence bundle, not production acceptance. All jobs remain PAYLOAD_VERIFIED_ROUTE_INTERACTION_ACCEPTANCE_PENDING, non-COMMITTED. `completeGeneratorReady=false` and all candidate acceptance flags remain false. Older V3 forced-kill results do not establish crash/power-loss safety for this new artifact.
