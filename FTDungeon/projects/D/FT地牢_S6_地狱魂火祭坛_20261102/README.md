## 交付

`out/S6/` 内四文件：`room.nbt`、`room.json`、`preview.png`、`qa.json`。图片设计来自第三批 S6，仅据现有设计图制作，没有调用付费生图接口。完整指纹、文件清单和接入注意事项见 `handoff.json`。

- Minecraft Java **1.20.1**，DataVersion **3465**，只有原版方块、单一调色板、gzip NBT；完整记录 **567** 个体积坐标（包括空气）。
- 占地 **9×9**，总高 **7**，`size` 按 **XYZ** 写作 `[9,7,9]`。概念图的 7×7 h5 在保留小房定位的前提下适度扩展，以容纳安全绕行、真实方块体积、吊灯支撑与滴落装置。
- 北入口玩家脚位 `[4,1,0]`；内部安全脚位 `[4,1,2]`；北开口 3 格宽、3 格高。地板、屋顶和其余边界完整。
- 1 处真正魂火，7 盏灵魂灯（3 吊灯、4 立灯）、9 节逐段有顶锚的锁链、3 颗有原生方块实体的骷髅头。
- 西后龛：玻璃护面的封闭熔岩落流。东后龛：封闭熔岩源、黑石实体支撑、朝下滴水石锥和两格下方净空；原版滴石流体解析实际返回 LAVA。
- 概念图地板的熔岩细线改为镀金黑石嵌线，不把玩家主路当熔岩沟。无容器、奖励库存、战利品表、刷怪笼或预放实体。

- `qa/forge-native.json`：隔离 Forge **47.4.10** GameTest，原生注册表和属性解码、`StructureTemplate` 往返、真实 `placeInWorld` 放置 **4 个旋转方向**；强制邻居更新和液体 tick，观察 **240 tick**。
- 每方向 **567** 个方块状态和 **3** 个骷髅方块实体完整保留；用实际碰撞体和 0.6×1.8 玩家体积检查通路，均有 **31** 个干燥安全脚位；未见液体逃逸、火焰蔓延或悬挂件脱落。
- `qa/native-roundtrip.nbt` 与原 NBT 的每个方块状态、方块实体数据精确一致。它是验证证据，不替代交付 `room.nbt`。
- `qa/forge-run.log` 包含 `S6_FORGE_PLACEMENT_PASS`、`All 1 required tests passed` 和 `BUILD SUCCESSFUL`。较早的两次测试工程资源配置错误和修正后通过日志另留作过程证据，不冒充最终通过。
- `preview.png`、`qa/four-views.png`、`qa/exterior.png` 均由实际交付 NBT 和原版模型/材质软件渲染。剖切只影响图片，最终 NBT 未拆顶；已目视核查。

## 边界

本次没有启动 Minecraft 客户端，没有修改正式玩家存档、其他房间、FT 核心或任何已部署 JAR。只在本独立工程 `forge/run/s6-only-gametest/` 创建一次性测试世界。软件预览不是实机截图；原生测试不等于完整整合包客户端、多人游玩或 FPS 验收。滴石的真实熔岩解析和支撑已验证，但没有声称已目视观察客户端滴落粒子。

本房间仍需接入负责人登记到目录、配置从 FT 大厅实际可走的连接、实现独立持久生成标记，并对目的地**整个体积**做占用拒绝。模板内有空气并不授权清空目的地。未经协调不要部署。

## 可复现

使用已配置的 Python + Pillow 运行 `tools/build_s6.py`，再运行 `tools/run_forge.ps1`、`tools/render_s6.py`、`tools/finalize.py`。`run_forge.ps1` 使用本机 Minecraft JDK17 和离线 Gradle 8.8 缓存，仅执行隔离 GameTest，不启动客户端。源图和 Minecraft 材质归档按本机原有绝对路径只读引用。

`tools/nbtio.py` 复用既有地牢工具；`tools/vendor/review.py`、`render_archive.py` 是既有软件渲染器的独立副本，仅改本工程内导入、模型审计记录与骷髅近似外观，未改源工程。
