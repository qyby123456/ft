## 构图与原版近似

- 新建35×20×43纵向大厅：两列各3根独立细柱，柱心XZ为(10,10)、(24,10)、(10,21)、(24,21)、(10,32)、(24,32)。底座3×3、柱身1×1、灯Y8、柱帽3×3/Y12，不复用前3张中央珊瑚丘、书桌或灯台。

- 四组低矮珊瑚花台、外围海带/海草/海泡菜，珊瑚有实体承托且邻水。六幅蓝/青/黄陶瓦马赛克表达墙旗，不是可摆动的旗帜方块实体。真实原版珊瑚颜色/分枝、海晶石纹样与插画不同。
