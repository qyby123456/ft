上层海带扎根楼板，底层海带扎根实底，不做悬挂会脱落的海带。珊瑚采用真实原版色形，铁栏杆代替参考青色栏杆；砂岩表达沙色拼块，未放重力沙。保留海底全浸条件，不按提示浅水字样生成空气带；无鱼、气泡、体积光线或氧气保障。
