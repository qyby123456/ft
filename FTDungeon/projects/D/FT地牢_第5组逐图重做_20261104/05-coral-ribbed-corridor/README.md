真实原版珊瑚方块、含水珊瑚/扇、海带、海草、海泡菜参与世界验证。原版不提供插画式细枝及完全相同橙粉色，使用其真实颜色与方块轮廓。砂岩表达沙色拼块，不放悬空重力沙。水下全浸合同优先于提示中的浅水字样，未伪造空气带；没有鱼、气泡特效、光束或氧气保障。
