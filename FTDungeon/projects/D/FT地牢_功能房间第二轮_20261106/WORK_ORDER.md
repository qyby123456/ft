## 独占范围

每线程仅负责指定S编号的10张参考图及本目录下对应S编号输出目录；references.json记录准确图片/提示词绝对路径和哈希。旧八组01—10验收源、合并NBT、存档及其他线程目录全部只读。不要修改mods、配置、KubeJS、共享构建脚本、旧验收表或正式世界。不要新生成付费概念图，不需要调用image2.5。用户此次要求开始工作，不代表授权自动修改正式世界。

## 制作流程

1. 读minecraft-builder-skill，核对本组references.json及适用AGENTS.md；先逐张查看11号实际图片和提示词，从构图、功能、空间比例、材质、标志特征及真实可通行接口制定建模方案。
2. **一次只制作当前一张**：11图书馆 → 12牢房 → 13厨房 → 14军械库 → 15训练场 → 16水井 → 17工坊 → 18墓窖 → 19瞭望台 → 20密道藏宝。不能先套一个通用房盒批量生成十张，不能用同一模板换材质冒充按图复刻。当前图建模、导出、渲染、看图和自检通过后再做下一图；保留候选哈希、问题和修正记录。自检不是独立验收，不得自己标为独立通过。
3. 每张交付vanilla Java1.20.1 structure NBT（完整结构不因概念图剖切而漏墙顶）、可重现生成配方、真实Lodestone预览、结构/方块实体清单、入口出口脚点/净宽净高及明确差异说明。展示剖切只能用于显示副本。不要把参考概念图当真实结构渲染。
4. 按实际方块注册/属性、尺寸、装饰支撑、0.6×1.8人体碰撞路线、容器空库存、液体/熔岩风险检查。优先复用旧八组经过验证的检查工具，但只能读，不直接改工具或复制其通过报告。新的证据必须绑定当前候选哈希。原生Java运行在本组qa目录，单进程并尽量限制堆≤2G；资源不足记录并排队，不能伪造通过。未执行的检查明确列出。
5. 十张均有独立候选与检查记录后，再按实际接口和高差设计本组新合并建筑，保留可通行功能和各图特色；走廊、门口补缝/玻璃与场景相符，外围联合包络加屏障且不截断内部连接。十张全是功能房间，**20号是密道藏宝而非总览，不能漏做**。不要复制旧组固定坐标。需要大模板时完整NBT+≤48格分片，源/分片逐格与实体载荷比对。
6. 本轮先交付独立产物、预览、QA、待复核清单与README；不要写入任何saves或安装战斗包。不要为装饰虚构可交互功能、刷怪/精英/Boss或生存通关验收。部署与战斗适配留待后续统一复核和指令。
