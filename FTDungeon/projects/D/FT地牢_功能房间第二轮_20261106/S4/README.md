# S4 沼泽湿地：第二轮 11—20 功能房间

本目录独占制作，未写入任何 saves、mods 或正式世界。房间严格按参考图片逐张制作，完成真实 Lodestone 渲染、查看和原版静态检查后才进入下一张；当前结果见 progress.json。自检 PASS 不代表独立验收。

## 可复现流程

1. 使用已安装 minecraft-builder-skill/scripts/run-build.mjs 构建当前房间 recipe.mjs，--data-version 3465，输出到该房间目录。
2. node qa/prepare.mjs 房间目录名：从候选生成哈希绑定的清单、路线输入；复用旧版原生检查类但不复制旧通过报告。
3. pwsh -File qa/run-native.ps1 房间目录名：单进程顺序执行两个原版 1.20.1 检查，堆上限 1536M，仅在本组 qa 下运行。
4. node qa/render.cjs 房间目录名：实际 Lodestone WebGL 导出完整视图和剖切副本，源 NBT 不剪切。
5. 实际打开预览检查后运行 node qa/finish.mjs 房间目录名 --viewed 检查说明，生成自检结果、房间 README 和进度。

## 证据与局限

- 每张 qa/inventory.json 包含结构尺寸、方块/方块实体清单、接口净宽净高、绝对局部脚点与功能访问点。
- 原生路线工具将输入 X/Z 加 0.5；prepare.mjs 明确反向偏移，确保实际测试与 metadata 脚点一致。0.6×1.8 人体、半格网格、最大无跳跃步高 0.5；不认证真实运动物理或梯子。
- 液体限制在有衬底、侧壁的浅池/蓄水井，使用干道绕行。没有执行放置世界邻居更新、随机刻或液体刻，也不宣称生存/战斗通过。
