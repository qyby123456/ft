## 产物与复现

每房间 `recipe.mjs` 是独立生成配方；`design.json` 记录构图、接口脚点、净宽净高、功能目标和与原图差异。`s5-XX.nbt` 是完整 Java 1.20.1 模板，DataVersion 3465，含显式空气。`complete.png` 为完整结构实际 Lodestone WebGL 渲染，`cutaway.png` 仅显示副本剖切，不裁切交付 NBT。

使用已安装技能的 `scripts/run-build.mjs <本组房间/recipe.mjs> --out-dir <本组房间>` 生成，然后在本目录运行 `node render.cjs S5-11` 和已配置 Python `check.py S5-11`。

`qa/inventory.json` 记录方块和空容器载荷；`qa/route-input.json` 绑定候选 SHA-256；原生注册/属性、模板往返、装饰 canSurvive 和 0.6×1.8 原生碰撞离线路线结果在 qa 中。检查类与 classpath 只读复用旧工具，但当前输入/结果重新生成；Java 单进程 Xmx1536m，工作目录限定本房间 qa。复用工具名中的 independent 不表示本次为独立验收。

## 水与氧气边界

采用浅水池与抬高干燥步道，不做全屋淹水；活珊瑚位于含水格，静态排查向下及四侧漏水面。对外门口位于水线之上，属于干口连接；单房 NBT 不能直接保证外部深海部署不倒灌，必须后续在封闭走廊/气闸中连接后复核。没有给予玩家水下呼吸或用气泡装饰假称供氧。
