## 结构与安全路线

模板尺寸 **25×17×25**（X×Y×Z）。入口脚坐标 **[12,2,0]**，北口范围 X=11..13、Y=2..5、Z=0..1，为 **3 宽 4 高**开放口；内部安全点 [12,2,6]，中央 **5×5**落点 X/Z=10..14、脚 Y=2。

首层主路 X=11..13、Z=0..22，向东支路 X=11..21、Z=20..22；均为 3 宽、3 高干路。中央落点与楼梯下平台均能往返北入口。地基 Y=0..1 全封闭，无洞、无水火、无蛛网。

两根独立落地双格石柱、柱脚、柱帽、木梁支撑 Y=10 残层。残层缺口 X=9..14、Z=5..8，共 24 格；缺口四周和前缘设护栏。右侧 **9 级、3 格宽**原版石砖台阶，从首层 Y=2 到残层脚 Y=11，台阶下方为实心石砌楔体，两侧有护栏。下落点 [20,2,21]、上落点 [20,11,9]，均保留 3×3 清空区域；上层安全点 [20,11,5]。

主题细节包括苔砖/裂砖/安山岩残墙、铁栏窄窗、贴地碎石和落梁、木箱、4 个空木桶、2 面带白色菱形的红墙旗、红地毯残布、苔块与持久树叶。6 盏灯笼中 4 盏由链条连到实木梁、2 盏立于完整地板。无预放实体、刷怪笼、命令方块、战利品表或脚本奖励。木桶可正常打开且为空，不伪装成 FT 奖励点。

NBT 含 **10,625 条显式记录**，其中 **6,513 条空气、4,112 条非空气**；6 个方块实体为 4 个空桶与 2 面墙旗。**显式空气会清除已有方块**，后续放置前必须检查完整 25×17×25 体积及实体/液体/边界，占用即拒绝，不能直接无条件清空。此交付未执行任何生产放置。

## 本机复现

使用已安装的 Minecraft Builder 依赖、Java17 和 Forge 离线缓存；`forge/` 为交付内测试夹具，不能安装到游戏实例。每次原生测试创建本目录内新的 `forge/run-时间戳/` 世界。

```powershell
$root = 'D:\ft工程文件\FT地牢_Image25接入_20261101\deliveries\zone-R01'
$skill = 'C:\Users\YOUR_USERNAME\.codex\skills\minecraft-builder-skill'
Push-Location $skill
node scripts/run-build.mjs "$root\source\recipe.mjs" --out-dir $root --name room --data-version 3465
Pop-Location
node "$root\source\static-qa.mjs"
& "$root\source\run-forge.ps1"
node "$root\source\preview-server.mjs"
```

预览服务为 `http://127.0.0.1:5311/preview/interactive.html`。在另一个终端运行 `node "$root\source\render.mjs"` 重新截图；运行已有 Pillow 环境的 Python 执行 `source/compose.py`，最后运行 `node "$root\source\finalize.mjs"`。NBT 修改后需重做所有校验并更新指纹，不能沿用旧证据。
