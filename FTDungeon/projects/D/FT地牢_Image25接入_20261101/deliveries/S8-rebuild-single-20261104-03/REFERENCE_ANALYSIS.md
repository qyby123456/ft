# S8-03：单箱壁龛小晶室

只制作S8-03-small-room.png；开始前核对S8-02-ACCEPTANCE.json及第2张最终NBT哈希，未授权第4张。当前建筑配方独立新写，不读取前两张结构或复用其晶台几何。

## 图像观察与解释

参考图是紧凑、近方形晶室，中央是一格箱体放在单层低矩形台上，不是晶核祭坛。近侧有明确入门，侧边有窄出口；后/侧墙上两层晶体壁龛、墙内分段支墩、两盏暖灯和白色方解石斑块构成主要识别点。图中屋顶和部分近墙为展示而去掉，不能按露天房交付。

提示词约9×9、6高仅作意图线索，画面里四个壁龛、宽墙墩和箱周通道无法精确量测。采用17×12×17的解释性比例：主地面顶Y2、脚位Y2、顶板Y11，墙净高9；外宽小于S8-02的25，且没有为16格区块限制削掉壁龛。屋顶与外壳保留；单NBT即可存储，不需拆片。

箱台5×3、高1格（Y2），箱体[8,3,9]，台前[8,2,7]可在不跳跃、不登台前提下接近。箱体正上方净空，不在顶盖开启体积加晶体；两簇边角小晶不作为主峰。箱中显式Items=[]，无LootTable、种子、机关或奖励逻辑；会单独用原版BlockEntity.loadStatic读取和检查，不把方块状态本身冒称已加载箱实体。实际开箱交互仍不是已测。

主入口北[8,2,0]，较窄侧口东[16,2,7]；都满足3宽×3高干口，侧口较低（3高）以表达图中窄侧道，且没有加入第三出口。全室同层，路线为入口到箱前分流，再沿东侧去窄口；墙龛前可抵达，箱台和墙龛是陈设，不要求登台或爬架。

## 与前两张的区别

无高晶核、无圆台/菱形环绕地带、无自由四柱、无后墙大拱对穿与木门储藏龛。这里的功能是箱前短停与墙龛展示，路径由小型箱台、两面壁龛和北—东转折决定；不是前两张换材质。地面为断续折线紫晶/方解石矿脉，不完整围成环。
