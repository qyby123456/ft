## 校验证据

`qa/static.json`：22971格完整体积与边界、1209列完整屋顶、基础、全部非空气方块六面连底、无液体/危险方块/未声明外口、四口各5宽×3高支撑净空与中央5宽×3高净空。

`qa/native.json`：原版注册表及属性校验、StructureTemplate读取/保存方块数核对，八份实际旗帜负载经BlockEntity.loadStatic读入。四旋转各17个标签目标（含interior与upper-landing重复坐标）全部无跳跃可达，包含四个门口、两侧走廊、入口低前室、楼梯顶和主厅；每向47处晶簇/灯笼/墙旗canSurvive静态支撑通过。每向四口中间三车道原版碰撞支撑与3高净空通过；5宽由静态检查另证，不冒称原版全5车道扫掠。

路线使用0.6×1.8身体、半格采样、原版碰撞AABB与对称扫掠边，非Entity.move或玩家实走。中轴路线每向实际包含脚高2/2.5/3/3.5/4，证明台阶不是忽略楼梯类别硬判通过。合成正反例控制全部通过。矩形旋转每90度交换宽深，方块[depth-1-z,y,x]、身体中心[depth-z,y,x]；门口从原坐标逐次交替原深度重算，另在打包环节核对每向锚坐标。校验器曾发现门锚尺寸使用错误，已修正并对最终候选重跑，不据旧失败报告放行。

`qa/lodestone.json`：八张真实Lodestone浏览器WebGL截图及读入NBT/图片哈希。四种内部剖切分别删对应近墙与顶板，范围见`qa/cut-rules.json`；原版建筑没有删柱或删横梁。`qa/cutaway-provenance.json`逐格核对范围外状态及方块实体负载不变。`views/`中所有inspection-only NBT均不是部署候选。

`qa/material-independent.json`：82项去材质几何筛查，没有完整固体坐标四旋转精确重合或内部IoU≥0.9；最大内部IoU0.2507。归一化体积/地面遮罩只用于相似度筛查，不等于全局语义独创性保证。前作及失败样本只读对照。

`qa/visual-review.json`为制作侧观察而非独立验收。柱体较粗、地纹较规则、旗帜无定制图案、玻璃/晶簇透明泛光不等同原图等偏差明确保留供独立判断。

## 复现

在已配置Python/Pillow环境运行`pipeline.py prepare`、`native`、`duplicates`。`previews`需要技能Lodestone服务器监听5604及Playwright/Edge依赖；参考图、前次验收、只读对照和Java依赖位置在脚本中显式记录。`qa/commands.jsonl`及`qa/classpath.txt`保留实际命令和类路径。每次重建后重新检查截图和视觉报告，再运行`pipeline.py package`；`checksums.json`覆盖所有交付文件，排除自身与__pycache__。
