可复现程序：`tools/verify-m04.mjs`；机器报告：`qa/static-qa.json`。

| 检查项 | 通过条件 |
| --- | --- |
| 参考图来源 | SHA-256 为 `537f369f2598d7c3f603011fca9b64e69f2793fe458285bc44da1afdeee10eee` |
| 模板格式 | gzip、DataVersion 3465、单 palette、13×12×41、6396 条唯一显式坐标 |
| 直线通路 | x=5..7 的全部 123 个脚位在 y=2，脚下 y=1 完整实心，y=2..4 全部空气 |

| 内容 | 无实体、无方块实体、无容器奖励；有柱梁、末地烛、暖灯、空吊笼与藤蔓 |

静态检查不猜测 Minecraft 注册表和实际碰撞形状；后两者由原生 Forge 报告给出。

## 原生验证

见 `qa/forge-placement.json` 与 `qa/forge-console.log`。四向实际放置，每向重复两次；校验合法注册方块及属性、NBT 往返、原生 `canSurvive` 与玩家 AABB；邻居通知后复查，再强制加载区块并等至少 200 世界 tick，显式调度全部水源 tick，扩大一格扫描底部和周边流体泄漏。默认 randomTickSpeed=3 未关闭；仅允许两侧贴墙藤蔓发生自然生长，任何此类变动单列数量，其他结构状态必须一致。

仅在交付目录中的一次性隔离 GameTest 世界执行，不读取玩家存档。不是整合包客户端游玩、FT 大厅接路或正式部署验收。准确 PASS/FAIL 和结构指纹以同目录 JSON 与日志为准，不用说明文档代替执行结果。
