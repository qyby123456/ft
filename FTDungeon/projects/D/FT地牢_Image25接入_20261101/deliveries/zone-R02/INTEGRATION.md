- 模板尺寸 21×11×21，闭区间 `[0,0,0]` 至 `[20,10,20]`。默认北向、不旋转、不镜像。

| 对象 | 世界坐标或闭区间 |

| 房间体积 | (Ox,Oy,Oz) 至 (Ox+20,Oy+10,Oz+20) |
| 一格安全外圈 | (Ox-1,Oy-1,Oz-1) 至 (Ox+21,Oy+11,Oz+21) |
| 入口脚位 | (Ox+10,Oy+1,Oz) |
| 安全点脚位 | (Ox+10,Oy+1,Oz+6) |
