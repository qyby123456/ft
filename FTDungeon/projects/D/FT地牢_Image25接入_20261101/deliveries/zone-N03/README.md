# N03 八角回廊楼梯枢纽

独立 Minecraft Java 1.20.1 交付；使用 Minecraft Builder / Lodestone 0.6.0 生成，隔离 Forge 47.4.10 GameTestServer 验证。交付范围仅 zone-N03，未部署、未写玩家存档、未修改正式模组或其他房间。

## 四件套

- room.nbt：gzip、单一调色板、DataVersion 3465、35 × 18 × 35；明确记录整个包围盒 22,050 格。
- room.json：原图与模板哈希、所有脚部接口、安全点、四组楼梯、灯具支撑、材料统计。
- preview.png：从最终 NBT 渲染的西北剖切预览；最终 NBT 保留完整屋顶。
- qa.json：静态、渲染、原生四旋转、稳定性与几何通行的汇总和证据路径。

## 接口及通行

坐标为模板原点相对 XYZ，接口坐标均为玩家脚部。所有外部接口水平出入，净宽 3、净高至少 3。

| 接口 | 脚部坐标 | 地板高程 |
| --- | --- | --- |
| 北下层／标准入口 | [17,1,0] | 0 |
| 南下层 | [17,1,34] | 0 |
| 东上层 | [34,13,17] | 12 |
| 西上层 | [0,13,17] | 12 |

内部安全点为 [17,1,2]；中庭平层安全点为 [17,7,11]、[23,7,17]、[17,7,23]、[11,7,17]。上下层平台另有安全点，详见 room.json。

四组楼梯各宽 3、六级完整楼梯块，每级分为两个半格踏步；南北从脚高 1 升至 7，东西从脚高 7 升至 13。全部踏步实心承托、至少 3 格净空；原生碰撞扫掠验证双向无须跳跃。中庭到四个楼梯口均连通，每向 736 个中庭平层脚位可达。垂直连接为内部楼梯，中央竖井无对外垂直接口，封底并以 1.5 格高石护栏围合；不可把竖井当接入洞口。

## 验收证据

- qa/static.json：14 项 PASS，包括参考哈希、全体积、完整八角屋顶、四个外部开口、楼梯连续性/支撑/净空、四柱、21 灯支撑、四块告示牌、平层安全点。
- qa/forge-native.json：四旋转 NONE／CLOCKWISE_90／CLOCKWISE_180／COUNTERCLOCKWISE_90 全部 PASS；每向放置 22,050 格，全量触发邻居更新并等待 120 tick，总计 88,200 格逐状态一致。
- 每向检查 312 次双向楼梯碰撞扫掠，使用原版碰撞体与 0.598 × 1.8 玩家包围盒；每向四接口经中庭与楼梯连通、21 灯可生存、四块文字牌保留、无意外实体。
- 每向堵路和撤灯支撑各一负例，共八次，均检测并恢复。
- qa/native-placed-*.nbt：四向稳定后世界回采；逐格方块状态与旋转源一致，各文件哈希写入原生报告。文字牌经原生块实体加载与蜡封/文字条数检查。
- qa/forge-gametest.log：ZONE_N03_NATIVE_PASS，All 1 required tests passed，BUILD SUCCESSFUL。日志中 Forge 版本检查网络超时和夹具首帧落后警告不影响通过结果，完整保留。
- preview/：四向内部、两张下层楼梯、四象限剖切、完整外壳及 four-view.png。软件 WebGL 预览，从最终 NBT 读取；剖切只过滤显示。

## 证据边界与接入注意

原生通行是碰撞体、踏步和可达图验证；未录制真实客户端玩家行走，未验证整合包多人或 FT 核心大厅接线、占用拒绝和幂等。源模板含明确空气，接入方仍必须先审查整个包围体积的占用和实体，不能直接覆盖世界。接入时按 room.json 的脚部高程接线，原点旋转也须同步变换接口、朝向和安全点。
