# 地牢走道 · 40 张（一字贯通 · 中 / 短两档）

> 用户需求：「由你发布任务和子线程绘制地牢走道图片（一字贯通）分为中，短两种（2~3区块，1区块）总计40个图片左右，交给image生成，注意风格不要太重复」

## 两档长度
- **中 M01–M20**：2–3 区块长（约 32–48 方块），远端可见门/拱与黑暗。
- **短 S01–S20**：1 区块长（约 16 方块），尽头近在眼前（门/拱）。

## 构图（一字贯通）
- 一点透视、镜头在走道正中、眼平高度直视前方；走道轴线对准画面中心灭点；
- **无转弯、无分岔、无楼梯**；两侧墙体平行，地面与天花板可见；
- 远端按档位呈现距离（中：远处门洞；短：近处门/拱）。

## 风格矩阵（避免重复）
- 20 种主题材质：石砖 / 黑石深板岩 / 冰霜 / 地狱 / 末地 / 灾变暗铁 / 废弃矿道 / 蔓生废墟 / 被淹水廊 / 蛛网 / 档案书库 / 牢房 / 熔岩锻造 / 骨墓 / 真菌 / 水晶 / 铜机械 / 血腥祭坛 / 冰封牢狱 / 黑曜试炼
- 6 类状态：完好 / 轻损 / 蔓生 / 积水 / 焚毁 / 陈旧
- 6 类光源：壁火把 / 吊灯 / 灵魂灯 / 熔岩辉光 / 末地烛 / 蜡烛
- 10 类特征：柱列 / 侧龛 / 破拱 / 铜管铁链 / 地面排水沟 / 铁门 / 雕像龛 / 吊笼 / 破旗 / 裂壁画
- 每张由「主题×状态×光源×特征」组合生成（见 `out/corridor_index.json`），Medium/Short 各 20 张，组合不重复。

## 统一规格
- `gpt-image-2.5-flare` / 1536×1024 / quality high / n=1；Minecraft 方块风；无水印/无文字/无角色。
- 每张提示词在 `prompts/`，文件名含编号与主题。

## 分开制作
- 3 个 image 线程分开绘制（分配见 `DISPATCH.md`），各自只写 `out/` 中自己的文件；Lead 兜底缺图并合成总览/文档。
