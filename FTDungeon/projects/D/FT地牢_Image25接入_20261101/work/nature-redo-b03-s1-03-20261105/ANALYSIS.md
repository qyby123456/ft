# S1-03 单图构图与尺寸解释

唯一参考：D:/ft工程文件/image2.5/nature-dungeon-styles-20261104/S1-mossy-forest/out/S1-03-small-room.png。

- 主体为小型方石室，中央单箱放在低石台上，台前留出步道；没有中心泉台、高祭坛或书架储物区。
- 画面左后粗树贴墙生长，树根向地面展开，顶部分叉横向延伸至右墙，叶丛和发光藤垂挂。两处后墙木架陈列红蘑菇与小盆。
- 画面左门与右门为相对侧连接，中央箱台形成局部绕行。左后根边与右前各有浅水凹池，不是中央水景。
- 19×12×17为以三格连接口、单箱与低台为尺度的整数近似，不声称精确测量；西门z9..11、东门z5..7，错位入口之间沿箱台南侧三宽步道相连。
- 中央台x9..11/z8..10/y2，箱位[10,3,9]；左后树干、双壁架、边池分别保留原图语义与相对位置。
- 图片外侧森林和光束不是室内几何，近侧缺墙按预览剖切理解。最终NBT有完整顶墙，仅保留东西侧连接口；实际显示裁切另行声明。
- 木架采用实心木板与落地支撑，小蘑菇/盆以原版盆栽红蘑菇和空花盆表达，避免独立蘑菇受光照脱落；地面绿植为永久树叶小丛。原图台阶和根部斜向轮廓采用整方块阶梯近似。
- 单箱不含Items/LootTable，不设波次、机关或奖励；只制作03，不并做04，不部署。
