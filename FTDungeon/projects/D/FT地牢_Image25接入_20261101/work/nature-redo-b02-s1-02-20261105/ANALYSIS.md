# S1-02：单图构图分析与适配

唯一设计图：D:/ft工程文件/image2.5/nature-dungeon-styles-20261104/S1-mossy-forest/out/S1-02-medium-room.png。

- 可见主体为单层方形石室，中央小型低矮方泉占地约房间宽度的四分之一，空间由绕泉台的步道串联；没有01图的高祭坛与后部主导巨树。
- 左后方有门洞、木桌和储物；右后方为根木包裹的书架/箱龛；右前有短瀑和池，前左另有池。木根贴墙弯曲并在顶上形成横向根梁。
- 石柱、门龛、低泉台构成石材层，粗根/叶丛形成上层自然覆盖，暖灯悬吊；图片体积光不属于结构几何。
- 23×13×21为基于门高、泉台占比和周边工作区的整数近似，不声称精确测量；没有按区块或单NBT上限缩小。泉台5×5、高1格，门洞净宽3、净高4，步道最小3宽3高。
- 北门为图中后门语义，南门为成品安全适配；以北为-Z明确坐标，不以相机左右代替世界方向。
- 右前短瀑采用玻璃封闭的源水竖槽与侧池表达，避免敞开瀑布流入主路；这是与图有差异的安全适配，不伪称真实开放流瀑还原。
- 图中近侧缺墙按剖切理解，最终结构有完整屋顶及外围墙，仅预览裁切；制作期不写正式存档。
- 桌面为实心原版木台＋灯笼，书架和两个空桶/一个空箱不分发战利品；不加图片未说明的波次或机关。
