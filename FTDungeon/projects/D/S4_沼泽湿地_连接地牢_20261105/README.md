# 第四组：沉根湿地·九域连通地牢

使用第四组当前已验收的 01—09 九份实际 NBT 房间重新组装，不复制第 10 张总览，不修改九份冻结原源。

## 结构与风格

完整体积 **179×38×220**，**1,496,440 个显式格**，九房间、八条新建连接通道。

南侧双门接引前庭 → 沉水旗柱大殿。主殿分出：

- 北线：垂藤积水长廊 → 古树环水主室。
- 西线：盘根水窟 → 浅水书房 → 苔灯折角。
- 东线：瀑水回廊庭院 → 双卫藏宝高台。

用模块底部平移对齐接口 Y10，不改变室内原有积水、水上踏步、桥、树根和高台。南侧入口为 Y8，沿原台阶进入。连接通道采用深色橡木地板/屋顶、苔石砖与裂纹石砖侧墙、灯笼，内部干燥以便通行，内宽 7，门口按源接口收窄。不用玻璃或屏障覆盖原室内水景。

未使用的旧外口封墙，连接口周边补缝，四个原门半块改为开启；全部改动位置与原因列在 `layout.json`，其他模块状态和方块实体负载逐格保留。构建过程中纠正过通用模板误封南入口的规则，失败源未部署；最终通过证据以当前 SHA256 为准。

联合房间、连接通道和入口平台外围有一层原版屏障，共 **55,822 格**，包含侧面、顶部和底部，不截断内部通路。屏障不限制旁观、传送或创造模式破坏。
