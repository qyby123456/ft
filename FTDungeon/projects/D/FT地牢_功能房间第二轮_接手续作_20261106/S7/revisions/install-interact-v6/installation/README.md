# S7 安装包使用说明（未部署）

适用：Minecraft Java1.20.1，零旋转、无镜像，仅主世界。包为fts7-datapack.zip；内部pack.mcmeta位于压缩包根目录。安装会清除指定完整区域的所有方块及BE，必须先由维护者预留全新空闲区域。不会清除实体，必须确认无现存实体、建筑、玩家物品、地牢或其他用途；也需预留未被其他系统强加载的区块。

|用途|位置/范围|
|---|---|
|结构最小角|10000 80 10000|
|完整清场包络|10000 80 10000 → 10325 119 10150，1969040格|
|外部落脚点|9992.5 85 10028.5|
|外部地板|9990 84 10026 → 9994 84 10030|
|外部头顶清空|9990 85 10026 → 9994 88 10030|
|内部进入/返回站位|10014.5 85 10028.5|

1. 维护者批准预留位置后，将zip置入目标世界datapacks目录，执行/reload。加载仅创建两个trigger目标，不自动安装、不自动清场。
2. 管理员执行/function fts7:install。它强加载安装区域，先执行110条fill清除完整包络，再放15个模板并建外部平台，设置安装标记，释放本次区域强加载。首次过程会占用服务器处理时间，请在维护窗口使用。installed标记使再次调用不会重复放置实体。
3. 玩家到达外部落脚点（管理员可首次/tp玩家到该坐标），站在半径1.5格范围内执行/trigger fts7_enter。它将玩家送到内部入口，原外围屏障不打孔。
4. 玩家沿房间返回内部入口站位，在半径1.5格内执行/trigger fts7_return，回到同一外部平台。
5. 普通玩家仅使用trigger；function安装、enter、return是管理员命令权限范围。远处即便保留已启用trigger也不会传送，分数会清零。未提供重复强制安装或自动卸载命令，避免破坏已有探索内容。

隔离GameTest已实际运行包内函数并验证：完整包络1969040格逐格方块类型一致、60115屏障保留、权限0进入/返回、远处触发无效、第二次install后仍3具装备架。测试使用嵌入式Netty通道支持原版服务器命令传送，未测试TCP客户端收包确认。installed-after.nbt保留安装后载荷。以上不是正式部署授权或独立验收。

本包固定坐标，不可只移动15片而不同时修改所有函数、平台与触发范围。不得以分片包络1324800格代替完整1969040格清场；也不得直接放稀疏NBT而留下世界旧方块。
