# S4 受控进入/返回安装方案

适用 Java 1.20.1、主世界；只绑定合并 NBT SHA256 `b01fdaf300987e299d141f1963530ad2b1861be8fe4c17631cdc879f7c7415d8`。两终端屏障维持封闭；进入/离开通过可审查的原版数据包完成，不切屏障、不修改共享生成器。本交付只在隔离 QA 世界执行安装，正式世界尚未安装。

## 安装到用户预留区域

1. 先在预留空域按 assembly/parts.json 原点安放全部 18 片，或用合适的结构导入工具安放完整 NBT；整组尺寸 415×24×67。选定总域最低角 OX/OY/OZ，保持原朝向、不镜像旋转。校验候选及分片哈希。原点是结构包围盒最低角，不是入口脚点。
2. 在结构包围盒以外预留一个 7×5×7 的空候台区域，候台中心 LX/LZ 建议半整数，脚高 LY 为整数。安装函数会把 [floor(LX)-3,LY-1,floor(LZ)-3]—[floor(LX)+3,LY+3,floor(LZ)+3] 改为平台/净空和两盏灯；仅在明确预留的空域运行。
3. 用配置的 Python 执行 `access/build-access.py --origin OX OY OZ --lobby LX LY LZ --out <新的输出目录>`。默认且仅支持 minecraft:overworld。生成器先检验候选 NBT 哈希，再生成绝对坐标函数和 installation.json；不能直接复制别处坐标后宣称测试仍适用。
4. 将生成目录放为目标世界 datapacks/s4-access，确保 pack.mcmeta 位于该目录根。管理员执行 `/reload`，再执行 `/function fts4_access:install` 创建候台。玩家无需 OP 即可使用后续 trigger。函数加载只创建三个本包计分板，不更改游戏规则、不装模组或脚本。
5. 玩家走上候台中心附近 5×4×5 的接入区域，执行 `/trigger fts4_enter set 1`；进入 O+[4.5,4,28.5] 的已验证内部干燥起点，标记该玩家 inside=1。在当前结构范围内执行 `/trigger fts4_exit set 1` 返回固定候台，inside=0。原内部路线到起点可返回，但返回触发也可用于内部受阻脱离。

每个玩家独立计分。外部非候台玩家触发 enter 无效；未进入本组的玩家不能用 exit 传送；其他维度及结构包围盒外的返回请求不执行。离开结构范围或维度后，inside 自动重置为 0，避免外部重入受残留状态阻止。请求每 tick 重置，并重新启用 trigger。函数名称/计分板为单个 S4 实例预留，同一世界只安装一个本配置；多实例需要另行命名及测试，不能直接覆盖。

## 已配置的隔离测试实例

测试原点 [1024,256,1024]；外部候台 [1016.5,260,1052.5]；内部 [1028.5,260,1052.5]。生成的数据包在 qa/access-gravity-r3/datapack，installation.json 列出每个函数的哈希和写入范围。它是可直接安装的此坐标测试配置；实际部署到其他坐标应重新生成。

qa/run-access-gravity.ps1 会创建本组下全新 server-access-时间戳 世界，把数据包在服务器启动前装入，再安放同哈希 NBT。以权限 0 的服务器玩家实际执行 trigger，经过真实数据包 tick 函数进入并返回，验证未授权返回拒绝及 24 个终端屏障方块保留。最终以同目录 exit.json/tests.xml/access-gravity-report.json 的一致结果为准，失败历史不算通过。

当前补证通过：11 号 275 帧、19 号 184 帧完成上下往返，连续真实服务器 tick，观测脚高分别 4→9→4、4→8→4（相对合并原点），最大单帧上升 0.5。引擎报告的 maxUpStep 为 1.0，未手工提高；本次实际轨迹未跨越超过半格的上升。不将配置上限与已观测的运动幅度混为一谈。

接入测试的标准 ServerPlayer 与标准 ServerGamePacketListenerImpl 在隔离 PlayerList 中直接登记为测试夹具（Forge 的公开玩家列表只读）；未经过 socket/客户端登录。传送、权限 0 trigger、选择器与数据包函数仍走实际原版执行路径，没有覆盖传送方法或人工代填预期位置。楼梯 actor 的 FakePlayer 只初始化一次位置，之后逐刻调用实际 Player.travel；其伤害免疫不用于任何战斗声明。

这提供了完整可安装的受控接入方案，不代表已经部署正式世界。测试不是网络客户端按键或生存/战斗认证。
