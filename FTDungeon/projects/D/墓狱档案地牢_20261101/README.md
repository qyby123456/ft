# 墓狱档案地牢 · Minecraft 1.20.1

依据 `D:/ft工程文件/image2.5/tomb-archive-block-structure-20261101/out/` 中的两张参考图制作：保留深板岩、深色木框书架、头骨墓龛、中央阅档石桌、铁栅密库、吊链灵魂灯、蜡烛及蛛网，并把单间概念扩展为一座可进入探索的独立建筑。

**占地31格宽 × 39格深，向上预留16格；NBT 的 XYZ 尺寸为31×16×39。** 全部使用原版1.20.1方块，不要求新增建筑模组。完整成品有屋顶，预览为了看清内部作了剖切。

![墓狱档案设计总图](preview/tomb-archive-design-sheet.png)

## 结构与还原

1. **入口前室**：朝北（-Z）的七格宽阶梯与石拱入口，两侧青色灵魂灯。
2. **阅档主厅**：双侧四格高书架，深色橡木柱框、局部雕纹书架与通行回廊。
3. **中央石桌**：深板岩桌面、双讲台档案书、头骨镇纸、三支蜡烛及四座石凳。
4. **墓龛骨匣**：侧墙和入口内侧的头骨烛龛，左后侧双石棺、骨块与空骨匣桶。
5. **抄录囚室**：右后侧铁栅小室、抄录台和铁门，门的内外均有石质压力板。
6. **铁栅密库**：后部独立库房，铁栅围护、双侧压力板铁门、链柱、吊灯、封名册与后墙书架。

六个讲台均装入真正的可阅读成书，包含值守名录、失卷记录、旧案索引、囚徒抄本和封名册。六个储物桶均为空，不配置免费刷新奖励。

参考图有非原版细节，做了明确替代：普通书架加深色木框，并非自定义深色橡木书架；用原版铁门而非锈蚀新材质；用讲台承载真实书籍，未制作羽毛笔/散落书籍模型；桦木压力板仅表现地面纸页意象，不是可拾取的纸张。墓狱中没有“苔藓深板岩”这种原版方块，少量斑驳使用苔石砖。

## 安装与放置

**本次只交付独立工程；没有安装到实例、替换地牢模组、写入玩家存档或新增收费图片请求。**

1. 先备份拟测试的世界。将 `out/ft-tomb-archive-1.20.1.zip` 复制到该世界的 `datapacks` 文件夹，进游戏执行 `/reload`。先在测试世界使用。
2. 执行 `/function fttombarchive:help` 查看尺寸和提示。
3. 在创造模式选择空地，站在建筑预留空域的**西北角、最低基础高度**。当前位置起，+X方向31格、+Z方向39格、向上16格必须都是空气；确保相关区块已加载。预留范围内除建造者本人外不能有其它实体。
4. 执行 `/function fttombarchive:build`。成功后自动将建造者移到入口前室，面向内部。

例如站在Y=64执行时，最低基础位于Y=64，主地面方块位于Y=66，玩家在Y=67行走。不会挖掉脚下Y=63的地面，也不会清除已有建筑。入口朝-Z，后部密库朝+Z；没有自动接通旧地牢大厅。

结构管理员也可执行 `/place template fttombarchive:archive <x> <y> <z>`，或使用结构块加载 `fttombarchive:archive`。本结构各轴均小于48，符合默认结构块UI上限。**原生放置命令与结构块会绕过本包的防覆盖检查**，不要在正式建筑上盲目使用。NBT仅在工程的out目录，未自动复制到实例schematics目录；机械动力导入兼容性未在客户端实测。

## 安全边界

- 当前是**建筑与档案叙事版**，不含战斗波次、Boss、收费、结算、传送或自然世界生成。没有改动FT现有地牢、个人返程、挑战入口或火盆数值。
- 不使用每tick函数，不强制常驻区块，不自动施工，不执行范围杀怪、清空地形或改变游戏规则。
- 建造前检查整块31×16×39空域，共19,344格；拒绝非空气、未加载或越界目标，且排除其它实体。一次检查可能短暂占用服务器时间，命令链数量低于原版默认65,536上限。
- 两处铁门采用原版双侧压力板，不设置Lock/定时封门。通路检查按踏板正常打开铁门计算；保护插件和整合包红石修改可能改变实际行为，须在副本确认。
- 没有主动刷怪不等于禁止自然刷怪；世界难度、照明和其它模组仍可能使房间生成怪物。蜡烛和灵魂灯不使用外露火焰或熔岩，不修改doFireTick。
- 防覆盖检查是施工前检查，不是支持崩溃恢复的事务。保护插件、服务器崩溃或其它命令干预仍需通过存档备份处理。没有提供全局删除/粗暴回滚函数。
- 删除数据包不会拆除已建建筑；结构内可阅读书籍和空桶仍保留。
- 预览从最终NBT生成，使用本机原版方块模型及贴图；头骨、旗帜和讲台书实体简化。不是实机截图，不代表实际光照、帧率或着色器表现。

## 复现与验证

Python3.10+可运行 `tools/build_archive.py` 重建结构和数据包；软件预览需要Pillow：

```text
python tools/build_archive.py
python tools/render_archive.py --textures-jar "Minecraft-1.20.1-client.jar"
```

几何检查验证入口至12处关键点的两格净高通路、头骨/蜡烛/踏板支撑、吊链与灯笼锚固、铁门上下半部及双侧踏板、六本书和空桶。`tools/VerifyArchive.java` 通过Forge开发环境加载真实Minecraft1.20.1注册表，检查所有方块属性、NBT结构往返、方块实体、书页JSON和Brigadier命令语法。执行 `gradle --offline --no-daemon runData`，结果写入 `qa/minecraft-format-verification.json`；开发验证模组仅用于工程检查，**不要装入游戏mods目录**。

原生格式验证不等于已在玩家世界放置和游玩验证；以后者为最终游戏验收。
